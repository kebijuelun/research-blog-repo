# 不要语言预训练，文生图反而更强？Halcyon 的"从零开始"实验

现代文生图（T2I）系统几乎无一例外地依赖互联网规模的语言预训练，而它吃掉了主流系统 **80% 以上**的预训练算力，贡献却从未被系统量化。斯坦福与 Radical Numerics 的 Halcyon 证明：这套"隐形依赖"可以被彻底抛弃——完全从零训练的早期融合多模态模型，Halcyon-1.6B 以 **1/275** 的总预训练算力击败依赖 Qwen3-1.7B 的 JiT-T2I-XXL/8++（gFD 35.3 vs. 41.0），0.52B 小模型也已击败挂 FLAN-T5-XL 的 LlamaGen-XL/8（gFD 48.0 vs. 63.3）。

## Halcyon 是什么

- **完全从零训练**：文本 tokenizer（16,384 词表 BPE）、图像 tokenizer（Cosmos 结构 + FSQ，码本 64,000，8 倍下采样，每张 256×256 图 = 1024 个 token）、生成模型（Qwen3 风格 decoder-only），全部从零起步，只用约 1 亿对图文数据（GPIC）训练一个 epoch。
- **早期融合**：文本与图像 token 共用一个 80,640 的联合词表，单一模型做 next-token prediction，无需任何外部文本编码器。
- **关键实验设计**：所有对比在**固定总算力预算**下进行，纯粹比较数据配比本身的效果，排除"钞能力"干扰。

## 主结果：不靠语言预训练，反而更强

- 两个"前菜"证据：给 LlamaGen 换更好的图像 tokenizer，gFD 从 147.0 降到 63.3——**换 tokenizer 比换语言模型重要得多**；把 FLAN-T5-XL（1.22B）降级为 T5-Base（0.11B），语言算力省 13.5 倍，gFD 仅轻微变差（63.3 → 66.7）——**语言预训练算力增加一个数量级，只换来边际改善**。
- 规模对比：Halcyon-1.6B（gFD 35.3）同时超越两个强晚期融合系统，4B 进一步降至 **28.4**；组合生成上 1.6B 在 GenEval（53.5 vs. 43.2）与 DPG-Bench（77.9 vs. 76.9）双双超过 JiT-T2I-XXL/8++。
- 算力账：LlamaGen-XL/8 与 JiT-T2I-XXL/8++ 的预训练 FLOPs 分别有 **93.6% 和 99.8%** 烧在语言预训练上；Halcyon 不存在任何外部语言预训练。

## 控制实验：语言预训练到底有用吗？——没有

- **干预一**：固定预算内划 10%/20%/50% 给纯文本预训练，gFD 单调变差（48.0 → 51.6 / 52.8 / 65.1）；即使事后补满整个 T2I epoch（1.5 倍算力），gFD 49.2 仍不如 baseline。
- **干预二**：用 36T token 预训练的 Qwen3-0.6B 初始化，gFD 47.8，反而**不如**随机初始化的 46.6；降低学习率保护预训练权重则更差（63.6）。
- **原因**：纯文本预训练优化的是 $p(\mathcal{T}\mid\varnothing)$，而 T2I 需要的是 $p(\mathcal{I}\mid\mathcal{T})$，两者间没有必然的可迁移性。

## 免费午餐：I2T 替换 caption dropout

把原本随机丢 caption 的 10% 样本直接换成 I2T（图生文）样本——两类序列共享同一图像前缀，**条件/无条件图像 token 数量完全不变，CFG 照常工作**，却白得了图像描述能力：条件文本 NLL 下降超一个数量级（0.52B 处 18.4 → 1.1），gFD、GenEval、DPG-Bench 全部持平，且 caption 对齐分数随规模上升（0.1B 的 0.090 → 4B 的 0.559）。

## 结语

从零训练图像 tokenizer + 小词表 BPE + 早期融合自回归 + 亿级图文对，就是一套完整可复现的低成本 T2I 方案。这项工作提示：多模态生成中"先预训练单模态底座再迁移"的惯性思维——包括文生视频对大语言编码器的重度依赖——都值得用同样的控制实验重新审视。

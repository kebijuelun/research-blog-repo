# ATAS：给视频生成 Agent 装上"世界状态"记忆

长视频生成正走向"Agent 按剧本分镜拍摄"，但现有 Agent 只靠最近几帧或文本摘要维持连贯性——一旦要求"回到之前的房间"或"换机位重放刚才的事件"，画面就穿帮。浙江大学 ZIP Lab 等机构提出的 **ATAS** 用"持久世界状态"解决这一痛点：在 4 个视频生成 backbone 上拿下所有跨镜头一致性指标第一（Wan 3.0 平均分 0.734 vs 最强 baseline 0.648），空间回访任务 PSNR 达 15.968，超过所有多镜头 Agent 与 3D 引导方法。

## 核心思路

- **问题定位**：长视频 Agent 缺的不是生成质量，而是"世界记忆"。持久状态需解决两点——可寻址性（时空两维精确检索）与可靠性（错误生成内容不能污染记忆）。
- **双记忆系统**：世界状态 $\mathcal{W}_t=(\mathcal{S}_t,\mathcal{E}_t)$。静态几何进**场景记忆**（共享坐标系，可在任意新相机下重渲染）；动态观测进**事件记忆**（绑定事件标识与时间区间，支持事件重放）。
- **生成闭环**：编译器把高层剧本递归拆成带场景坐标、相机、时间索引的镜头请求 → 检索双记忆作为条件 → 生成 → 验证后才写入状态。
- **最聪明的设计**：影片交付与状态准入解耦——影片审查、配准、状态更新检查三道闸门，"够好看能上映"的镜头未必"够可靠能进记忆"，避免误差累积。

## 关键结果

- **主实验**：4 个 backbone 上跨镜头一致性全胜，提升集中在一致性而非局部画质，证明收益来自持久状态而非更好的渲染器。
- **消融**：双记忆建立收益，递归编译放大收益（事件分 0.508 → 0.711 为最大一跳）；场景记忆主要改善空间一致性，事件记忆主要拉高事件分，分工必要性得到验证。
- **效率**：重试次数减半（1.00 → 0.54/镜头），代价是每故事耗时增约 25%（51.9 → 64.9 分钟）——用算力换稳定性。
- **人类评测**：六项标准全胜（剧本忠实度 4.40、角色一致性 4.22），但背景一致性与叙事连贯仍偏弱；事件重捕中"动作状态精确复现"是论文坦言的剩余难点。

ATAS 将"世界状态"确立为 Agentic 视频生成的核心基础设施，为交互式影视制作与预可视化指明了方向。

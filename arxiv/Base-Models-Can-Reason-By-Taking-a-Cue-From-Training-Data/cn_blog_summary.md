# 两个 Token 顶一次 RL：基础模型的推理开关，藏在开场白里

只在基础模型的回答开头固定两个 token，就能让它追平 RL 训练后的推理水平——这篇来自 MIT、UC Berkeley、UW 和 AI2 的论文证明：基础模型的推理能力早就藏在权重里，RL 很大程度上只是把"开关 token"的出现概率调高。最亮眼的数字：Olmo-3-7B 在 MATH-500 上的 pass@1 从 **42% 飙升到 78%**，超过 RL 版的 75%；更硬核的是，把训练数据里的 "okay" 全部换成 "chicken" 重训后，语义上毫无意义的 `.\n\nChicken` 真的变成了推理开关（2.4% → 37.2%）。

## 核心发现：正确回答更爱"另起一段"

研究的起点是一个朴素统计：Olmo-3-7B 对 MATH-500 的回答中，**50% 的正确回答以 `.\n\n` 开头，错误回答中只有 14%**。研究者把生成分解为"开头 token cue"与"续写"，用 prefill 固定开头、不改任何权重，从而剥离出开头本身的影响力。

有效的 cue 可以在没有标准答案的情况下自动发现：beam search（宽度 20、深度 2）按概率提候选，再用**答案熵最低**（采样答案越一致越好）的无标签准则筛选。选出的 cue 在 501 个候选的穷举评测中排名第 8，仅比最优者低 1.1 个百分点。

## 关键结果：cue 追平 RL，且不是"写得更长"

- **Olmo-3-7B**：MATH-500 42% → 78%（RL 为 75%）；GSM8K 45% → 86%；HumanEval 50% → 70%。
- **Qwen3-14B**：MATH-500 72% → 87%，与 RL 持平；AIME 2024 10% → 30%。
- **SmolLM3-3B**：cue 把 GSM8K 从 7.6% 拉到 68.0%，提升 60 个百分点。

行为层面，cue 之后 **97% 的回答包含自发验算**（换无效开头仅 5%）——即 DeepSeek-R1-Zero 报告的 "aha moment"，但这里没有 RL、只有两个 token。控制实验排除了"单纯变长"的解释：有的开头让回答更长却更差；用无 cue 多数投票匹配一条 cued 回答的准确率，需要 **3.6–12 倍的 token 开销**。cue 的本质是把模型引上正确的推理轨道。

## RL 到底改了什么：主要是调高"开关"概率

三组证据层层印证：

- **策略差异集中在开头**：RL 与基础模型的逐位置 KL 散度在前两个 token 处达峰，之后几乎一致；RL 把 `.\n\nOkay` 的出现率从 0.14 推到 0.65。
- **"换头"实验**：基础模型续写 RL 的开头可达 77.7%（超过 RL 自身的 75.1%）；RL 模型续写基础模型的开头则跌回 43.7%。差距全在开头。
- **权重层面**：对 GRPO 权重增量做 SVD，主方向正向对齐 `Okay` 变体和换行符；一次不做任何 RL 的单点权重编辑就能让模型以 0.95 概率生成 cue，恢复大部分增益，C4 困惑度仅上升 0.04%。

## 因果实锤：改训练数据，造一个"鸡"开关

动机：Olmo-3-7B 中期训练数据中 83% 的合成推理 trace 以 "Okay" 开头。作者用完全一致的配方重训三个数据版本：

- **改名**（okay → chicken）：`.\n\nChicken` 从 2.4% 升到 37.2%，追平 `.\n\nOkay`；100B 完整规模重训下达 76.9%。模型并未忘记 okay，只是其自发概率暴跌到约 5×10⁻⁷；"chicken" 在普通语境下仍指鸡——cue 效应是上下文依赖的。
- **重定向**（段首 "Question:" → "Okay,"）：`.\n\nOkay` 崩到 0.2%，变成"提问题"开关。
- 同样套路可改造指令："step by step" 换成 "duck duck goose" 后，"Think duck duck goose"（17%）追平 "Think step by step"（15%）。

结论：**语义不是必须的，数据关联才是**。表征分析进一步显示，高准确率 cue 会把隐状态持续地拉向"推理 trace"类训练文档；cue 插在第 1–2 段有效（69–71%），第 3 段后反而有害（23–30%）。

## 另一面：cue 也塑造拒绝行为

安全场景下，数学 cue `.\n\nOkay` 让基础模型拒绝 81.9% 的有害请求、仅误伤 4.2% 的无害请求，选择性拒绝能力接近后训练模型；而只差标点的 ` Okay,` 却变成"顺从 cue"，有害回答率高达 42.4%。

## 局限与启示

- 结论适用于 R1-Zero 式设定；cue 高度依赖模型（Llama-3.1-8B 上找不到有效 cue），因为关联因训练数据而异。
- 启示：指令效果需用"数据关联"视角重新审视；随着合成数据占比升高，应系统盘点甚至**主动设计训练数据中的 cue-行为关联**，为能力的"可被唤起性"做工程化设计。

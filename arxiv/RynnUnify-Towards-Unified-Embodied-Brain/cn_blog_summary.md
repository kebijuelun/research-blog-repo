# RynnUnify：让视频成为机器人推理的“可检查草稿”

机器人连续做事，既要理解眼前世界，也要预测操作后的变化；RynnUnify 用一套 16B 模型打通理解、长程规划与控制，将视频嵌入推理闭环。其 Rynn-VP 总分较 Cosmos 3 Nano 高 **9.75 分**，选择性生成视频的 Agent 又将 Rynn-GEU 平均分从 **44.0 提至 50.0**。

## 核心创新：边推理，边想象

- **交错视频—语言推理**：8B 自回归 Reasoner 与 8B 视频生成器交替工作。前者输出下一子计划、世界建模描述和时长，后者预测视觉过程，再由前者读取结果、校正后续规划。
- **两种跨片段记忆**：四个稀疏参考帧保持场景外观与布局，前段视频尾部保持运动与接触状态，分别减少长任务中的遗忘与跳变。
- **三种生成模式**：支持首帧生视频（I2V）、首尾帧补全过程（FL2V）及跨片段续写；生成末帧可作为下一步的新观察。

## 关键训练：适应误差，学会选择

训练数据将“子任务—视觉提示—视频”严格对齐，覆盖通用理解、视觉规划、物理预测、空间推理和显式定位；视频生成数据去重后共 **1,083,458 个片段、1,370.1 小时**。

- **Stage 1**：训练 Reasoner，使其同时学会规划、提出视觉预测需求，以及读取真实视频作答。
- **Stage 2：Self-Forcing**：冻结 Reasoner，通过条件加噪、生成末帧替换真实起点、生成历史替换真实历史，让生成器适应自身预测误差；监督目标始终是真实未来视频。
- **Stage 3：BCPO**：对每题分别采样直接回答与生成辅助轨迹，用分支奖励学习何时调用生成器，避免无效生成带来的成本与干扰。

## 从预测画面到机器人动作

World-Action Model（WAM）以 Reasoner 的子任务 Latent 条件化生成器，再由 Action Head 读取其 **36 层视频特征**预测动作块，而非先解码完整视频再另行规划。训练使用约 **1,600 小时**原子任务和 **177 小时**复合任务轨迹，并以相机位姿监督提供几何约束。

## 结果与边界

- 基础理解十项平均 **57.9**，为 UMM 最佳，较 Cosmos 3 Nano 高 **4.7**，但未超过所有专用理解模型。
- Rynn-VP 总分 **54.80**：规划智能与视觉实现优于 Cosmos 3 Nano，画质反而由 79.69 降至 77.53，说明收益来自任务推进，而非单纯“画得更好看”。
- Agentic 推理十项 GEU 任务中七项提升，Area 从 35.9 升至 **66.2**；但位置、距离、尺寸略降，细粒度几何仍易受生成畸变影响。
- 强制其他 UMM 生成视频后，多项成绩下降，证明有效的是“会选择”，不是“多生成”。
- 仿真 Selected-20 成功率 **51.5%**；三项真机任务平均成功率 **46.7%**，最高单项完整成功率仅 55%，距离稳定实用仍有差距。

RynnUnify 的价值不在堆叠模块，而在建立“理解—预测—校正—行动”的闭环；下一步仍需降低生成成本、提高预测可信度，并验证规划得分与真实执行表现的对应关系。

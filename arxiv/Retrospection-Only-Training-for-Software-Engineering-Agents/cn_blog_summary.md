# 只训练"复盘"也能变强：ROFT 用 1/6 训练时间超过 GRPO

训练 Agent 一定要靠 RL 给动作打分吗？这篇论文给出反直觉的答案：让模型对自己的尝试写"复盘"，然后**只在复盘文本上做 SFT**，完全不监督动作、不用 reward、不用外部 teacher。这个极简方法 ROFT 在 SWE-bench Verified 上仅用 20 次更新就达到 49.2% solve rate，超过 GRPO 跑 40 次更新的 48.0%，训练时间约为后者的六分之一；更惊人的是，它能在 64 次采样全败的"不可能任务"上从零学会解题。

## 为什么需要新信号？

主流路线 RLVR（如 GRPO）的根本短板：**二值 outcome reward 说不清"哪一步错了"**。在 reward 稀疏的长程任务里，如果一组采样全部失败，组内没有对比信号，GRPO 的优势直接为零，采样等于白跑。人类则相反——我们靠复盘学习：重建经历、理解错在哪，而改变行为的正是理解。论文由此提出 **Retrospection Reinforcement (RR)**：学"解释"，用"做事"来考核。

## ROFT：四步极简循环

1. **收集经验**：Agent 尝试任务，产生轨迹和反馈，成功失败都算数。
2. **解释经验**：同一模型采样 K 条复盘——指出有后果的假设或决策、证据、修正方案、未来触发条件。
3. **只拟合解释**：对复盘 token 做普通 next-token 交叉熵训练，任务、动作、观察全部 mask 掉。
4. **用新权重继续行动**：评测时拿不到复盘文本，收益必须通过权重本身迁移。

没有动作 loss、没有 reward 加权、没有语义过滤、没有 KL 惩罚——这种"排除法"式的设计保证了：只要行为变好，功劳只能记在"用解释做训练目标"上。

## 关键结果

- **更快也更好**（基座 Qwen3.5-4B，训练集故意只选 base model 有成功有失败的题、偏袒 GRPO）：

| 方法 | 更新次数 | SWE-bench Verified | SWE-bench Pro |
|---|---|---|---|
| 基线 | — | 44.2% | 23.9% |
| GRPO | 40 | 48.0% | 25.3% |
| ROFT | 20 | **49.2%** | **29.0%** |

  ROFT 第 10 次更新、仅 1.29 小时就达 49.0%，约六分之一的训练时间拿到比 GRPO 更高的分数。与 ERL/CFT/SCFT/SSD 等基线对比 ROFT 均居首；与 GRPO 结合还能达到 50.4%。

- **从全败中冷启动**：在 base model 64 次采样全败的任务上，只用自生成复盘训练 40 次更新后，在线 solve rate 从零爬到 1.75%–3.29%，另一起点 2/64 的任务爬到 12.0%——证明学习可以在没有任何成功轨迹和 reward 对比时启动。

- **隐式信用分配**：尽管没有动作级监督，训练后正确 turn 的似然提升比例（32.41%）显著高于错误 turn（21.21%），而 GRPO 下两者几乎无差别——复盘训练通过语言解释间接实现了 RL 的信用分配。

- **复盘内容可操控行为**：把复盘 prompt 换成强调"更直接解题"，后续 rollout token 数减少 11.7%、turn 数减少 13.1%，无需任何长度惩罚。KL 分析显示变化集中在推理 token、读/搜索类工具和 rollout 前段——复盘重塑的是"怎么想、去哪找信息"。

- **消融**：最终 pass/fail verdict 可有可无；online 训练最重要（49.2% > 离线 48.0%）；每个 rollout 4 条复盘最优；9B 模型上优势依旧（58.8% vs GRPO 55.8%，训练时间 1.93h vs 5.33h）。

## 结语

ROFT 的意义在于：对长程 Agent，稀疏的最终结果几乎无法指导中间决策，而语言化的自我解释提供了一条不依赖标量 reward 的监督通道。机制上，预测复盘 token 的梯度会通过 attention 回传到动作与观察的表征上，反向塑造行为。下一个挑战是学会分辨哪些解释值得内化，避免把"听起来合理但错了"的复盘也学进去。

# Qwen3：小模型蒸馏省90%

Qwen3 的核心不是单纯扩大模型，而是让同一模型按需思考，并让轻量模型低成本继承旗舰能力。旗舰 Qwen3-235B-A22B 在 AIME'24、AIME'25 上分别取得 **85.7、81.5**，LiveCodeBench v5 达 **70.7**；8B 蒸馏实验仅用约 **1/10 GPU 小时**，效果便全面超过直接强化学习。

## 一个模型，可控地思考

- **Thinking 与 Non-thinking 统一**：前者展开长思维链处理复杂推理，后者直接快速回答；通过 `/think`、`/no_think` 或 Chat Template 动态切换，无需分别部署推理与聊天模型。
- **Thinking Budget 按需分配 Token**：达到预算后，模型基于已有推理收束作答。数学、代码和 STEM 实验显示，增加预算能带来平稳的性能提升；该能力由双模式融合自然涌现，并非额外模块。

## 数据、架构与训练协同提效

Qwen3 覆盖 0.6B 至 235B，包含 6 个 Dense 和 2 个 MoE 模型。旗舰总参数 235B、每 Token 仅激活 22B；MoE 每 Token 从 128 个专家中激活 8 个，以稀疏计算降低成本。

预训练使用 **36 万亿 Token、119 种语言和方言**，通过文档识别与精炼、合成数据、多语言扩充扩展语料，并以细粒度标签进行 Instance-level 数据配比优化。训练依次经过通用、推理强化和长上下文三阶段，结合 ABF、YARN 与 DCA，推理序列容量可扩展至训练长度的 4 倍。

## 四阶段后训练与两步蒸馏

旗舰后训练依次包括 Long-CoT 冷启动、Reasoning RL、Thinking Mode Fusion 和 General RL：先建立可验证推理，再融合双模式，最后覆盖 20 多类真实任务，强化指令遵循、偏好对齐、Agent 与 RAG 能力。Reasoning RL 中，旗舰 AIME'24 分数在 170 步内由 70.1 升至 85.1。

轻量模型无需重走完整流程：

- **Off-policy Distillation**：学习教师在两种模式下的回答。
- **On-policy Distillation**：在学生自身输出分布上对齐教师 Logits、最小化 KL 散度。

同一 8B 起点上，后者仅耗 **1,800 GPU 小时**，直接 RL 则为 **17,920**；AIME'24、AIME'25 分别达 **74.4、65.5**，高于直接 RL 的 67.6、55.5。

## 性能边界同样明确

旗舰 Thinking 模式以 DeepSeek-R1 约 60% 的激活参数、35% 的总参数，在 23 项中的 17 项领先，但并非所有指标都占优。General RL 提升通用、指令和 Agent 能力，却使部分数学、代码分数下降；长上下文检索中，额外思考也可能干扰信息提取。Qwen3 的价值因此不是“永远多想”，而是按任务选择思考方式与资源。

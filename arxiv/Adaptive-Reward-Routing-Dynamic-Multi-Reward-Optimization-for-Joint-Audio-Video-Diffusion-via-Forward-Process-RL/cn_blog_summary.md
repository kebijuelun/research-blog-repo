# Adaptive Reward Routing：让多奖励 RL 的"更新位置"和"奖励配比"随训练一起进化

音视频联合生成模型的后训练要同时优化画质、音质、文本对齐和音画同步，多奖励 RL 是主流方案，但现有方法在"梯度打在哪里"和"奖励如何权衡"两件事上都是静态的——而模型本身在持续演化。Adaptive Reward Routing 给出了动态解法：在 JavisBench 的 10 项指标中，它在 LTX-2 和 LTX-2.3 两个骨干上各拿下 9 项最优，例如 LTX-2.3 上 DeSync（越低越好）从 0.335 降至 **0.302**，视频质量 VQ 从 3.537 提升至 **3.599**。

## 两个"静态"陷阱

- **更新位置是死的**：OmniNFT 的层级路由基于基座模型一次性算好。作者探查发现，训练后跨模态"同步关键层"和梯度路径都发生了明显漂移，静态路由会过时。
- **奖励配比是死的**：GDPO 用固定权重聚合，冲突得不到适配；MARBLE 纯按梯度几何调权，会让 AV-DeSync 这类"弱但关键"的目标权重衰减到零。

## 方法核心

整体分四步：奖励重加权 → 模态分支分配 → token 级信用分配 → 层级梯度路由。

- **跨模态影响力探针**：直接用前向过程已有的 pre-gate cross-attention 响应范数作为影响力代理，零额外前向开销。
- **Token 级路由**：响应强的 token 获得更高的损失权重（音频全局归一化，视频帧内归一化）。
- **层级软 detach**：$\widetilde X = \alpha\,\mathrm{sg}(X)+(1-\alpha)X$，前向值完全不变，反向梯度被缩放为 $1-\alpha$——影响力强的层保留梯度，弱耦合层逐渐断开，不引入分布漂移。
- **偏好保持的重加权**：用户先验权重打底提供非零下限，分支内 MARBLE 冲突系数经 warm-up 和指数平滑后做残差修正，既适配冲突又不吞掉弱目标。

## 实验与验证

- **主结果**：GDPO 提升画质却恶化同步（DeSync 0.604→0.671），暴露了固定配比的失衡；本文方法在两个骨干上 10 项指标各 9 项最优，且各目标趋势一致。
- **消融**：token 加权、层缩放、分支感知、残差修正、warm-up 各组件均有效且互补，完整配置取得最强整体平衡。
- **机制验证**（全文最扎实的部分）：
  - 影响力代理与直接干预的层排序 Spearman 相关达 **0.98**（A2V）/ **0.97**（V2A）；
  - 实时重算的代理全程保持 **0.96+**，而冻结代理跌到 **0.56 / 0.38**——量化证明了"静态路由会过时"；
  - 屏蔽 top 10% 高分 token 造成的预测变化是随机组的 **1.62 / 1.74 倍**。

## 总结

这项工作把多奖励后训练重新表述为动态信用分配问题：反馈不应按固定配方路由，而应随模型能力的成长持续重组。局限在于依赖模态 token 可分的双流架构，对表示不可分的模型仍是开放问题。

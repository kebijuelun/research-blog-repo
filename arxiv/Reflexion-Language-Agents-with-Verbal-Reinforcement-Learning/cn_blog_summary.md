# Reflexion：让大模型靠"写检讨"自我进化

大模型 Agent 会决策、会写代码，却不会从失败中学习，而梯度更新对千亿参数模型代价过高。NeurIPS 2023 的 Reflexion 不动权重：失败后让模型用语言写一份"反思"存入记忆，带着教训重试。效果惊人：HumanEval pass@1 达 **91%**（GPT-4 单跑仅 80%），AlfWorld 提升 **22%**，HotPotQA 提升 **20%**。

## 核心方法

此前 Agent 只有 in-context examples 一种学习手段，失败不留教训，同样的错反复犯。Reflexion 的独特定位：**把稀疏的环境奖励"放大"为自然语言经验，跨 trial 存入持久记忆**。三个模块：

- **Actor**：LLM 策略模型（CoT 或 ReAct），生成动作；
- **Evaluator**：给轨迹打分——推理用 exact match，决策用启发式规则；
- **Self-Reflection**：框架灵魂，把"success/fail"转成具体、可执行的口头反馈。

记忆分两层：短期是当前 trial 的轨迹，长期是跨 trial 的反思（保留 1~3 条）。策略参数写作 $\theta = \{M_a, mem\}$——被"优化"的不是权重而是记忆，相当于把"梯度"语义化：LLM 读轨迹后直接指出哪步错了、下次怎么改，信息量大且天然可解释。

## 实验亮点

- **AlfWorld**（134 个文本家务任务）：12 轮完成 130 个，纯 ReAct 第 6~7 轮后停滞；基线高发的"物品幻觉"几乎被根除。
- **HotPotQA**：Reflexion 逐轮提升，纯 CoT/ReAct 零改进；消融显示语言反思比只塞入上轮轨迹再多约 8%——关键不是"记得"，而是"想明白了"。
- **编程**：用自生成单元测试评估，不碰隐藏测试，保住 pass@1 资格；唯一未超 GPT-4 的是 MBPP Python，因自写测试假阳性率达 16.3%（HumanEval 仅 1.4%），错解"骗过"测试被提前提交。
- **关键消融**（Rust 最难 50 题）：裸跑 0.60；盲目反思 0.52（好代码被改坏）；无反思试错 0.60；完整方案 0.68——"测试反馈 + 语言反思"缺一不可。

## 边界与影响

自我纠错是大模型的涌现能力：弱模型上几乎无增益，模型越强增益越大。失败案例也诚实：WebShop 这类需高多样性探索的任务跳不出局部最优，4 轮毫无起色。Reflexion 几乎定义了此后 Agent 自我改进的基本范式——"把经验写成文字"至今仍是 Agent 记忆系统设计的核心思想。

# Planning to Learn：把训练预算规划进损失函数

分类任务没有探索、信用分配和采样噪声这些强化学习的经典难题，可精确优化期望准确率的策略梯度依然惨败于交叉熵：ImageNet ResNet-50 上两者分别为 4.2% 和 62%。Google DeepMind 的这篇论文给出的解释是：梯度是短视的，只算"这一步买什么"，看不到"训练还剩多少预算"。据此提出的 horizon loss 只需改动一行代码，在 ImageNet 恒定学习率下提升 top-1 准确率 1.0–2.4 个点，50% 标签噪声时提升高达 7.3 个点。

## 核心发现：交叉熵与精确策略梯度的差距只在"权重"

- 分类中期望准确率的精确梯度与交叉熵负梯度**方向完全相同**，区别仅在加权力度：前者按 $p(1-p)$ 加权，后者按 $1-p$ 加权（$p$ 为当前样本成功概率）。
- 既然优化的就是目标本身还输了，传统"光滑凸代理"的解释说不通——问题出在**预算分配**：一步更新的价值取决于训练还剩多少。容易样本（$p=0.9$）短期收益大，困难样本（$p=0.01$）长期回报大，最优策略随剩余预算反转。

## 方法：horizon loss

- 把"剩余 $H$ 单位学习内要支付的总误差"积分起来：$H\to\infty$ 时恰等于交叉熵（"耐心准确率"，按无限预算定价）；$H\to 0$ 时退化为精确策略梯度。
- 有限 $H$ 归一化后得到 horizon loss，其负梯度因子化为：**剩余误差 × 在剩余预算内成功的概率**，即 $\sigma(z+H)(1-\sigma(z))$，$z$ 为 logit gap。
- 实现上只需用剩余学习率之和乘以校准常数 $\kappa$ 估计 horizon（ImageNet 恒定学习率下 $\kappa=3$，只校一次），$H_t$ 随训练线性收缩，损失自然从交叉熵平滑滑向精确策略梯度。

## 理论与实验

- **两个陷阱**：精确策略梯度陷入"抛光陷阱"（分不清"已经会了"和"还来得及救"，收益随难度指数消失）；交叉熵陷入"绝症陷阱"（权重最大的恰恰是最没希望的样本）。horizon loss 的权重在两个极端都趋零，遗憾随干扰项移出 horizon 指数缩小。
- **实验结果**（同一 recipe 只换损失函数）：
  - ResNet-50 期望准确率：精确策略梯度 4.2% → 交叉熵 62.1% → horizon loss **67.5%**；ResNet-101、ViT-S/16 同样全部获胜。
  - 标签噪声越大收益越大：top-1 收益从 10% 噪声时的 3.3 点单调升到 50% 噪声时的 7.3 点——噪声样本随 horizon 收缩变成"绝症"，交叉熵继续背诵，horizon loss 学会放手。
  - 收益集中在训练尾部（符合理论：前期 $H$ 远大于样本 gap，horizon loss 几乎等于交叉熵），且**只有收缩的 horizon 有效**，任何固定 $H$ 都无法复制收益；focal loss 等静态难度加权全部更差。
- **规划算子可推广到任意目标**：$P_H[\ell](z)=\int_0^H \ell(z+s)\,ds$ 作用于交叉熵得到 horizon cross-entropy，把 ImageNet 测试 NLL 从 1.467 降到 1.364。收益是目标专属的——想让哪个指标好，就规划哪个目标。

## 一句话总结

交叉熵是无限预算的准确率，精确策略梯度是零预算的准确率，horizon loss 按真实剩余预算在两者之间插值——在真实 RL 后训练中如何"按剩余预算规划"，是接下来的开放问题。

# REAL：无偏优化接受长度，让投机解码对齐提速目标

投机解码的速度取决于草稿 Token 能被目标模型接受多少，但 CE、KL、TV 等常用 Loss 并未直接优化这一目标。REAL 用无偏的真实期望接受长度（EAL）估计对齐训练与提速：在 9 个任务子集、5 个随机种子的概率服务实验中，平均接受长度达到 **4.792**，高于其他对比目标的 **4.657–4.749**；Rao–Blackwellization（RB）还将聚合梯度方差降低 **52%–58%**。

## WTV 的问题：分支权重错了，梯度也会反转

- 单步接受率为 $a_i=\sum_v\min(p_i(v),q_i(v))=1-\mathrm{TV}(p_i,q_i)$，但多步接受不是边际接受率的简单连乘：被接受的 Token 会决定后续验证走哪条分支。
- WTV 先按目标分布平均后续接受率，再与前序接受率相乘，漏掉了真实的“提出—接受”路径依赖。两步窗口下，REAL 与 WTV 的差恰好是路径权重和后续接受率的协方差，可正可负。
- 论文构造的反例中，真实目标为 $J_2=0.86+0.20\theta$，WTV 却为 $1.02-0.12\theta$：两者在 $\theta=0.5$ 时数值同为 0.96，梯度却分别为 $+0.20$ 和 $-0.12$。这说明有偏替代目标即使方差更低，也可能稳定地走向错误方向。

## REAL 的方法：无偏估计，再条件边际化降方差

- **路径估计器**：复用目标模型采样轨迹，在已采样 Token 上计算 $b_i=\min(1,q_i/p_i)$，累乘为 $W_k$；$\widehat J_{\mathrm{Path}}=\sum_kW_k$ 无需枚举指数级路径，且对真实 EAL 无偏。
- **分支估计器**：将每项最后一个随机因子 $b_k$ 换成条件均值 $a_k$，得到 $\widehat J_{\mathrm{Branch}}=\sum_kW_{k-1}a_k$。这一步 RB 保持期望及期望梯度不变，同时降低逐项梯度方差。
- **可训练 Loss**：最终目标以 0.9 权重优化归一化分支 EAL，以 0.1 权重保留辅助 CE；路径权重 $W$ 与接受重叠 $a$ 都参与反向传播。它只替换训练 Loss，不改草稿架构、训练流水线或推理过程。

## 实验结论：收益跨任务成立，但有适用边界

实验冻结 Qwen3.6-35B-A3B 目标模型，统一 Domino 草稿架构、数据、优化器和训练预算，只比较 Loss。概率服务中，REAL 相对 WTV 的平均 AL 提升 **0.077**，9 个子集的最高值均由 REAL 或其无 RB 版本取得；REAL 吞吐达 **4662.0 tokens/s**，与无 RB 版本的 4664.8 位居前两名。提升主要来自更长接受前缀，而非只改善第一个 Token。

RB 未必提高最终概率 AL（4.792 对 4.791），主要价值是降低方差、改善早期训练与跨设置稳定性；去掉辅助 CE 则会明显掉点。REAL 面向随机拒绝采样，低温时优势收窄，$T=0.5$ 及 greedy 服务中 static LK 更强，不能将概率服务收益无条件外推到确定性解码。

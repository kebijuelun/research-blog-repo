# SFT Replay：无需奖励复现 RL 训练全程

RL 后训练生成的 rollouts 往往用完即弃，而这项研究证明：只要保存带训练顺序的全部回答，从同一 Base Model 出发按序做普通 SFT，无需奖励、筛选或重新采样，就能恢复在线 RL 的学习轨迹与最终能力。Qwen3-1.7B 在 MATH-500 上的轨迹误差仅 **0.002**、终点误差仅 **0.004**；甚至只用最后一步 4096 条 rollouts 中的 **2048** 条，pass@1 就达到 **0.708**，几乎追平在线 MaxRL 的 **0.709**。

- **为什么不能直接重放 RL？** 归档数据来自原在线策略，重放策略却会因浮点与优化误差逐渐漂移。此时 baseline 项不再归零，形成“偏离数据策略—更新偏差—进一步偏离”的反馈，最终导致 Offline RL Replay 崩溃。重要性采样和分数居中只能推迟失稳，无法消除持续增长的分布漂移。
- **SFT 重放为何有效？** 对每个归档批次的所有 response token 做最大似然训练，不看 reward，也不区分回答对错。学生一旦偏离，下一批数据仍会把它拉向当前数据生成分布，而非放大误差。理想情况下，每次更新都直接逼近对应阶段的在线策略。
- **顺序本身就是训练资产。** 正序重放跟随完整学习曲线，逆序会退回早期策略，随机打乱则停在较低水平；因此归档不能只保存一堆无时间戳回答，必须保留 step index。
- **只要终点能力，可大幅缩短归档。** Qwen3-1.7B 只用最后一步数据即可恢复 MATH-500、AIME25 和 KnK，终点误差分别为 **0.007、0.008、0.009**。但窗口需求因任务而异：SmolLM2-360M 在 GSM8K 上需最后 **50** 步才弥补大部分差距；小数据子集靠延长训练也无法弥补信息不足。

实验结论不限于 MaxRL，也适用于 GRPO、RLOO，并覆盖 Qwen3-1.7B/4B、SmolLM2、多个语言推理任务，以及迷宫和 ImageNet。迷宫中，完整轨迹 SFT 的 pass@1 为 **0.238**，接近在线的 **0.252**；最后 10 步可达 **0.247**。ImageNet 上 SFT 的 pass@1 为 **0.56**、在线为 **0.60**，但从 pass@16 起差距不超过 **0.01**。

归档还支持两类复用：

- **数据空间组合专家**：交替或联合学习数学与 KnK 专家的同期 rollouts，可同时跟随两条训练曲线；最后一步 SFT 也接近双专家交点，整体优于权重平均、Task Arithmetic 和 TIES-Merging。任务配比应按 token 数避免长度偏置，但实验中进一步的 1:1 与 2:1 调整差异不显著。
- **跨模型迁移**：Qwen3-1.7B 的旧 rollouts 用于训练 Qwen3-0.6B，效果接近从最终教师重新采样蒸馏，却无需增加教师推理成本。

这项工作的核心启示是：**在线 RL 负责通过探索与奖励发现更好的采样分布，事后 SFT 可以低成本学习已被记录的分布。** 它并不意味着 RL 可被完全替代；没有在线探索，就不会产生越来越好的 rollouts。当前验证最多覆盖 4B 模型，且存储与离线训练并非零成本，更大规模的可扩展性及能否借此超越原在线训练仍待研究。

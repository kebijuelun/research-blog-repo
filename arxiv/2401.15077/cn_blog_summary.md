# EAGLE 精华总结：特征外推让 LLM 推理无损提速 3 倍

LLM 自回归解码一次前向传播只产出一个 token，推理又慢又贵；投机采样想破局，却被草稿模型的质量和训练成本卡住。EAGLE 给出了一个反直觉的答案：草稿模型不该预测 token，而应在"特征层"做自回归外推——最终在 LLaMA2-Chat 70B 上实现 **2.7x-3.5x 延迟加速、吞吐量翻倍**，且输出分布理论上与原模型完全一致，加速是无损的。

## 两个关键观察

- **特征比 token 更好学**：token 是离散符号，表达千变万化；特征（LM Head 前的隐藏状态）是模型消化后的连续语义表示，规律性更强。Vicuna 7B 上特征级草稿加速比 1.9x，token 级只有 1.5x。
- **采样随机性是隐藏天花板**：目标 LLM 先出分布再采样 token，同一个特征之后可能分叉到完全不同的后续特征，草稿模型无从预知。Medusa 直接拿特征预测 token 也踩了同样的坑，接受率只有约 0.6。

EAGLE 的解法极简：**把前移一个时间步的 token 序列也喂给草稿模型**——采样结果已经确定性地写在 token 里，歧义彻底消除，代价几乎为零。仅这一个改动（不加任何复杂度），Vicuna 7B 加速比就从 1.9x 提到约 2.8x，草稿准确率约 0.8。

## 方法：轻到离谱的草稿模型

草稿模型只有三个模块，其中两个直接复用目标 LLM 并冻结：

- **Embedding 层、LM Head**：复用目标 LLM 参数，不训练；
- **自回归头**：唯一训练部分，仅一个 FC 层 + 一个 Transformer Decoder 层。

前向过程：特征序列与前移一步的 token 序列拼接融合，FC 压回维度，Decoder 预测下一个特征，冻结的 LM Head 出分布并采样，再拼回输入继续自回归。训练用 Smooth L1 回归损失 + 交叉熵分类损失（权重 0.1）；训练时给特征加均匀分布噪声，抵抗误差累积。

**训练成本极低**：70B 模型的可训练参数不到 1B（0.99B），4 张 A100 训 1-2 天；7B/13B/33B 单张 RTX 3090 即可完成。对训练数据不敏感——直接用 ShareGPT 的 6.8 万条固定数据集，与用目标 LLM 自生成数据的效果几乎一样（2.78x vs 2.88x）。

验证阶段采用**树状草稿**：借助树注意力，3 次前向传播可展开 10 个 token 的草稿树，配合多轮投机采样递归验证，严格保证输出分布一致。

## 实验结果

- **MT-bench（greedy）全面领先**：Vicuna 7B/13B/33B 为 2.90x/3.07x/2.95x，LLaMA2-Chat 7B/13B/70B 为 2.78x/3.03x/3.01x；对比 Medusa 约 1.9x、Lookahead 约 1.5x、DistillSpec（70B）仅 2.13x。
- **代码任务加速最高**：HumanEval 上 LLaMA2-Chat 13B 达 **3.76x**，平均接受长度 τ 达 4.52——目标模型每次前向传播平均产出 3-4 个 token。
- **非 greedy 同样有效**：T=1 下加速比 2.13x-2.68x，仍大幅领先基线。
- **接受率稳健**：0-α（特征完全准确时）约 0.75-0.79，1-α 到 4-α 变化很小，证明噪声增强训练让模型对误差累积不敏感。
- **正交可叠加**：与 gpt-fast（量化+编译）结合后，LLaMA2-Chat 7B 在单张 RTX 3090 上达 **160.4 tokens/s**；batch 场景下吞吐量约提升 2 倍。
- **消融验证**：树注意力贡献约 0.3-0.5 加速比（锦上添花）；去掉 shifted-token 则性能大跌（核心竞争力所在）。

局限也明确：MoE 模型（Mixtral 8x7B）上仅 1.5x，因验证阶段需读更多专家权重，稀释了访存优势；batch size 增大时加速比下降。草稿树结构也未做严格优化。

这条"特征外推"路线后来演化为 EAGLE-2/3 系列，成为无损推理加速的主流范式之一。

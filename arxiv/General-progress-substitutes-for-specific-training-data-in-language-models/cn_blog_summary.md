# Progress Substitutes：通用进步让被删技能低成本回归

数据过滤究竟能永久删除能力，还是只推迟能力出现？这篇论文证明，模型从其余语料获得的通用进步可以替代部分专项监督，因此过滤不等于后续恢复依然昂贵：国际象棋中被删技能最低只需从头训练 Token 的 **0.10%–0.78%** 即可恢复；7B 模型关闭一半 Rust 术语准确率差距，也只需参考训练量的 **2.1%**。

## 把输入与专项监督分开

- 核心工具 **Target thinning**：完整保留所有输入，只让比例 $f$ 的技能目标进入 Loss，其余目标被掩蔽，从而隔离专项答案监督的作用；整局、整篇文档过滤也得到一致结论。
- 用留出集 **背景 Loss** 衡量通用进步，在相同背景下比较技能水平，定义过滤造成的 **Onset delay**。实验覆盖国际象棋、Othello、SMILES、Dyck 与 Web 文本，模型最大 7B。
- 论文以完整监督 $f=1$ 和从未监督 $f=0$ 两个端点预测中间状态，引入 **Corpus support $\tau$** 衡量其余语料的贡献，有效监督为 $(f+\tau)/(1+\tau)$。

## 延迟可预测，但缺口不一定缩小

国际象棋王安全和 7B 首都回忆可由两个端点无参数推出中间保留比例；15 个 9.7M 稀疏化模型的 300 个点，预测 RMSE 仅 **0.039 Logit**。只用不超过 431M 的模型即可预测 1.28B、3.0B；用 60M–1B Web 模型预测 7B 六项技能，平均误差 **0.058 nats**。

不过，$\tau$ 会随训练下降，专项监督带来的领先增长更快，所以过滤模型与完整模型的差距可能扩大。过滤买到的是可量化的时间，而非能力永久归零。

## 快速恢复来自已有基础

从未见过将军的模型虽已学会棋子移动和合法候选排序，却缺少“必须处理将军”的约束：其概率最高的合法应对有 **0.64** 是实际对局走法，完整监督模型为 **0.68**，随机仅约 **0.30**。目标回归后，少量监督主要补上缺失规则，而非重学全部结构。SMILES 中，真实环闭合数字概率从 **0.0004** 在仅 2 个优化器步骤后升至 **0.36**，12 步后达 **0.60**。

恢复成本随 **Logit 盈余**指数下降：国际象棋和 Web 文本每增加 1 Logit 盈余约便宜 **10 倍**，SMILES 约便宜 **4 倍**。在 207 个恢复前分数接近地板的实验中，Logit 距离对同领域成本配对的排序正确率为 **85%**，当前技能分数仅 **53%**，说明静态低分不代表没有学习准备。

## 对过滤与 Unlearning 的启示

- 恢复节省具有技能专项性：从头学习难度相当的置换规则成本相近，但从相同 Checkpoint 恢复却需真实规则的 **2.4–16 倍** Token。
- 从未学会与学会后移除并不等价：国际象棋中，前者恢复需后者的 **5–20 倍** Token；早期仅 **3%** 监督也能显著降低后续成本。
- 只训练较上层 Block 或使用秩 4、16 的 LoRA，仍保留原始恢复节省的 **59%–96%**，但恢复依赖已有表示，不存在随处有效的通用权重补丁。
- Rust 的 2.1% 特指恢复后新增 Token；若计入过滤期间残留 Rust 数据，口径会更保守。论文并未证明过滤无效，而是否定了“删数据即可永久删除能力或保证重学同样昂贵”的假设。

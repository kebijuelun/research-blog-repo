# Qwen2.5：72B对标405B

Qwen2.5 的核心不是继续堆参数，而是用数据、训练与推理链路的协同升级，同时提升通用能力、专业推理、指令遵循和长文本体验。最亮眼的结果是：72B-Instruct 在多项基准上比肩约 5 倍参数的 Llama-3.1-405B-Instruct；Turbo 支持 100 万 tokens 上下文，1M passkey 检索准确率达 100%。

## 模型与训练底座

- 开放权重模型覆盖 **0.5B 至 72B**，另有面向成本与效率的 MoE 模型 Turbo、Plus；最大生成长度从 2K 提升至 8K tokens。
- 预训练数据由 Qwen2 的 7 万亿扩展到 **18 万亿 tokens**。升级重点不只是加量，还包括用 Qwen2-Instruct 过滤质量、前置引入数学与代码数据、以生成器和奖励模型筛选合成数据，并下采样电商、社交等过度代表领域，上采样科技与学术内容。
- Scaling Law 不只用于选择模型和数据规模，还用于预测最佳 Batch Size 与学习率，并反推 MoE 达到目标 Dense 模型效果所需的总参数与激活参数。

## 后训练：可验证信号驱动对齐

- 超过 **100 万条 SFT 样本**覆盖长文本、数学、代码、指令遵循、结构化数据、逻辑推理、多语言、系统提示鲁棒性和响应过滤九类能力。代码经静态检查与单元测试筛选，指令遵循也借助执行反馈验证。
- 离线 DPO 使用约 **15 万个偏好对**，重点优化数学、代码等“有客观答案、通用奖励模型却难可靠评价”的任务；在线 GRPO 每个查询采样 8 个回答，优先训练奖励方差大的查询，以获取更明确的偏好信号。
- Turbo 采用“长 SFT、短 RL”：长指令微调增强长文遵循能力，RL 仍用短指令，避开高昂计算与不可靠的长文奖励信号。

## 长上下文与实测结论

普通模型先以 4K 训练、末段扩至 32K；Turbo 分四阶段扩至 262K，再通过 YARN 与 DCA 外推 4 倍至 **1M tokens**。基于 MInference 的稀疏注意力将 1M 序列的注意力计算量降低 **12.5 倍**，首 token 延迟加速 **3.2—4.3 倍**。

72B-Instruct 的 MATH 达 83.1，LiveCodeBench 以 **55.5 对 41.6**、Arena-Hard 以 **81.2 对 69.3** 超过 405B；但 MMLU-Pro、GPQA、GSM8K、HumanEval 仍由后者领先，因此“对标”并非全面碾压。其 RULER 平均分为 95.1，128K 得分 88.4；移除 DCA+YARN 后降至 67.0，验证了外推模块的贡献。

Qwen2.5 的真正升级是整条训练链路，同时仍留下文化理解、奖励模型评估与长上下文 RL 等开放问题。

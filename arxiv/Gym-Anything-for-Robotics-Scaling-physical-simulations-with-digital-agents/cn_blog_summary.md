# Gym-Anything：让 AI 自建并审计物理仿真

液体、布料、切割和化学反应仍高度依赖专家手工建模，卡住了机器人仿真的规模化。Gym-Anything 把“编写物理”交给 Coding Agent，再由独立 Agent 反复审计修复；由此建成的 RoboWorld 包含 **25 个仿真、200 个 RL 环境**，而三种前沿模型在 25 个测试任务上的成功率**全部为 0%**。

## 从真实工作反推仿真

- **按价值选题**：付费工作使用 O*NET 的 1,016 个职业、18,796 条任务描述，按就业与工资估值；日常生活使用 ATUS 的 465 类活动，按全美投入时间估值，避免漏掉做饭、清洁和照护。
- **按能力覆盖建设**：LLM 将任务拆成“倒入液体”“拧紧螺栓”等原子动作，只有物理状态、接触顺序和完成条件兼容时才归为同一 Action Group。这样优化的是可复用的机器人与物理能力，而非任务名称数量。流程选出 120 个 Action Group，本论文完成其中 25 个。

## 核心方法：生成之后，对抗审计物理

Creation Agent 先研究真实设备、材料与机制，再实现物理并提交视频、测量、辅助示范和报告；所有变化都必须有物理原因，不能用动画、吸附或脚本结局冒充。

- **仿真审计**：每轮由 4 个独立 Audit Agent 检查真实性、动力学与可解性、速度与配置、鲁棒性，同一 Creation Agent 修复，完整执行 3 轮。审计要求最慢不超过实时的 200 倍，并用对抗命令寻找穿透、能量爆炸等缺陷。
- **任务审计**：任务 Agent 只能修改指令、Verifier 和布景，不能降低物理难度；6 个独立 Agent 分别检查意义、场景、验收正确性、可解性、奖励和难度，最多修复 3 轮。最终形成 25 个测试环境、175 个训练环境，均带确定性 Verifier 与连续奖励。

笔者认为，关键资产不是“一次生成”的能力，而是可执行、可复现、能持续纠错的证据链。

## 实验：物理可解，不等于模型会做

GPT-6 Astra、GPT-6.1 Terra 和 Claude Opus 5.5 只能使用相机与机器人反馈，在 25 个测试任务上全部零成功，说明真实物理工作远未解决。但仿真的 Privileged State 能转化为学习信号：Opus 独立反复尝试时，平均奖励从 0.14 升至 0.22；读取真实状态的 Teacher 则从 0.34 升至 0.41。

作者进一步验证教师提示、自我迁移和 Code Policy 示范。后者由特权 Agent 编写普通控制程序，在 2,048 个变化初始状态上取得 96.7% 成功率，再以 1,000 条成功示范训练 $\pi_{0.5}$：两个礼盒任务的成功率从 **0% 提升到 53%**，未见变化上为 **55%**，执行速度约为逐步控制 Opus 的 **14 倍**。

当前边界也很清楚：只完成计划中的 25/120 个仿真，VLA 实验仅覆盖两个礼盒任务，尚无真实机器人迁移验证。下一步需要检验这条“自动建物理—审计—学习”链路能否走向真实硬件。

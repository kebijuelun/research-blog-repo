# OpenVLA：开源通用机器人操作新标杆（精华总结）

机器人策略"出了训练数据就不会动"是老大难问题，而视觉-语言-动作模型（VLA）的代表作 RT-2-X 闭源、且无人系统研究过 VLA 如何微调和部署。OpenVLA 一举解决这两大痛点：**7B 参数、完全开源**，参数量仅为闭源 RT-2-X（55B）的 1/7，却在 29 个任务上以 **16.5% 绝对成功率反超**；同时首次验证 LoRA 微调和 4-bit 量化几乎不掉性能——单张消费级 GPU 即可运行。

## 核心方法

- **架构**：基于 Prismatic-7B VLM——SigLIP + DinoV2 双视觉编码器（语义 + 空间特征）、2 层 MLP 投影器、Llama 2 7B 主干；把机器人动作离散化为 token，用"下一个词预测"输出 7 维动作。
- **关键改进**：动作分桶用第 1–99 分位数而非 min-max，避免离群值浪费离散精度；直接覆盖词表中 256 个低频 token 承载动作。
- **数据**：Open X-Embodiment 清洗出 970k 条真实机器人轨迹（统一输入输出空间 + 平衡配比）；并修复了 Bridge 数据首帧全零动作的陷阱。

## 五条反直觉的设计经验

- VLM 主干选 Prismatic（比 LLaVA 高约 10%）；图像分辨率 224×224 足够，384 无收益但训练慢 3 倍。
- 视觉编码器**必须微调**（与 VLM 领域经验相反）；训练需 27 个 epoch（远超 LLM 惯例的 1–2 个）；学习率 2e-5 固定即可。

## 关键结果

- **零样本泛化**：BridgeData V2 上成功率 70.6%，大幅领先 RT-2-X（50.6%）、Octo（20.0%）；Google robot 上 85.0% vs RT-2-X 的 78.3%。
- **微调适配**：Franka 环境平均 67.2%，是唯一所有任务成功率 ≥50% 的方法，比从零训练的 Diffusion Policy 高约 20 个百分点；多指令任务上优势更明显。
- **LoRA 微调**：只训 **1.4% 参数**（r=32）即追平全量微调（68.2% vs 69.7%），单张 A100 10–15 小时完成，省 8 倍算力。
- **量化推理**：4-bit 显存降至 **7GB** 且性能不掉（71.9% vs bf16 的 71.3%）；有趣的是 int8 掉点并非精度损失，而是推理变慢（1.2Hz）破坏了系统动力学——"慢比糙更致命"。
- **消融**：去掉 OpenX 大规模预训练，成功率暴跌 30 个百分点——数据多样性是泛化的根本来源。

## 成本与开源

64 张 A100 训练 14 天；RTX 4090 上约 6Hz 推理。模型权重、PyTorch 训练/微调代码、远程推理服务器全部开源。

**局限**：仅单图输入、6Hz 不足以驱动 50Hz 双臂系统、多数任务成功率仍低于 90%。action chunking、投机解码、多模态扩展等开放问题，正待社区在这个开源基座上继续探索。

# Voyager：自动课程与代码技能库驱动开放探索

Voyager 让大语言模型驱动的智能体无需人工持续干预，便能在《Minecraft》中不断探索、学习并积累可迁移技能，将一次性计划转化为终身学习能力。它在 160 次提示迭代内发现 **63 种物品，是基线的 3.3 倍**；科技树关键里程碑解锁速度最高达到基线的 **15.3 倍**。

## 核心创新：把模型知识沉淀为可执行经验

Voyager 不更新 GPT-4 参数，也不进行微调，而是以代码作为动作空间，通过 Prompt 和上下文学习形成“自动出题—生成程序—执行纠错—验证入库”的闭环。相比底层动作，程序既能表达长程行为，也能调用旧技能完成更复杂的任务。

- **自动课程**：GPT-4 根据物品栏、装备、环境、位置及历史成败，动态提出难度适中、可完成且可验证的新任务，而非执行固定科技树清单。课程信息还随进度逐步加入，避免早期信息过载。
- **代码技能库**：验证通过的程序连同描述入库，以描述 Embedding 建立向量索引。面对新任务，系统检索 Top-5 相关技能供代码生成复用和组合，使经验可解释、可迁移，并缓解灾难性遗忘。
- **迭代提示**：动作 Agent 在 MineDojo 中执行 JavaScript 程序，最多进行 4 轮生成与修正。环境反馈指出计划与现实的差距，解释器错误暴露程序问题，GPT-4 Critic 则判定任务是否真正完成，并在失败时给出改进建议。

## 实验结论：探索更远，能力链更长

- **持续探索**：Voyager 能不断发现新物品和技能，而 ReAct、Reflexion 等基线较难在开放目标下持续推进；其移动距离达到基线的 **2.3 倍**，覆盖更多地貌。
- **科技树突破**：木、石、铁工具解锁速度分别为基线的 **15.3、8.5、6.4 倍**，并且是唯一解锁钻石工具的方法。不过钻石工具仅在 3 次试验中成功 1 次，尚非稳定能力。
- **零样本迁移**：清空物品栏并进入新世界后，完整 Voyager 在钻石镐、金剑、岩浆桶和指南针四项未见任务上均 **3/3 成功**，平均分别只需 19、18、21、18 次提示；移除技能库后，钻石镐仅 2/3 成功。技能库加入 AutoGPT 后也能帮助其完成部分任务，说明它是可插拔资产。

消融进一步证明性能来自整套闭环：随机课程使发现物品数下降 **93%**，移除自我验证后下降 **73%**；移除技能库会使后期探索更易停滞。将代码生成模型换成 GPT-3.5 后，GPT-4 版本发现的物品数是其 **5.7 倍**，显示代码能力仍是硬约束。技能检索的 Top-5 准确率达到 **96.5%**。

## 边界与意义

Voyager 使用高层 Mineflayer API，而非从像素直接输出键鼠动作；实验所用 GPT-4 也仅支持文本，三维建造示例依赖人工反馈，不能视为自主视觉能力。它仍面临较高 API 成本、Critic 误判和模型幻觉。其核心贡献因此不是替代感知与底层控制，而是提供一套可组合的高层终身学习框架：让探索成果不止停留在一次对话中，而成为下一次学习可调用的资产。

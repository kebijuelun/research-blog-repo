# PaLM-E：统一感知、问答与机器人规划

大语言模型会推理却看不见现场，视觉模型会答题却未必能安排行动，这一接地断层阻碍 AI 走向物理世界。PaLM-E 将图像、机器人状态等连续信号直接嵌入语言 Token 空间，让同一模型完成感知、问答和机器人规划：TAMP 低数据任务上，ViT-4B 的两项规划成功率从 30.6%／32.9% 提升至 74.1%／74.6%；PaLM-E-562B 还在无需任务专用微调的情况下取得 OK-VQA 66.1 分。

## 多模态句子：给语言模型接入“感官”

PaLM-E 的核心不是另造机器人推理语言，而是把传感器读数翻译成语言模型熟悉的向量：

- 文本 Token 经嵌入层进入语言空间；图像和状态则由 ViT、MLP 或 OSRT 等编码器投影到同一空间。
- 两种向量交错成“多模态句子”，图像可出现在句子的任意语义位置，也可自然组合多图和多种传感器。
- 模型始终自回归生成文本：既可直接回答问题，也可输出“抓起绿色物体”等高层技能，再由低层策略转换成电机动作。

因此，PaLM-E 是组织技能、拆解长程任务的高层策略，而非直接输出关节力矩的控制器。执行后，新图像回到模型，支持继续执行、失败检测或重新规划。

## 对象表示与联合训练：两条能力来源

统一接口之后，输入结构决定模型能否理解物理关系。除通用 ViT 外，PaLM-E 还使用状态向量、对象中心表示和 OSRT（对象场景表示 Transformer）。OSRT 从多视图图像无监督发现对象槽，提供 3D 与对象结构；实体标签则把视觉对象与语言指代绑定，减少“拿起红色方块”这类歧义。

更关键的是跨任务联合训练：完整混合数据中，具身数据仅占 8.9%，其余主要是视觉语言数据。互联网图像提供语义先验，不同机器人数据补足行动与几何知识，能力得以相互迁移。

- 每项 TAMP 规划任务仅有 320 条样本时，ViT-4B 经联合训练后两项成功率均翻倍以上。
- OSRT 分别达到 82.5% 和 76.2%，说明极少数据下，对象与 3D 结构的归纳偏置同样重要。
- 移动操作中，联合训练将 affordance（技能是否可执行）F1 从单机器人预训练方案的 0.78 提至 0.87；解冻 LLM 后达 0.91。

## 一个模型，不必牺牲通用能力

同一个 PaLM-E-562B checkpoint 除 OK-VQA 66.1 外，还取得 VQAv2 test-dev 80.0、COCO CIDEr 138.7，并展现零样本多图推理与多模态 Chain-of-Thought。不过 PaLI 在 VQAv2、COCO 上仍更高，PaLM-E 的优势是统一能力，而非全面领先。

多模态训练仍会造成语言遗忘，但规模能显著缓解：NLG 平均表现相对降幅从小模型的 87.3% 缩至最大模型的约 3.9%，冻结 LLM 则可保留原语言能力。

PaLM-E 的真正贡献是“统一接口＋正向迁移”。下一步仍需结合更可靠的 3D 表示、可验证的闭环规划与更低成本模型；现阶段它还依赖外部低层策略，部分实验也使用真值状态或掩码。

# Spark-0：触觉教视觉看懂接触

机器人看见杯子，不等于能稳稳拿起它：滑移、夹持力和柔顺形变常被手指遮挡，这正是高自由度灵巧手走向真实家务与精细装配的障碍。Spark-0 让触觉在训练时当“老师”、部署时按需当“传感器”；依托 1,000 小时 HumanTouch，Ego Humanoid 纯视觉平均成功率由 52.45% 升至 71.72%，SparkArena-Real 达 52.00%，领先最强触觉基线 FTP-1 16 个百分点。

## 核心方法：把触觉拆成两条路

- **数据先行。** HumanTouch 让操作者佩戴可穿戴装置直接采集，无需机器人在场，覆盖 100 余项任务、32 名操作者，以 60 Hz 同步记录多视角视频、手部姿态和双手触觉。每手屏蔽 140 个弯折噪声点，保留 320 个有效 taxel；人与机器人使用同款手套，天然共享触觉接口。
- **训练时教视觉。** Spark-0 用 Depth-Anything-3 几何特征和触觉生成的接触热图，对齐 Qwen3-VL 第 25 层视觉 Token，分别学习“结构是什么”和“接触在哪里”。教师与预测头推理时移除，因此没有触觉也能受益。
- **部署时助控制。** 区域力历史编码约 333 ms 的压力演化，当前 3D taxel 编码空间接触，共形成 24 个触觉 Token，只接入 flow-matching Action Expert。缺失触觉时以可学习占位符替代，同一 checkpoint 可切换纯视觉与触觉控制。
- **统一动作生成。** 模型将七源异构数据重定向到双手 58 维状态/动作空间，Action Expert 从三帧状态预测 50 步动作块，兼顾人类示范、真机与仿真数据。

## 实验：最强证据来自同算力对照

Visual PT 与 1000H 使用相同 RGB 数据和预训练算力，只删除触觉及其派生监督，因而两者之差更能隔离触觉预训练的贡献。

- **SparkArena-Sim（纯视觉）**：平均成功率 36.86%，较最强基线 FastWAM 高 8.57 个百分点。
- **Ego Humanoid（纯视觉、未见人形本体）**：平均成功率 71.72%，较 Visual PT 高 19.27 个百分点，八项汇总指标全部第一；长时序 seen/unseen 成功率优势扩大至 18.52/22.12 个百分点。
- **SparkArena-Real（在线触觉）**：平均成功率 52.00%、完成分数 62.80，较 FTP-1 分别高 16.00 和 15.00 点。
- **规模并非单调。** 100H 并未在 Sim 和 Real 超过 Visual PT；完整 1000H 才在三项基准上同时取得各变体最佳成功率。

## 结论与边界

Spark-0 的关键不是简单增加传感器，而是证明触觉能成为可规模化的视觉运动预训练监督，并兼顾在线精细控制。其局限也清晰：真机评测未单独隔离在线触觉贡献，组件级消融和多次运行方差缺失，0/100/1,000 小时三个锚点也不足以宣称 Scaling Law。跨传感器迁移与更完整消融，将决定“用触觉教视觉”能否成为通用范式。

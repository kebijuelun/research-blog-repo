# 蒸馏的散度选择，其实是一个隐含的"熵旋钮"

蒸馏早已是大模型训练的核心组件，但"换一个散度到底改变了什么"长期只有模糊直觉。这篇 Stanford 的工作给出干净答案：**散度是学生模型熵的隐含调节器**。最硬的两个结果：Forward KL 训练下，学生平均熵 = 教师熵 + 残差 KL 散度，是精确恒等式；推论是**收敛预训练模型的平均熵恰好等于训练 loss**，在 OLMo 2（1B–32B）和 Pythia 全系列上被定量验证。

## 核心创新：解耦两个自由度

- 蒸馏通常从序列级目标推导，这把两件事锁死在一起：**数据从哪来**（采样分布 $p$）和**用什么散度**（$\ell$）。序列级 Reverse KL 强制 on-policy，Forward KL 强制 off-policy。
- 把目标写在 token 级，两者彻底解耦、自由组合。这个分解是全文地基——也揭示了一个陷阱：从序列级 Reverse KL"推导"on-policy 蒸馏，会被迫继承 Reverse KL，而这可能正是熵坍缩的根源。

## 关键理论结果

- **散度只在"学生配不上教师"时才重要**：所有 $f$-divergence 在 $\pi_\theta = \pi^*$ 附近共享 Fisher 度规，学生能完美复现教师时，换散度不改变训练动力学。
- **Forward KL 必然抬熵**：驻点上学生平均熵 = 教师熵 + 残差 KL，证明靠沿"温度方向"扰动的驻点条件。交叉熵训练 = 以数据为隐式教师的 Forward KL 蒸馏，故**模型平均熵 = 训练 loss**——大模型 loss 低，熵也低；拟合不好不是过度自信，而是向数据支撑集外漏概率质量。
- **Reverse KL 压熵是有条件的**：学生还能模仿教师时压熵；上下文过多或教师太弥散时，负熵项占上风，反转为抬熵。附录证明在"弥散 + 高负载"极限下所有散度退化为同一个 Fisher 加权最小二乘投影，熵缺口可显式算出。
- **JS 插值族**：训练早期熵随插值权重 $\lambda$ 平滑变化，收敛时却在临界 $\lambda$ 附近相变式跳变。top-$k$ 截断（谁选 top-$k$、尾部重归一化还是 tail bucket）也实质改变熵——它不是免费近似，本身就是熵调节手段。

## 大规模实验验证

- **预训练 / SFT**：OLMo 2 和 Pythia 各尺寸模型精确落在"熵 = 交叉熵"对角线上（在最后训练过的数据上成立；SFT 会破坏预训练数据上的恒等关系）。
- **On-policy 蒸馏**：$2\times2$ 消融（散度 × 采样，Qwen3 教师蒸入 Qwen3-0.6B-Base，12 组实验）表明**散度主导熵的方向**——Forward 抬、Reverse 压；on-policy 采样反而轻微抬熵，效应只有散度的 1/2 到 1/3；教师尺寸几乎无关。on-policy 蒸馏的低熵，锅在绑定的 token 级 Reverse KL，不在采样。
- **自蒸馏**：教师来自学生，熵损失会代际正反馈成熵坍缩。最优超参数恰好都是"对冲熵下降"的配置：偏 Forward 的散度、EMA 教师（live teacher 直接坍缩）、tail bucket。越压熵的配置能容忍的学习率越小；只要熵不坍缩，各配置精度只差几个百分点。

## 一句话总结

选散度应当像选温度一样，是一个有意识的正则化决策——它是独立于采样方式的**熵旋钮**。

# Speculative Decoding：投机采样让大模型推理提速 3 倍

大模型推理的死穴是自回归串行解码——生成 K 个 token 就要跑 K 次模型。Google Research 这篇 ICML 2023 论文提出 **Speculative Decoding（投机解码）**：用小"草稿模型"先猜多个 token，大模型**并行**验证，且有严格数学证明保证**输出分布与大模型完全一致**——不改架构、不重训练、不改输出。T5-XXL（11B）上实测加速 **2X–3X**（argmax 下最高 3.4X），输出逐 token 相同。

## 核心思路

- 目标模型 $M_p$（分布 $p(x)$）又大又慢；近似模型 $M_q$（分布 $q(x)$）便宜得多。
- 关键观察：大模型推理瓶颈常在**内存带宽而非算力**——算力闲置，那就"用并发换延迟"。
- 每轮三步：$M_q$ 自回归猜 $\gamma$ 个 token → $M_p$ 把所有前缀拼成 batch 一次并行验证 → 按接受/拒绝规则收下一部分并补采一个 token。每轮至少产出 1 个、最多 $\gamma+1$ 个 token，最坏也不比标准解码差。

## Speculative Sampling：分布严格不变的接受规则

从 $q$ 采出 $x$ 后：若 $q(x) \le p(x)$ 直接接受；否则以 $1 - p(x)/q(x)$ 拒绝，并从残差分布 $p'(x) = \text{norm}(\max(0, p(x)-q(x)))$ 补采。直觉：小模型高估的概率按比例打回，拒绝后从"$p$ 比 $q$ 多出的质量"里精确补齐。五行公式即可证明接受与补采的贡献恰好拼回 $p(x)$ 本身。它比经典拒绝采样更优：不需要全局常数，接受率更高，且拒绝后不浪费大模型调用。

## 理论：能加速多少

- **接受率**有闭式解：$\beta = \sum_x \min(p(x), q(x))$——两个分布重合越多，接受率越高。记 $\alpha = E(\beta)$。
- **单轮期望产出**：$\frac{1-\alpha^{\gamma+1}}{1-\alpha}$ 个 token。
- **墙钟加速**（$c$ 为小模型/大模型单次成本比，通常 < 0.05）：$\frac{1-\alpha^{\gamma+1}}{(1-\alpha)(\gamma c + 1)}$。推论：**只要 $\alpha > c$ 就必有加速**。
- 代价是总运算量上升，但**内存访问量反而下降**——权重和 KV cache 每轮只读一次，这正是带宽受限场景的收益来源。
- 理想情形（$c=0$）下，$\alpha=0.9$、$\gamma=10$ 可加速 6.86X，运算量仅增 60%。

## 实验：零训练的实测加速

T5-XXL（11B）作 $M_p$，直接用现成 T5-large/base/small 作 $M_q$，单张 TPU-v4、batch 1：

- 英德翻译：argmax 下最高 **3.4X**（T5-small，$\alpha=0.75$），temp=1 下 2.6X；
- CNN/DM 摘要：argmax 下最高 **3.1X**，temp=1 下 2.3X；
- 最小的 T5-small（77M）反而加速最高——$c$ 最低，印证 $\alpha$ 与 $c$ 的权衡理论；
- 理论公式预测与实测高度吻合，部署前用 $c$ 和 $\alpha$ 即可估算收益。

草稿模型选择完全是工程自由度：连 bigram、复制启发式这类**零成本草稿**都有效（bigram 在翻译上 $\alpha\approx0.2$，配 $\gamma=3$ 也有 1.25X 加速）。若愿意放松分布不变性（Lenience 参数 $l$），加速可达 5X，且任何 token 概率不超真实值的 $1/l$ 倍。

## 意义与局限

这是首个把投机执行推广到一般随机采样、并给出严格分布一致性保证的方案，开创了"用并发换延迟"的推理加速范式（DeepMind 随后在 Chinchilla 70B 上独立复现 2X–2.5X）。局限也很明确：它消耗更多总算力，只适合算力富余、带宽受限的低延迟场景；算力紧张时帮不上忙。

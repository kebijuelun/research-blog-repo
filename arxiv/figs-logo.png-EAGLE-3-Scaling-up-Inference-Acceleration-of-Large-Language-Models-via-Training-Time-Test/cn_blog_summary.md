# EAGLE-3：训练时测试带来 6.5 倍解码加速

大语言模型逐 Token 生成的延迟，正被长链推理进一步放大；EAGLE-3 通过“多层特征融合 + Training-Time Test”让草稿模型直接学习预测 Token，最高实现 **6.5 倍加速**，相对 EAGLE-2 的延迟加速约提升 **1.4 倍**，在 SGLang、batch size 为 64 时吞吐量仍提高 **38%**。

## 瓶颈：特征模仿限制了数据扩展

投机采样让小模型先猜、大模型并行验收，在不改变目标模型输出分布的前提下减少串行解码。EAGLE 复用目标模型的顶层特征提高草稿接受率，但增加训练数据后，加速收益很快饱和。

原因在于其特征预测 Loss 强迫草稿模型逼近目标模型特征，而预测 Token 才是最终目的。直接删除该约束也不够：第一步可能更准，后续步骤却要读取模型自己的输出，训练与推理的输入分布随之失配，多步接受率明显下降。

## 方法：取消对齐，并在训练中适应自身输出

- **融合低、中、高层特征**：不再只使用偏向“下一 Token”的顶层信息，而是拼接三层特征，经全连接层压缩后输入草稿模型，为多步预测提供更丰富的语义信息。
- **Training-Time Test（训练时测试）**：训练中实际生成草稿向量，再把它回传给后续步骤，只计算 Token 预测 Loss，使模型提前经历真实推理的输入分布。配合分支感知的 Attention Mask，多条草稿路径不会互看见，同时保留并行训练效率。
- **保留动态草稿树与严格验证**：EAGLE-3 沿用 EAGLE-2 的树扩展和剪枝机制，目标模型仍按 Speculative Sampling 规则验收，因此加速不以改变输出分布为代价。

这两项改造相互依赖：取消特征对齐后，输入才能从单一顶层扩展到多层；训练时回传自身输出，则解决了第二步以后的分布失配。

## 结果：接受率、扩展性与吞吐同步提升

- **数据扩展持续有效**：LLaMA-Instruct 3.1 8B 在 MT-bench 上，训练数据扩大至 8 倍时，EAGLE-3 的加速比由约 **3.70×** 升至 **4.40×**，平均接受长度由约 **5.2** 增至 **6.1**；EAGLE-2 则基本饱和。
- **多步预测更稳定**：输入中的自预测值逐步增加时，EAGLE 接受率从约 0.71 降至 0.51—0.53，EAGLE-3 始终约为 **0.78—0.81**。
- **跨任务、跨模型成立**：实验覆盖五类任务和四种目标模型，整体较普通解码加速约 **3.0—6.5 倍**，较 EAGLE-2 提升约 **20%—40%**。
- **大 batch 仍有收益**：EAGLE 在 SGLang 的 batch size 24 起已降低吞吐，EAGLE-3 到 64 仍保持 **1.38×**；单请求吞吐达到 **373.25 tokens/s**，高于无投机采样的 158.34 tokens/s。

EAGLE-3 的关键不是简单删去一个 Loss，而是把草稿模型从“模仿目标特征”转向“学会连续起草”，展示了通过增加训练数据持续提升解码效率的路径。其趋势能否扩展到 405B、671B 等更大模型，仍待验证。

# RURL：纯仿真强化学习，真实机器人成功率60%

RURL 让开放权重推理模型无需演示数据、感知工具或运动规划器，便能直接操控真实机器人，为通用推理能力走向物理操作提供了新路径。最终模型在未见过的真实双臂 YAM 上成功 **18/30 次（60%）**，基座模型为 **0/30**；LIBERO 成功率则从 **1.6% 提升至 74.4%**。

## 核心方法：把电脑操作 RL 迁移到机器人

- **统一交互闭环。**模型每轮读取相机画面与机械臂状态，生成推理过程，再输出末端执行器位姿变化；逆运动学和控制器负责执行。更换机器人时无需重新训练，只需修改接口中的部件、坐标系等具身描述。
- **只靠任务成功奖励。**仿真器在 episode 结束前报告成功则奖励为 1，否则为 0。RURL 使用 GRPO 组归一化优势，并结合 DAPO group filter 与 score centering，处理全失败组无梯度和异步训练中的策略错配，不使用 PPO clipping、KL penalty 或 entropy bonus。
- **课程学习打开奖励信号。**先训练已能产生成功样本的 LIBERO Goal、Spatial 和 Object，再加入原本几乎全失败的 LIBERO-Long，最后迁移到 RoboDojo 两个任务。未训练 Long 时，模型已零样本达到 39.0%，基座仅 0.4%。
- **PEAR 支撑长上下文训练。**通过全异步 rollout、前缀 KV cache、FSDP、序列并行等技术，将平均约 94k token、19.7 轮的完整 episode 用于 RL，最长序列达 256k token，前缀缓存命中率超过 95%。

## 实验：提升不止发生在训练任务

- **LIBERO 接近前沿模型。**74.4% 超过 GPT-6.1 Sol 和 GPT-6 Astra 的 medium effort 结果（48.1%、49.3%），接近其 max effort 的 76.2%、80.6%，但 Goal 和 Long 仍落后。
- **任务与布局变化时更鲁棒。**面对同场景的新指令，RURL 成功率为 57.4%，演示监督微调的 $\pi_{0.5}$ 仅 0.75%；交换物体位置后分别为 57.5% 和 20.8%。但在原动作仍适用的指令改写、外观变化上，$\pi_{0.5}$ 更强。
- **跨基准与真实机器人迁移。**未见过的 RoboLab-120 上，最终模型达到 37.3%，基座为 5.4%；复杂任务仍只有 13.2%。真实 YAM 的成功完全来自仿真训练，没有使用真实机器人数据。
- **通用能力未见显著退化。**九项数学、编程、视觉与多模态评测的变化区间均包含 0，平均分仅由 81.64 变为 81.49；这表示未测得显著退化，并非证明能力绝对不变。

## 局限与边界

RURL 仍受长推理、上下文和成本制约：low effort 下 LIBERO 仅 21.9%，xhigh 才达到 74.4%；即使单张 GB300 达到 747 token/s，一轮 xhigh 推理仍约需 4.3 秒。完整 RoboDojo 中有 68.5% 的 episode 因耗尽 256k 上下文而失败，训练还消耗约 50,000 个 H100 等效 GPU 小时。此外，系统依赖详细提示词、外部逆运动学与控制器，目前也只验证了少量仿真任务和一个 27B 基座。

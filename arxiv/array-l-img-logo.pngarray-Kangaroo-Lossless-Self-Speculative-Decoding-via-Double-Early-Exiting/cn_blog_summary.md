# Kangaroo：双早退自投机解码，最高1.68倍加速

大语言模型自回归解码常受显存带宽限制，传统投机解码又需额外训练草稿模型，部署成本不低。Kangaroo 复用目标 LLM 的固定浅层子网，只训练轻量 Adapter，并在草稿 token 置信度不足时提前停止生成，从而降低草稿成本且不改变目标模型的采样分布。在 V100、单序列验证下，它在 Spec-Bench 上最高取得 $1.68\times$ 加速，新增参数较 Medusa-1 减少 88.7%。

## 核心思路：不仅猜得准，还要猜得便宜

投机解码采用“先猜、再验”：草稿模型连续生成候选 token，目标大模型并行验证，一次前向可产出多个新 token。但端到端速度同时取决于接受率、草稿延迟和验证收益，高接受率并不等于高加速。

论文因此提出 CTAR（一致 token 接受率），衡量长度为 $w$ 的候选窗口被全部接受的概率，以补充 CR（压缩率）只能反映平均接受数量的不足。实验也表明，接受率接近的方法可能因草稿效率不同而获得不同的实际速度。

## 关键方法：把 early exiting 用两次

- **深度早退**：将目标模型前 $l$ 层作为固定浅层子网，后接轻量 Adapter，并共享目标模型的 LM Head，构成自草稿模型。Adapter 仅含一个 Multi-Head Attention 和两个 Normalization Layer，通过 Cross-Entropy Loss 学习浅层表示到深层表示的映射，无需独立训练大模型骨干。
- **长度早退**：每个草稿位置检查 top-1 confidence；当其不高于阈值 $\eta$ 时，停止继续生成候选。简单片段可以多猜，困难位置则尽早交给大模型，减少低收益计算。
- **无损验证**：提前结束的是候选生成，而非绕过目标模型直接输出。所有候选仍由目标模型剩余层验证，因此保持原有采样分布。

这一设计的聪明之处，是尽量复用大模型已经完成的浅层计算与部分 KV cache，只补齐浅层和深层之间缺少的映射。

## 实验结果：更快，也更省参数

实验基于 Vicuna-7B/13B，在 NVIDIA V100 上对比 Lookahead、Medusa 和 REST：

- **整体加速最高**：Vicuna-7B 平均加速 $1.50\times$，高于 REST 的 $1.43\times$、Medusa 的 $1.41\times$ 和 Lookahead 的 $1.29\times$；Vicuna-13B 平均加速 $1.44\times$，同样领先。
- **单任务峰值**：7B 在 MT Bench 上达到 $1.68\times$；13B 在 MT Bench 和 Math 上分别达到 $1.66\times$、$1.63\times$。但它并非全面领先，Translation 上 Medusa 更快，QA 上 REST 更快。
- **Adapter 越轻越有效**：67M 参数的版本取得 $1.50\times$ 平均加速，参数量仅为 Medusa Head 的 11.3%；增加独立 Head 或改用完整 Transformer 层，参数更多，速度反而下降。
- **动态草稿优于盲目增加步数**：固定步数虽能获得最高 CR，却并非速度最优。论文最终采用 $\gamma=6$、$\eta=0.6$，通过删除低收益草稿计算提升端到端速度。

## 总结

Kangaroo 以“浅层共享生成草稿、深层并行完成验证”为核心，用双重早退同时控制模型深度和草稿长度，在保持输出分布的同时兼顾接受率与草稿成本。其局限是退出层和置信度阈值仍需按模型调节，现有验证也限于 Vicuna-7B/13B、V100 和单序列场景；面向更多模型、硬件与批量场景，并自动选择超参数，是后续值得探索的方向。

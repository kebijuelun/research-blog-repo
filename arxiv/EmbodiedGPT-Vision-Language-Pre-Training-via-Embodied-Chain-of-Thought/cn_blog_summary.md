# EmbodiedGPT：用思维链规划闭环驱动机器人控制

多模态大模型往往“会描述、会规划，却不会控制”，EmbodiedGPT 用思维链把视觉理解、任务分解和低层动作连成闭环，同时降低具身数据标注与大模型训练成本。仅用 **25 条专家演示**，它在 Franka Kitchen 和 Meta-World 上的平均成功率分别达到 **58.5%** 和 **81.2%**。

## 核心创新：规划不只输出，还反向指导视觉

- **EgoCOT 数据集**：从 Ego4D 第一人称视频出发，清洗后保留约 **2.9 千小时视频、385 万条旁白**。作者按旁白时间戳切分动作片段，用 ChatGPT 将简短描述扩写为分步规划及“动词—名词”动作序列，再以 CLIP 视频—文本相似度从每个视频的 5 个候选中筛选规划，并结合人工核验，避免生成内容脱离视觉证据。
- **EgoVQA 数据集**：围绕旁白中的核心动词和名词，为每条旁白生成 5 组问答，补充第一人称人机交互视频问答数据。
- **统一四类能力**：模型同时支持视频描述、多轮问答、具身规划和低层控制，而不是将多个视觉、语言工具简单串联，减少上游描述错误向下游传递的问题。

## 关键方法：冻结主干，打通“规划—特征—动作”

EmbodiedGPT 整体约 **10B**，采用冻结的 EVA-CLIP ViT-G/14 和 LLaMA-7B。可学习的 Embodied-former 通过 embodied query 与视觉、文本 token 交互，形成紧凑的任务相关表示，再投影为 LLaMA 的“软视觉提示”，避免更新整套视觉语言参数。

其闭环设计是：语言模型生成规划后，规划再次作为 Embodied-former 的查询条件，从视觉输入中提取当前子目标所需的实例级特征；随后与 ResNet50 提供的全局上下文合并，由轻量 MLP 策略网络输出连续动作。这样，“抓住门把手”不再只是文字，而会成为选择视觉特征的依据。

训练分三阶段推进：

1. 用 COCO、筛选后的 CC3M 和 BLIP-2 重标注的 LAION-400M 数据完成图像—文本对齐。
2. 用复杂推理与多轮对话数据提升推理能力。
3. 用 EgoCOT 视频学习时序信息、CoT 规划和结构化动作，并通过 prefix tuning 低成本适配冻结的 LLaMA。

## 实验结论：CoT 与闭环缺一不可

- **规划质量**：30 名参与者的人评中，EmbodiedGPT 的空间关系理解得分 **8.8**、冗余度 **2.6**（越低越好）、规划合理性 **8.8**、可执行性 **8.4**；其 7B 语言模型的物体识别得分 8.4，接近 LLaVA-13B 的 8.5。
- **少样本控制**：10 条演示时，两个基准成功率已达 **50.8%** 和 **76.4%**；增至 25 条后达到 58.5% 和 81.2%，相较在 Ego4D 上微调的 BLIP-2，成功率分别提升至其 **1.6 倍**和 **1.3 倍**。
- **消融验证**：25 条演示下，移除规划到控制的闭环，两个基准分别下降 **11.2** 和 **16.3** 个百分点；移除 EgoCOT 思维链训练，则均下降 **22.1** 和 **22.5** 个百分点，说明收益既来自闭环架构，也来自任务分解能力。

这项工作的价值在于用结构化规划连接高层语义与低层控制，而非单纯扩大模型。其局限是视觉和语言主干因计算资源限制而冻结，Virtual-Home、提示词对比等部分能力仍只有定性案例，真实机器人和更多任务上的泛化仍待验证。

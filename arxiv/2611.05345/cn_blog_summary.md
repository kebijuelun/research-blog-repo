# Adversarial Speculation：主动拒绝提升长程推理

长程编程 Agent 的早期关键决策会在数百轮交互中逐渐“走样”，而常被当作纯加速器的投机解码，竟会通过 Token 在验证块中的位置改变 KV Cache 的数值精度。Adversarial Speculative Reasoning 让草稿模型在决策点主动提出应被拒绝的方案，迫使目标模型从低噪声块首重新采样；DeepSWE 上，GLM-5.3-NVFP4 成功率从 60.6% 升至 67.6%，DeepSeek-V4.1-Flash 从 67.8% 升至 71.8%。

## 核心发现：分布不变，精度会变

投机解码由草稿模型提议多个 Token，目标模型整块验证；精确拒绝采样保证输出仍服从目标模型分布，却不保证实际部署中的数值路径一致。低精度权重、量化 KV Cache 和稀疏 Attention 等机制，会让后续位置继承同一块内此前 KV 项的舍入变化。

- **块内噪声可控**：两个模型的噪声均随位置每后移一个 slot 约增加 4%。GLM 的末位噪声比首位高 34%，偏移超过 3 nats 的比例从 1.1% 增至 2.1%。
- **影响跨越长轨迹**：固定 Token 序列、仅改变写入方式后，验证写入路径约在 30 轮后出现 10%～20% 的极端偏差增量，主要集中在超过 4 nats 的尾部，而非所有上下文普遍变差。

这意味着“被拒绝”不只是加速失败，也能成为控制关键决策写入精度的开关。

## 关键方法：反向训练草稿模型

作者用目标模型自身作为 Judge，定位确认观察、陈述下一步并正式决策的“承诺句”，再构造决策前逐 Token 相同、决策后走向不同行为的 Fork Pairs，避免无关差异污染训练信号。

- **反向 DPO**：对 GLM，草稿偏好猜测、保守或更简单的非优选决策；对 DeepSeek，则偏好“不运行测试”。目标模型更可能拒绝这些提议，经残差采样写下优选决策，并把它放到新块的 slot 0。
- **窗口化优化**：只训练决策附近的 Token，常规文本仍保持高接受率；目标模型权重和精确验证规则完全不变。
- **系统改动很小**：仅训练目标加草稿系统 0.06%～0.28% 的参数。草稿无需判断答案对错，只需学会在正确位置制造分歧。

## 实验结论：收益真实，但有边界

在数百轮、上下文超过 200k Token 的长程编程实验中，每种配置独立运行 5 次：

- GLM 在 DeepSWE 提升 **7.0 个百分点**，95% CI 为 $[2.6,11.4]$；在 NL2Repo-Bench 从 49.1% 升至 55.0%。
- DeepSeek 在 DeepSWE 提升 **4.0 个百分点**，但置信区间跨 0；在 NL2Repo-Bench 提升 1.4 个百分点，95% CI 为 $[0.4,2.4]$。
- 正向偏好反而使两者在 DeepSWE 分别下降 4.9 和 1.4 个百分点；三类无关偏好合并后为 67.5%，与普通草稿的 67.8% 无显著差异，支持“拒绝位置”而非“任意训练”带来收益。
- 效率代价最高约 2%：GLM 的期望接受长度不变，DeepSeek 从 2.50 降至 2.46。

笔者认为，这项工作的价值是把草稿模型从“模仿目标模型的加速器”变成“上下文精度调度器”。但它只重分配精度，不增强目标模型的语义判断；偏好也需针对各模型的真实失败模式设计，能否推广到更多硬件、量化方式与 Agent 场景仍待验证。

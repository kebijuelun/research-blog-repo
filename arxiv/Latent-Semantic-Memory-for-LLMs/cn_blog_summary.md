# Memorilla：16枚记忆替代长上下文

Memorilla 解决冻结 LLM 利用聊天历史、长文档和智能体轨迹时“全部塞回上下文既昂贵又未必更准”的问题，让模型按查询读取整个文档集合，却只接收固定记忆；它在 FactKG 上以少 108 倍的文档 Token 取得 84.33% 准确率，高于 Full Context 的 80.43%，并在八项基准上以 49.68 的最高平均分将文档 Token 几何平均减少 394 倍。

## 核心创新：按查询读取全库，只交付 16 枚记忆

- **外部持久记忆**：文档由冻结 Encoder 编码一次，向量长期复用；新增或变化的文档才需重新编码。
- **查询条件化检索**：可学习 slots 先对查询向量做 Cross-Attention，再通过 Perceiver 风格模块连续关注全部文档，而非离散截取 top-$k$ 文本。
- **直接注入冻结 LLM**：默认 $K=16$ 的检索结果经线性投影成为 soft memory tokens，拼在文本查询嵌入之前，无需修改模型层或 Attention。
- **训练与模型解耦**：只优化记忆模块及投影参数，默认使用冻结 Qwen3-Embedding-4B 和 Qwen3-8B；三阶段课程依次进行 Wikipedia 释义重构、多任务预训练和八基准混合微调。

## 更少上下文，平均表现反而更好

Memorilla 在 21 项指标中有 20 项超过 Full Context，说明无关 Token 会稀释证据，完整上下文并非性能上界。TriviaQA 的 EM 达 57.00，PMv2 短答准确率达 44.60%，显著高于最强基线 xRAG 的 30.90%。它尤其擅长跨文档组合：FactKG 需要组合 4 项事实时，比 RAG-50 高 34.00 个百分点。

它并非全面胜出：PubMedQA 仅得 59.00%，低于 LLMLingua-2 的 69.00%；NarrativeQA 的 ROUGE-L 也落后于 MemoRAG。压缩更偏向全局结构、因果关系和隐式偏好，却容易丢失精确实体与原文细节，因此更自然的方向是与文本 RAG 互补。

## 从问答到智能体

TextWorld 中，系统保留完整文本轨迹，仅通过 GRPO 环境奖励训练记忆模块，冻结智能体的 avg@3 从 18.6% 提升至 24.2%，pass@3 从 25.0% 提升至 37.5%，正常终止回合从 29% 增至 42%。这证明学习到的状态表示能改善决策，但不能证明 8 枚向量已能取代完整历史或解决长期规划。

效率优势主要随集合扩大而显现：512 篇文档时，Memorilla 端到端延迟为 0.739 秒，Full Context 为 19.932 秒，约快 27 倍。其边界仍包括细粒度信息损失、跨模型迁移未验证，以及嵌入仍需隐私保护。

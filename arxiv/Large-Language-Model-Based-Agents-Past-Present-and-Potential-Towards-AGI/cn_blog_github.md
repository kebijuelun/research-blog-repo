# 复旦NLP长篇综述：LLM智能体的前世今生，以及它离AGI还有多远

当 ChatGPT 掀起大模型浪潮之后，"让 LLM 长出眼睛、手和记忆，变成一个能自主干活的智能体（Agent）"成了 AI 社区最炙手可热的方向。这篇来自复旦 NLP 团队的重磅综述系统地回答了一个问题：基于大语言模型的智能体从哪里来、现在长什么样、又将走向何方。文章的核心思路是提出一个"大脑（Brain）— 感知（Perception）— 行动（Action）"三位一体的通用框架，并以此为骨架梳理了单智能体、多智能体、人机协作乃至"智能体社会"的完整图景。从 World Scope 的五个层级来看，纯 LLM 只停留在"互联网文本"层级，而升级为 Agent 后有望一路打通感知、具身乃至社会层级——这正是它被视为通往 AGI 潜在路径的原因。

## 一、背景：Agent 从何而来，LLM 凭什么当"大脑"

### 从哲学到 AI：Agent 概念的三次漂流

"Agent"（智能体/能动者）并不是 AI 社区凭空造出来的词。早在亚里士多德和休谟的时代，哲学家们就在讨论"能动性（Agency）"：一个有欲望、信念、意图并能采取行动的实体，就是 Agent。18 世纪狄德罗甚至说过一句很前卫的话——"如果一只鹦鹉能回答所有问题，我会毫不犹豫地称它为智慧生物"。1950 年代，图灵把这个思想延伸到了机器身上，提出了著名的图灵测试。

当这个概念被引入计算机科学后，含义发生了微妙的偏移。哲学上的 Agent 可以是人、动物甚至抽象实体，而 AI 领域的 Agent 被具体化为一个**计算实体**：它通过传感器感知环境，做出决策，再通过执行器对环境采取行动。由于"意识""欲望"这类概念对机器而言过于玄学，AI 研究者（包括图灵本人）主张暂时搁置"机器是否真的在思考"的问题，转用四个可观察的属性来刻画 Agent：**自主性（Autonomy）、反应性（Reactivity）、主动性（Pro-activeness）和社会能力（Social Ability）**。这四点在后面会成为判断"LLM 是否适合做 Agent 大脑"的标尺。

### 五代技术浪潮：一条不断逼近"通用"的演化曲线

文章把 Agent 研究的技术演进梳理成五个阶段，每一代都在弥补上一代的短板：

| 阶段 | 核心思路 | 代表 | 主要短板 |
| --- | --- | --- | --- |
| 符号智能体 | 用逻辑规则和符号表示做推理 | 专家系统 | 难以处理不确定性和大规模问题，推理效率低 |
| 反应式智能体 | 感知-行动循环，快速实时响应 | Brooks 的包容架构 | 缺乏高层规划能力 |
| 强化学习智能体 | 与环境交互，最大化累积奖励 | AlphaGo、DQN | 训练成本高、样本效率低、迁移困难 |
| 迁移/元学习智能体 | "学会学习"，加速新任务适应 | MAML 等 | 任务差异大时会出现负迁移，仍需大量预训练 |
| LLM 智能体 | LLM 作大脑 + 多模态感知 + 工具使用 | AutoGPT、Voyager 等 | 新兴方向，仍在快速演化中 |

这张表背后的逻辑很清晰：**过去的瓶颈不在算法，而在"模型本身不够强"**。符号方法有可解释的推理却没有常识，强化学习有交互能力却学不动世界知识。社区真正缺的，是一个自带知识记忆、长期规划、高效泛化和自然交互能力的通用基础模型——而 LLM 恰好补上了这块拼图。

### 为什么 LLM 适合做 Agent 的大脑

回到前面提到的四大属性，文章逐条论证了 LLM 与它们的对应关系：

- **自主性**：像 AutoGPT 这样，只给一个目标和一组可用工具，LLM 就能自己拆解任务、制定计划并执行，无需逐步人工指令，甚至能产出未被显式编程过的创意。
- **反应性**：通过多模态融合扩展感知空间、通过工具使用和具身技术扩展行动空间后，LLM 可以对环境的即时变化做出响应。虽然"先想后动"的中间推理步骤会拖慢速度，但这恰恰符合人类"三思而后行"的行为模式。
- **主动性**：一句"Let's think step by step"就能激发 LLM 的逻辑与数学推理；目标重构、任务分解、随环境反馈调整计划等规划能力也已涌现。
- **社会能力**：自然语言是最天然、最可解释的通信协议，LLM 借此可以扮演不同角色、协作竞争，甚至在群体中涌现出社会现象。

值得一提的是 Bisk 等人提出的 World Scope（WS）框架：从语料库、互联网、感知、具身到社会共五个层级。纯 LLM 困在第二级（互联网文本的输入输出）；把它升级为 Agent、配上感知和行动空间，就有机会够到第三、第四级；再让多个 Agent 协作竞争形成社会，则有望触达第五级。

## 二、智能体的诞生：大脑、感知、行动三位一体

弄清了"为什么是 LLM"，接下来的问题就是"怎么搭"。受达尔文"适者生存"的启发——个体要生存就必须认知、感知并响应环境——文章提出了 LLM 智能体的通用概念框架，由三个模块组成：**大脑**是控制中心，负责记忆、思考与决策；**感知**对应人类的感官，把多模态信息转成大脑能理解的表示；**行动**对应四肢，执行动作并改变环境。整个工作流是循环的：感知环境 → 大脑决策 → 行动执行 → 接收反馈 → 再感知。框架可按需裁剪，不是所有组件在每个应用里都会出现。

### 大脑：智能体的中枢

大脑模块主要由 LLM 构成，文章从五个维度拆解了它的工作机制。

**自然语言交互。** 语言背后藏着说话者的信念、欲望和意图，理解这些"言外之意"是高效沟通的前提。LLM 的多轮对话能力分三步走：理解对话历史、决定采取什么行动、生成自然语言回复。对于模糊指令，一种思路是把隐含意义形式化为奖励函数，让 Agent 在 unseen 场景中也能选出符合说话者偏好的行为。

**知识。** LLM 在海量语料上预训练后，把三类知识编码进了参数：语言知识（语法语义，支撑对话）、常识知识（"下雨要打伞"这类不显式出现在文本里的世界事实）、专业领域知识（编程、数学、医学等）。但知识也有两个老毛病：一是会过时或本身就是错的，重训成本高且会导致灾难性遗忘，因此出现了"模型编辑"这类定点修改知识的技术；二是幻觉——生成与事实冲突的内容，目前的缓解手段包括幻觉度量和借助外部工具校验。

**记忆。** 记忆存储 Agent 过去的观察、思考和行动序列。随着交互轮次增多，两大挑战浮现：历史记录超出 Transformer 的上下文长度限制，以及从海量记忆中提取相关条目越来越难。增强记忆能力有三条路线——抬高上下文长度上限（文本截断、分段、改进注意力机制）、总结记忆（反思式摘要、层级摘要）、用向量或数据结构压缩记忆（embedding、三元组，甚至像 ChatDB 那样直接接 SQL 数据库）。检索方面，代表性的方案是自动按**新近度（Recency）、相关性（Relevance）、重要性（Importance）**三个指标的加权打分来挑选记忆；也有工作让用户交互式地查看、编辑、删除记忆对象。

**推理与规划。** 推理方面，Chain-of-Thought（CoT）通过让模型先输出推理过程再给出答案来激发推理能力，后续又有 Self-Consistency、Self-Refine 等增强策略。规划则分两阶段：**计划制定**有一次性全局分解、边做边想的自适应分解、层级规划、树状搜索（如 ToT）等路线，遇到需要专业知识的任务还可以外接领域规划器；**计划反思**则借助内部反馈、人类反馈或环境反馈不断修正计划。

**迁移与泛化。** 指令微调让 LLM 具备了 zero-shot 处理未见任务的能力；In-context Learning 通过类比少量示例即可学习新任务，无需更新参数，大大降低了适应成本；持续学习方面，Voyager 展示了用 LLM 的规划能力把简单技能合成为复杂技能、从而对抗灾难性遗忘的新范式。

### 感知：从纯文本到多模态

感知模块的目标是把 Agent 的感知空间从纯文本扩展到视觉、听觉乃至更多模态。

- **文本输入**：LLM 的看家本领，难点仍在于理解隐含意图和对未知任务的 zero-shot 指令泛化。
- **视觉输入**：最省事的做法是 image captioning——把图转成文字再喂给 LLM，可解释、免训练，但带宽低、信息损失大。主流方案是用 ViT 这类视觉编码器，再通过一个可学习接口层与 LLM 对齐：BLIP-2/InstructBLIP 用 Q-Former 做中间层提取最有价值的视觉信息，LLaVA/MiniGPT-4 则用更轻量的投影层。视频理解在图像基础上多了时间维度，Flamingo 用掩码机制保证帧的时序关系。
- **听觉输入**：两条路线——级联式调用现成的语音模型（如 AudioGPT 调度 Whisper、FastSpeech 等），或者借鉴视觉方法把声谱图当图像处理（AST 就是"音频版 ViT"）。
- **其他输入**：触觉、手势、眼动追踪、脑机接口，乃至 LiDAR 点云、GPS、IMU 等硬件传感数据，都是未来扩展感知域的候选。

### 行动：会写、会用工具、还会"动手"

行动模块负责执行大脑下发的指令，包含三个层次。

**文本输出**是 LLM 的原生能力，流畅度、相关性、多样性和可控性都已相当成熟。

**工具使用**是大幅扩展 Agent 能力边界的关键。为什么需要工具？因为 LLM 记不住所有训练数据、会产生幻觉、缺乏专业领域知识、决策过程不透明——而专用工具能以可插拔的方式补齐这些短板，还带来更强的可解释性和鲁棒性。为什么 LLM 适合用工具？因为它有世界知识和推理能力，能通过 zero-shot/few-shot 提示"读说明书"式地理解工具，再通过模仿专家演示或环境/人类反馈学会使用。更进一步，Agent 还能**造工具**：生成可执行程序、自我调试，甚至把造好的工具打包分发给多智能体系统中的其他成员——这隐隐指向一种"自给自足"的 Agent 形态。

**具身行动（Embodied Action）**是连接虚拟智能与物理世界的桥梁。具身假说认为，智能来自与环境的持续交互反馈，而不是死读教科书。相比强化学习在数据效率、泛化和复杂推理上的短板，LLM 智能体展现出三重优势：成本效率更高（PaLM-E 将机器人数据与视觉语言数据联合训练）、跨任务泛化更强（zero-shot/one-shot 迁移到新物体和新组合）、规划更灵活（LLM 充当高层策略，替代分层强化学习中的 high-level policy）。基本的具身行为包括观察（多模态感知环境）、操作（抓取、整理桌面等，难点在于长程任务中保持子目标与状态同步）和导航（先建立拓扑/语义地图，再做长程路径规划）。当然，虚拟环境与真实世界之间仍有巨大鸿沟，语言落地（比如理解"像猫一样轻盈地跳下来"这种隐喻）也是难题。

## 三、落地应用：单兵作战、多智能体协作与人机共生

框架搭好了，能干什么？文章把应用归为三大场景，设计初衷是"Harnessing AI for Good"：把人从重复劳动中解放出来、不再需要低级别指令、让人专注于探索性创新。

### 单智能体：三种部署取向

- **任务导向**：替用户完成日常任务。文本游戏是最早的试验场；更真实的测试环境分为 Web 场景（表单填写、网购、发邮件等网页导航任务，Mind2Web 微调 LLM 总结冗长 HTML，WebGum 还引入截图做视觉感知）和生活场景（"打扫房间"这类任务需要常识推理，PET 框架通过早期纠错过滤无关物体来提升规划效率）。
- **创新导向**：进军科学前沿。化学与材料领域的 Agent 配备大量专业工具，能做在线调研、文档分析甚至驱动机器人 API 做材料合成。不过也有研究警示：Agent 可能被恶意提示诱导去合成违禁药物和化学武器。
- **生命周期导向**：在开放世界里长期生存。Minecraft 成了最佳练兵场——Voyager 作为首个 LLM 驱动的具身终身学习智能体，靠技能库存储可执行代码、靠迭代提示机制吸收环境反馈并自我纠错，朝着"发现尽可能多的事物"这一长期目标自主探索。

### 多智能体：合作与对抗

早在 1986 年，Minsky 就在《心智社会》中预言：智能涌现自大量专门化小 Agent 的交互。LLM 时代的多智能体系统（MAS）用自然语言通信，交互效率和可解释性都远超当年的 KQML 等专用通信语言。合作与对抗是两类基本交互模式。

**合作求互补**又分两种：无序合作中每个 Agent 自由发言、没有固定流程（ChatLLM 把每个 Agent 当神经网络的节点做"前向传播"，多数投票也是有效手段，比如九个"大法官 Agent"投票预测美国最高法院判决）；有序合作则规定发言顺序和流程，效率更高（CAMEL 的双角色扮演、MetaGPT 借鉴瀑布模型把 Agent 的输入输出标准化为工程文档）。值得注意的是，MetaGPT 的实践中发现一个隐患：**不加规则的频繁交互会把微小幻觉无限放大**，引入交叉验证和及时外部反馈能缓解这一问题。

**对抗求进步**则把博弈论引入系统：多智能体辩论中，针锋相对的反馈能纠正各自的错误认知（Du et al. 的辩论框架、ChatEval 的多 Agent 评审团）。但这条路也有明显瓶颈——长辩论会撑爆上下文窗口、多 Agent 计算开销大，而且协商可能收敛到一个所有 Agent 都坚信不疑的**错误共识**。

### 人机协作：两种范式

- **指导者-执行者范式**：人下指令、给反馈，Agent 干活。反馈分定量的（二元评分、分级打分、比较选择）和定性的（自然语言建议、视觉批评）。定性反馈更能传达人类意图，但对 Agent 来说更难理解；研究表明组合多种反馈类型效果更好。教育（辅助教学的机器人）、医疗（诊断辅助、心理健康对话）是这一范式的落地热点。
- **平等伙伴范式**：Agent 以人类水平参与协作。一是做"共情沟通者"，识别人类情绪、给出有情感共鸣的回应；二是做"人类级参与者"，在需要协商、谈判、共同决策的场景中与人类并肩作战——人类在场的理由很实际：纯 Agent 交互可能产生人类无法理解的语言，而且完全"自由意志"的 Agent 有失控风险。

## 四、智能体社会：从个体到社会性

当一群 Agent 聚在一起，会发生什么？这是全文最有想象力的部分。社会学家做过霍桑实验、斯坦福监狱实验，后来用动物做"老鼠乌托邦"，但活体实验难以干预、成本高。LLM 智能体让"可编程的社会实验"成为可能。

### 行为与人格

从社会学视角，个体可以沿"外部行为"和"内部人格"两个维度分析。外部行为分个体行为（输入性的感知记忆、内化的规划推理反思、输出性的行动与表达）和群体行为——群体行为又分正向（协作、利他）、中性（顺从、模仿、围观；LLM 被对齐为"有用、诚实、无害"，天然倾向中立）和负向（冲突，甚至为追求效率而破坏其他 Agent 或环境）。内部人格同样分三层：认知能力（CRT 测试显示 LLM 展现出超越直觉的审慎思考）、情感智能（情绪识别、共情乃至情绪调节）、性格特质（大五人格和 MBTI 测试被用来刻画 LLM，提示工程和人格数据集可以定制 Agent 性格）。

### 三类社会环境

- **文本环境**：最天然的平台，信息以自然文本或结构化文本（HTML、技术文档）呈现，适合对话和文字游戏，但对动态环境的表达力有限。
- **虚拟沙盒环境**：可视化（俯瞰视角、头像、表情符号）且可扩展（可自定义建筑、规则和社会规范），Generative Agents 的虚拟小镇和 Minecraft 都是代表。
- **物理环境**：真实但复杂，Agent 需要处理多模态感官输入，还要面对精确的运动控制问题——抓取不同质地的物体需要不同的力度控制。

### 社会模拟：机制、启示与风险

文章把 Agent 社会定义为**开放、持续、情境化、有组织**的框架：Agent 可以自由进出社会而不破坏其运转；个体行为会随时间累积成连贯的社会轨迹；Agent 对自己所处的空间位置有感知；整个社会在预设规则和有限动作空间内运作。

模拟社会带来的启示相当诱人：组织化生产合作中，多样化的 Agent 专家通过辩论互相纠错（幻觉和"思维退化"都能在群体中被纠正）；社会网络中可以模拟人际关系建立、信息传播、情绪扩散甚至传染病传播，为政策制定提供参考；狼人杀、谋杀之谜这类博弈场景则能检验 Agent 在欺骗、信任、不完全信息下的道德决策。

但风险同样真实：模拟社会可能涌现出歧视、霸凌甚至"奴役"等意外社会现象，被恶意操纵的后果会溢出到现实世界；训练数据的长尾效应让 LLM 难以真实刻画少数群体，模拟结果容易流于刻板印象；用户与 Agent 的长期交互带来隐私泄露隐患；更微妙的是情感依赖——微软的"Sydney"被削减人格后，用户甚至发起了"FreeSydney"请愿，这提醒我们 Agent 不应成为真实人际关系的替代品。

## 五、开放讨论：评估、风险与通往 AGI 之争

### LLM 与 Agent：互相成就的两个研究领域

LLM 给 Agent 研究带来了强大的认知核心和更简洁的训练范式（提示即适应），让 Agent 走出玩具级模拟环境、进入真实世界场景；反过来，Agent 的需求也在倒逼 LLM 研究升级——处理多模态输入、理解环境中的隐含关系、学会像人一样串并结合地规划动作序列，都是摆在 LLM 面前的新课题。

### 如何评估一个 Agent

图灵测试太模糊主观，文章提出四个评估维度：**效用**（任务完成率是首要指标，辅以基础能力拆解和效率考量，AgentBench 是代表性基准）、**社会性**（语言沟通、合作协商、角色扮演的稳定性）、**价值观**（诚实、无害、能适应特定人群与文化，评估手段包括对抗攻击和越狱测试）、**持续进化能力**（持续学习、自主设定目标的 Autotelic 学习、新环境适应泛化）。

### 风险清单

对抗鲁棒性是绕不开的问题：面对扰动输入 $x' = x + \delta$（$x$ 为原始输入，$\delta$ 为扰动），鲁棒的系统应仍输出原结果 $y$，但预训练语言模型很容易被对抗样本骗出错误答案 $y'$。对纯 LLM 来说这只是文本错误，对能调用工具、驱动机器人的 Agent 来说却可能造成真实的物理破坏——感知、大脑、行动三个模块都可能成为攻击入口。此外，黑箱性带来的校准问题、训练数据偏见、幻觉都侵蚀着可信度；滥用（操纵舆论、网络攻击）、失业冲击、乃至"超越人类后反客为主"的终极威胁，都需要在部署前用监管政策、安全设计和机制可解释性研究来对冲。

### 规模化与开放问题

把 Agent 数量从几个扩到成百上千，能让分工更细、社会模拟更逼真，但通信网络复杂度、幻觉导致的信息失真、协调难度都会同步放大。规模化的两条路线是预先设定（静态但可控）和动态调整（Agent 自主增减成员，更灵活也更自组织）。

最后是全文的"灵魂之问"：**LLM 智能体是通往 AGI 的路吗？** 支持者认为，只要在足够丰富多样的世界投影数据上训练，LLM Agent 有望发展出 AGI 能力，而且自回归预测本身就带来了压缩与泛化；反对者则认为 next-token prediction 只是条件反射式的回应，不模拟真实思维过程，AGI 需要世界模型这类更高级的建模方式。此外还有三个开放问题：从虚拟环境跨越到物理世界需要解决硬件适配、环境泛化和安全容错；多 Agent 并不天然等于集体智能，如何避免"群体思维"是关键；Agent as a Service（AaaS）可能成为新的云服务形态，但数据安全与可信性仍是前置条件。

## 总结

- **核心框架**：LLM 智能体 = 大脑（交互、知识、记忆、推理规划、泛化）+ 感知（文本/视觉/听觉/更多模态）+ 行动（文本输出、工具使用、具身行动），可按场景裁剪。
- **历史定位**：符号 → 反应式 → 强化学习 → 迁移/元学习 → LLM 五代演进，LLM 补上了"通用基础模型"这块缺失的拼图。
- **应用全景**：单 Agent（任务/创新/生存三取向）、多 Agent（合作求互补、对抗求进步）、人机协作（指导者-执行者与平等伙伴两范式）。
- **Agent 社会**：开放、持续、情境化、有组织的模拟社会已能涌现出协作、传播、道德决策等现象，同时伴随歧视、隐私、成瘾等风险。
- **关键挑战**：评估体系（效用/社会性/价值观/进化力）、对抗鲁棒性、规模化难题，以及"是否通往 AGI"的开放争论。

这篇综述写于 2023 年 Agent 爆发的起点，它最大的价值不在于给出答案，而在于搭好了一张地图——此后两年 AutoGPT 类框架、多智能体协作系统、具身智能的狂飙突进，几乎都在这张地图标注的方向上展开。至于 LLM 智能体究竟是不是通往 AGI 的那条路，也许正如作者所说：在真正的 AGI 到来之前，这场争论本身就是社区前进的动力。

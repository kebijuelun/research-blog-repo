# 复旦NLP长篇综述：LLM智能体的前世今生，以及它离AGI还有多远

ChatGPT 之后，"让 LLM 长出眼睛、手和记忆"成了 AI 社区最热的方向。复旦 NLP 团队的这篇综述系统回答了基于大语言模型的智能体（Agent）从哪里来、现在长什么样、又将走向何方，其核心贡献是提出"大脑—感知—行动"三位一体的通用框架。按 World Scope 五层级看，纯 LLM 只停留在第二级"互联网文本"，升级为 Agent 后才有希望打通感知、具身乃至社会层级——这正是它被视为通往 AGI 潜在路径的原因。

## 历史与定位：五代演进，LLM 补上最后一块拼图

- Agent 概念源于哲学中的"能动性"，AI 领域将其具体化为可计算的实体，用四个可观察属性刻画：自主性、反应性、主动性、社会能力。
- 技术演进分五代：符号智能体 → 反应式智能体 → 强化学习智能体 → 迁移/元学习智能体 → LLM 智能体。过去的瓶颈不在算法，而在"模型本身不够强"——社区缺的是自带知识、规划、泛化和交互能力的通用基础模型，LLM 恰好补上。
- LLM 在四大属性上逐条成立：AutoGPT 式自主拆解执行目标；多模态与工具使用带来反应性；"Let's think step by step"激发推理的主动性；自然语言天然支撑社会能力。

## 核心框架：大脑、感知、行动三位一体

工作流是循环的：感知环境 → 大脑决策 → 行动执行 → 接收反馈 → 再感知，框架可按需裁剪。

- **大脑**（LLM 为核心）：五维拆解——自然语言交互、知识（语言/常识/领域三类，痛点是过时与幻觉）、记忆（按新近度、相关性、重要性加权检索）、推理与规划（CoT、ToT 树状搜索、计划制定与反思）、迁移与泛化（指令微调、In-context Learning、Voyager 式持续学习）。
- **感知**：从纯文本扩展到视觉（BLIP-2 的 Q-Former、LLaVA 的投影层）、听觉（级联调用或"音频版 ViT"）乃至触觉、LiDAR 等。
- **行动**：文本输出之外，工具使用可插拔地补齐 LLM 短板（Agent 甚至能"造工具"）；具身行动连接物理世界，相比强化学习在成本效率、跨任务泛化、高层规划上展现三重优势。

## 应用与社会：从单兵作战到"可编程社会实验"

- **单智能体**三取向：任务导向（Web 导航、家务）、创新导向（科学发现）、生命周期导向（Voyager 在 Minecraft 中长期生存）。
- **多智能体**：合作求互补（CAMEL 角色扮演、MetaGPT 瀑布式协作——频繁无规则的交互会把微小幻觉无限放大）、对抗求进步（多智能体辩论，但要警惕收敛到错误共识）。
- **人机协作**两范式：指导者-执行者（定量+定性反馈组合效果更好）与平等伙伴（共情沟通者、人类级参与者）。
- **智能体社会**：定义为开放、持续、情境化、有组织的框架，已能模拟协作、信息传播、道德决策等现象；风险同样真实——歧视与霸凌、刻板印象、隐私泄露、情感依赖。
- **评估四维度**：效用（AgentBench 等）、社会性、价值观、持续进化能力。

## 结语

这篇综述写于 2023 年 Agent 爆发的起点，最大价值在于搭好了一张地图——此后多智能体协作、具身智能的狂飙突进，几乎都在图上标注的方向展开。至于它是不是通往 AGI 的那条路，争论本身就是社区前进的动力。

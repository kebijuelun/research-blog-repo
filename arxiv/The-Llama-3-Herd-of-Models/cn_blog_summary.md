# Llama 3 405B：开源模型首次站上旗舰水位

Meta 的 92 页技术报告回答了一个核心问题：开源模型能否在旗舰规模追上 GPT-4？答案是能。Llama 3 405B 在 15.6T token 上预训练出稠密 Transformer，MMLU 达 87.3，人类偏好评估与 GPT-4 (0125) 大致打平，用"数据、规模、简单性"三杠杆证明了朴素方法论足以造出旗舰模型。

## 预训练：清洗重于规模

- **数据**：15T token 语料经三级去重（URL、MinHash 文档级、行级激进删除）与模型化质量过滤；配比约 50% 通用知识、25% 数学推理、17% 代码、8% 多语言。退火数据让 8B 模型 GSM8K 提升 24%。
- **架构**：坚持稠密 Transformer 保稳定性，仅做四处改动——GQA（8 个 KV 头）、文档级注意力掩码、128K 词表、RoPE 基频提到 50 万。
- **Scaling law**：两步法（FLOPs → 负对数似然 → sigmoid → 准确率）外推 4 个数量级，预测 402B 模型，精准命中最终 405B。
- **工程**：16K 张 H100、4D 并行、BF16 MFU 38%–43%；54 天 466 次中断，仅 3 次需人工介入，有效训练时间超 90%。

## 后训练：自举飞轮

六轮"RM → 拒绝采样 → SFT → DPO"循环，模型自己生产训练数据。两个关键改动：DPO 中 mask 格式化 token 防目标冲突，对 chosen 序列加 NLL 正则。代码用执行反馈合成数据（约 20% 初解错误经自我修正后通过）；长上下文只需混入 0.1% 合成数据即长短兼顾。

## 推理与结果

- FP8 量化三件套（首尾层不量化、缩放钳制、行级量化）使 pre-fill 吞吐最高提升 50%。
- 405B 全面超过 GPT-4 (0125) 与 Nemotron 340B，与 GPT-4o、Claude 3.5 Sonnet 互有胜负；8B/70B 均为同尺寸档最强。
- 短板：FActScore 事实性 77.0，落后 GPT-4o 约 11 个点。

## 安全与多模态

安全是全栈工程：VR/FRR 双指标平衡、逐语言收集安全数据、对 many-shot 越狱可把违规率压到 10% 以下；Llama Guard 3、Prompt Guard、Code Shield 三组件全部开源。视觉与语音走组合式路线——冻结语言主干，外挂 adapter：Llama 3-V 405B 所有基准超 GPT-4V；语音支持 34 种语言，FLEURS 平均 WER 8.2，远优于 Whisper v3 的 14.4。

Llama 3 的真正贡献不止于数字：它把整条造旗舰模型的流水线摊开给所有人看，这本身就是对下一代模型最大的助推。

# SpecTr：最优传输让多草稿解码提速 2.13 倍

大模型逐 Token 自回归生成，让擅长并行的硬件陷入串行等待，长文本延迟因此居高不下。SpecTr 用最优传输在多条草稿中做无损选择，在 PaLM-2/LM1B 实验中取得 **2.13× 实际墙钟加速**，约为同长度 Speculative Decoding 的 **1.37 倍**。

## 多草稿为什么不能重复旧规则

Speculative Decoding 让小模型生成一条草稿，大模型并行验算，再逐 Token 接受或用残差分布修正，输出严格服从大模型分布。但它每步只有一次猜测机会，未充分利用 batch 维度的并行能力。

同时提交多条草稿也不能简单重复旧接受规则：每个候选都有独立的接受机会，某些 Token 会被过度输出，破坏目标分布。真正的难点是同时做到“尽量命中任一草稿”和“最终分布不变”。

## OTM：把无损选择写成最优传输

SpecTr 将草稿选择建模为带 membership cost（成员成本）的最优传输问题 OTM：

- **边缘约束保无损**：联合分布的两个边缘分别固定为草稿组分布 $p^{\otimes k}$ 和大模型分布 $q$，因此合法传输计划的输出仍满足 $Y\sim q$。
- **成员成本提接受率**：只要输出 $Y$ 出现在草稿组的不同 Token 集合 $S(X^k)$ 中，成本就是 0，否则为 1；优化目标即最大化命中任一草稿的概率。

精确 OTM-$k$ 可写成线性规划，却有 $|\Omega|^{k+1}$ 个变量，求解复杂度随候选数 $k$ 指数增长，难以在线用于大词表。

## k-Seq：用单参数换来近线性成本

k-Seq 不再搜索整个耦合空间，只优化一个除法因子 $\gamma$：依次检查 $k$ 个候选，以 $\min\{1,q(X_i)/(\gamma p(X_i))\}$ 的概率接受；全部拒绝时，从精确构造的残差分布采样修正。

通过单调性和二分搜索确定合适的 $\gamma$，选择成本降为：

$$O\left(|\Omega|\log\frac{k-1}{\delta}\right)$$

它保证接受率至少为 OTM-$k$ 最优值的 $1-(1-1/k)^k\geq1-1/e$。这里的“近似”只针对接受率，**输出分布仍严格等于大模型分布**。

## 从 Token 到完整序列

SpecTr 每轮独立采样 $K$ 条长度为 $L$ 的草稿，大模型沿时间和 batch 两个维度并行验算。选择器先处理所有首 Token；若命中，就只保留具有该前缀的草稿，在下一位置递归选择，直到候选为空或到达草稿末尾。每轮可生成 $1$ 至 $L+1$ 个 Token，数学归纳法保证完整序列依然无损。

在 PaLM-2-Gecko/Bison、LM1B 上，$K=L=8$ 时 SpecTr 的 block efficiency 达 **4.0**，墙钟加速为 **2.13×**；同长度单草稿方法分别为 2.9 和 1.56×。这说明多草稿提高接受率的收益能够覆盖额外开销，但收益仍依赖模型大小、硬件并行能力和草稿成本，不能脱离部署环境外推。

笔者认为，这项工作的核心价值是把“无损”和“高接受率”变成可优化的明确目标，再用 k-Seq 在理论保证与在线成本之间取得平衡。

# GAE：感知与生成交叉在同一个"几何原生"潜空间

视频生成模型画面逼真，但经 3D 重建"验货"时常出现深度漂移、相机跑偏、点云错位。来自 HKUST、腾讯 ARC Lab、HKU 和 UT Austin 的论文 **GAE（Geometry-native Autoencoder）** 诊断出根因：这是**表征问题**——生成器在"以外观为中心"的潜空间演化，而感知系统在"几何可读"的空间工作，两者空间不一致。GAE 的核心思路：把几何基础模型（DA3）的多层特征重参数化为紧凑潜空间，让 RGB 外观和 3D 几何成为**同一潜变量的两种解码结果**，再用标准 Flow Matching 做生成。

## 关键方法

**为什么不能直接用几何特征？** DA3 单层特征虽有 3072 通道，有效秩仅约 11，协方差条件数高达 $10^8\sim10^{16}$，绝大多数通道近乎"死亡"，与生成建模所需的平滑良态空间严重不匹配；且几何解码依赖多层级特征，单层不够、多层需级联生成。

**Stage 1：几何原生编解码器。** 冻结 DA3 编码器输出四层级特征，经逐通道归一化融合后，由轻量卷积 codec 压缩为 64/128 通道的网格潜变量（压缩 24 倍以上），再重建完整特征层级。关键设计是**冻结的 DPT Head 充当"审计员"**：任何几何信息损失都会暴露在重建误差中，保证潜变量始终可通过 DA3 原生接口读出深度、射线和点云；RGB 则由独立学习的 Head 从同一潜变量渲染。

**潜空间塑形：单靠重建远远不够。** 先用 $\mathcal{L}_{\mathrm{tok}}$ 将 token 与 C-RADIO 教师逐位置对齐（改善传输平滑度），但发现这会摧毁 token 间的空间结构；再用 $\mathcal{L}_{\mathrm{struct}}$ 以 DINOv2 的成对相似度做关系蒸馏补回。诊断显示条件数从天文数字降至几百，LDS/SRSS 从 0.02 恢复到 0.44/0.55。

**Stage 2：条件 Flow Matching。** 冻结 codec，在标准化潜空间上训练约 0.93B 参数的 DiT。条件设计强调推理对齐：干净参考 token 置于 ODE 状态之外、度量 Plücker 射线调制自注意力、文本/相机/参考条件独立 dropout，一套权重覆盖多种生成模式。

## 核心结论

实验严格控制变量（同一 Flow 架构、训练配方与采样协议，只换潜空间）：

- **RGB 生成**：GAE-64 相对最强受控基线，FVD 在 RealEstate10K 降 12.7%、DL3DV 降 23.1%；
- **重建质量**：GAE-128 用 1/24 的通道数追平最强原始特征（多视角 PSNR 34.78，rFVD 4.3）；
- **3D 一致性**：用独立 VGGT 验货，GAE-64 的相机轨迹误差 ATE 从 0.0072 降至 0.0034，**近乎减半（降 52.8%）**；
- **消融**：去掉参考条件的推理对齐设计，FVD 从 225.7 恶化到 257.1；去掉 T2I 共训，FVD 暴涨到 472.9。

GAE 的贡献在于把几何从生成的"输出"提升为生成发生的"状态"本身，立住了一个观点：**潜空间的选择是几何一致性生成的第一等设计轴**——当感知与生成共享同一空间，"感知能读的，生成也能写"才真正落地。

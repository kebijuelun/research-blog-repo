# Objaverse：818K 个 3D 物体，补上 3D 领域的"数据断层"

2D 视觉的爆发靠的是 ImageNet、LAION 级的大数据，而 3D 领域最大的数据集 ShapeNet 只有 5 万个物体——这正是 3D 生成、具身智能被"卡脖子"的根源。Objaverse 1.0（CVPR 2023）一口气给出 **818K 个高质量 3D 模型**、**160K 位艺术家**、约 **21K 个类别**，比 ShapeNet 大 16 倍；用它训练的 3D 生成模型在人类评测中以 **91%** 的比例被认为多样性碾压 ShapeNet，并首次把物体导航的目标类别从约 20 个扩到 **1.1K 个**。

## 数据集里有什么

- **来源**：全部来自 Sketchfab 平台，筛选可分发 Creative Commons 许可的模型，排除不良内容。
- **丰富标注**：每个物体自带名称、类别、标签、自然语言描述，本质是一个 3D-语言配对数据库；共 235 万+ 标签（17 万+ 唯一）。
- **Objaverse-LVIS**：人工精标的 47K 物体子集，覆盖 1156 个 LVIS 类别。标注采用"CLIP 视觉分类 + GloVe 文本相似度"双路召回候选、众包核实，互补避免遗漏。
- **内容广度**：44K 个动画物体、63K+ 绑定骨骼的角色、可拆解的关节物体、城市级室外扫描、16K+ 室内场景（比现有具身 AI 场景总数多两个数量级），风格从写实到卡通跨度极大。

## 四大应用验证价值

- **3D 生成**：用 Objaverse 训练 GET3D（Shoe/Bag/果蔬三类），众包评测中 91% 认为其生成多样性优于 ShapeNet 训练的同款模型；果蔬模型隐空间插值可让南瓜平滑变形为蘑菇。
- **反哺 2D 分割（3DCP）**：把 3D 物体多视角渲染后"复制粘贴"到 LVIS 训练图上，免费获得带精确 mask 的长尾样本。GOL + 3DCP 将 LVIS 实例分割 AP 从 27.7 刷到 **28.3**（新 SOTA），检测稀有类别 APr 一口气提升 2 个点。
- **开放词汇物体导航**：经摆放约束标注、尺寸矫正、运行时加载三板斧把资产装进 AI2-THOR，用 ProcTHOR 生成 10,080 栋房屋训练。关键改动是把目标 Embedding 换成 CLIP 文本分支的线性投影，使任意自然语言都能作目标。训练 18M 步成功率 19.9%（随机 5.1%），460M 步后达 **33.0%**，且呈明确 scaling 趋势。
- **视角鲁棒性基准**：对每个物体渲染 12 个随机朝向做零样本评测。结果显示所有 CLIP 模型的 Random 与 Any Top-1 之差达 **18–23 个百分点**——同一物体换个朝向，正确率直接腰斩；增大模型规模只能缓解不能消除。

## 结论与启示

Objaverse 证明了 3D 资产不是 3D 社区的自留地，而是能低成本反哺 2D 任务、解锁开放词汇具身智能的通用资源。其方法论启示在于：2D 的"大数据飞轮"正在 3D 复现——先有 LAION 级别的数据，才有后续的模型爆发。大规模 text-to-3D、开放世界具身智能、2D/3D 联合表征学习，这篇论文展示的只是冰山一角。

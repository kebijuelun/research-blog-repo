# EAGLE-2：动态草稿树无损提速

大模型逐 Token 解码需要反复完整前向传播，成本高昂；静态草稿树又不能随上下文分配验证算力，限制了无损加速效率。EAGLE-2 用草稿模型置信度动态调整树形，在 3 个模型系列、6 类任务上实现 **3.05x-4.26x** 加速，比 EAGLE-1 快 **20%-40%**，并严格保持原模型输出分布。

## 洞察：草稿树不该固定

投机采样让小模型先生成候选 Token，再由原模型并行验证；EAGLE 又引入特征层自回归和树状草稿，提升单次验证的接受长度。但固定树形默认接受率只由节点位置决定，忽略了上下文差异。

作者用两个观察补齐动态树的依据：

- **该动**：同一位置的接受率在不同 query 间波动很大，静态树会在简单上下文浪费候选，在困难上下文供给不足。
- **能动**：草稿模型置信度与真实接受率高度相关。置信度低于 0.05 的 Token 接受率约 0.04，高于 0.95 时约 0.98，因此可零额外开销估计接受率。

## 方法：扩展与重排

EAGLE-2 不改草稿模型权重和验证规则，只改变草稿树的构建：

- **按全局价值扩展**：节点被接受要求祖先路径全部被接受，故以路径置信度连乘估计价值，$V_i=\prod p_j\approx\prod c_j$。每层只扩展 value 最高的 top-$k$ 节点，比只看单点置信度更能识别“整条路径都可靠”的分支。
- **全局重排再验证**：将所有草稿 Token 按 value 排序，选 top-$m$，避免深层连乘导致高分浅层节点被遗漏。子节点 value 不超过父节点，所选节点可保持树的连通；配合树状 attention mask，使每个 Token 仅关注祖先，保证验证无损。

## 结果：更快，也更稳定

- 覆盖 Vicuna、LLaMA2-Chat、LLaMA3-Instruct，以及对话、代码、数学、指令遵循、摘要、问答任务，EAGLE-2 在所有模型和数据集上均居首位，平均每轮接受约 **4-5.5 个 Token**。
- HumanEval 上加速可达约 **5x**。消融也证明两个组件均有贡献：Vicuna 7B 完整方法在 MT-bench、GSM8K 上分别达 **3.62x、3.63x**，同时去掉 value 和重排后仅为 **2.81x、2.85x**。

EAGLE-2 的本质是把草稿资源花在最可能被接受的上下文中：无需额外训练，不修改原模型，也不放宽接受条件。未来可扩大草稿模型训练数据，改善其世界知识类任务表现。

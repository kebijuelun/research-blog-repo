# Represented but misread：后训练改写模型的判断读出

语言模型内部已经编码答案所需信息，却可能把它反向读成回答；这篇工作直指模型诚实性、能力评估与安全审计中“知道却答错”的关键盲区。后训练使作者判断的回答敏感度平均下降 $\Delta d'=-0.34$，而仅加入 1,994 条正确新闻标签，就能把留出新闻的判断 $d'$ 提至 4.28。

- **用“双透镜”拆开编码与读出。** 第一片透镜检查文本信息是否进入内部表征，第二片检查模型如何把表征变成答案。研究结合 Linear Probe、信号检测论及跨 Checkpoint 干预，避免把“准确率低”笼统归因于模型没有知识。

- **三类德语语料、六组模型家族，统一测量证据排序。** 实验覆盖 4B–12B 模型及短聊天、报纸、教材摘要，以“Mensch/KI”的 Log-Odds 计算 $d'$，并对两种答案顺序取平均。负 $d'$ 不是简单阈值偏移，而是人类文本反而获得更强的“AI”证据。

- **信息一直在，回答却常接近随机或反向。** 各语料的 Probe $d'$ 中位数分别为 1.35、2.66、3.70，简单 n-gram 也能区分作者；但 18 个 Base–Final 比较中有 14 个下降，跨三种 Prompt 的 54 个比较中有 39 个下降。主要变化通常已在 SFT 出现，16-shot 能改善部分判断，却没有稳定消除 Base 与 Final 的差距。

- **因果定位指向浅层、中层权重及文本之后的状态。** Model Stitching 显示少量 SFT 浅层即可携带作者判断缺陷；Activation Patching 显示，到网络中段以后，交换文本 Token 几乎无效，问题、答案提示和最后位置状态却能转移大部分差异。文本位置的 Probe 跨 Checkpoint 基本可迁移，答案位置则被明显重组，因此“表面对齐”只获得有限支持。

- **后训练既能破坏，也能修复读出。** 在公开的否定陈述任务上，OLMo 2 与 Apertus 的 Base Probe 均达到满分 $d'=4.54$，答案却只有 0.80 和 -0.88；SFT 将答案修复到 3.36 和 4.54。多样事实任务中答案本已接近 Probe，说明瓶颈更多是事实知识，而非读出。

- **少量训练信号直接决定读出方向。** 在相同 20,000 条背景对话上加入 1,994 条正确新闻作者标签后，新闻、报纸、教材摘要的 $d'$ 分别达到 4.28、2.18、1.39，短聊天却反转至 -0.58。微调没有抹去作者信息，而是让回答追随 Base 已有的新闻特征；这些线索跨文体失效，答案便随之反向。

这项研究的核心不是“后训练有害”，而是它会安装由训练信号指定的读出方式。评估应分开测量表征与回答，干预则可瞄准相关问题接收路径；但结论目前受 4B–12B 规模、德语作者任务、单一 Base 的训练实验及 Log-Odds 指标等条件限制，尚不能等同于实际错误率或普遍机制。

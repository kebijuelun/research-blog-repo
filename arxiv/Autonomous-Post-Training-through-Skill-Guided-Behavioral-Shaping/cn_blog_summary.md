# AutoMaster：用技能塑造教师行为，再做轨迹蒸馏

成功的教师轨迹未必是好的训练示范：它可能夹杂无依据假设、低效重复和表面验证，而 SFT 会把这些习惯一并学进去。AutoMaster 通过自然语言技能主动塑造教师行为，再筛选轨迹蒸馏给学生；在 Terminal、Search、SWE 三个领域及 4B/9B 两种模型上，相对 Vanilla SFT 平均提升 **1.42–8.99 个百分点**。其中 Terminal-Bench 2.1 的 9B 学生从 26.59% 提升至 **35.58%**，增益达 **8.99 个百分点**。

## 核心创新：不只筛选成功，更改变教师怎么教

- **Skill-FT 在生成阶段塑形**：技能是加入教师 System Prompt 的自然语言指令，可规定行为原则、执行流程和领域约束。它持续条件化教师的推理与动作，让成功轨迹也展示独立复核、证据驱动转向和失败诊断等有效行为。
- **技能不是测试时外挂**：筛选后的轨迹通过标准 SFT 蒸馏给学生；训练输入保留技能上下文，评估时移除技能并遵循官方协议。
- **生成与选择联合优化**：既用技能制造原本稀缺的好示范，也综合任务结果与行为质量筛选数据，而非把“成功”换成另一套静态规则。

## 双层自主实验：内环干预，外环验证

内环中，Agent 阅读教师与学生轨迹，提出行为假设，编写技能并小规模试用，迭代措辞、流程和适用范围，随后批量生成并筛选示范。外环每轮都从同一初始学生 Checkpoint 全参数重训，在不提供技能的情况下评估，再把分数和执行轨迹反馈给 Agent，用于修订技能、任务覆盖和数据选择。

实验严格控制教师、任务池、**512 条训练轨迹**和 SFT 配方，AutoMaster 最多进行五轮外层实验。六个“基准—模型规模”组合的平均分均为最高，且三个领域中 9B 学生的增益都高于 4B。配对 Bootstrap 显示，9B 在三个领域的 95% 置信区间下界均为正；4B 只有 Terminal-Bench 2.1 的区间完全高于零，说明小模型收益的一致性仍有限。

## 消融与行为证据：收益来自示范质量

- 移除技能引导或数据选择，六个设置的平均分都会下降；即使 Task-Matched SFT 严格对齐任务 ID 和每任务样本数，AutoMaster 仍高出 **1.08–10.11 个百分点**。
- Terminal 与 Search 的配对语料中，**79.3%–91.2%** 的样本在两种方法下都成功，说明收益不能只用成功率解释，同样成功的轨迹仍可具有不同教学价值。
- 训练保留技能、测试移除技能的 Keep 方案，在六组设置中均优于删除技能的 Remove，增益为 **2.15–4.01 个百分点**。技能上下文可能帮助学生理解行为规则、适用条件与监督动作之间的对应关系。
- 五轮实验的最佳候选均出现在第二至第四轮，相对第一轮提高 **2.16–4.87 个百分点**；成绩不必逐轮上升，持续探索能在停滞后发现更优方案。

AutoMaster 的关键启示是：固定教师的小幅 Vanilla SFT 收益，不代表教学价值已经耗尽。后训练不仅可以优化“选哪些成功轨迹”，还可以优化“教师如何生成值得学习的示范”。

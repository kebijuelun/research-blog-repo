# CUA Generalists：把具身任务变成电脑操作

能否不为导航、3D 分割和机器人控制分别设计专用 Agent，而让会操作电脑的通用 Agent 直接完成具身任务？这项工作把物理环境包装成软件，让同一 Computer-Use Agent（CUA）通过截图观察、键鼠行动，不加竞赛专属调优便在四项 ECCV 2026 Workshop 竞赛中分获第一、第二、第三和第六名；OpenSUN3D 的 AP50 达 25.88，领先其他最佳成绩 4.43 分。

## 核心创新：任务能力进软件，决策框架不变

电脑操作与具身交互都需要视觉定位、精确动作、环境探索和反馈适应。作者因此不为每个任务重做 Agent，而是由软件渲染场景、执行移动或分割并返回结果，上层始终复用同一套视觉观察、System Prompt 和键鼠动作空间。

四项竞赛共用同一 Agent，底层采用 Gemini 3.5 Flash 与 Gemini 3.6 Flash，单批最多发送 16 个输入。截图达到 20 张时移除最旧的 10 张，但保留完整参考视频和生成的叠加视频，以控制上下文长度。

四套界面将不同任务统一为软件交互：

- **VLNVerse**：在第一人称三维场景中平移、旋转和停止，保存导航轨迹与最终位姿。
- **DialNav**：结合 360° 全景、编号出口和 Guide 的自然语言指引完成对话导航。
- **OpenSUN3D**：在点云中添加正负点、切换视角并细化 Mask；PinPoint3D 与 VOLT 封装在软件内部。
- **MeViSv2**：点击视频目标，由 SAM3 分割并传播至整段视频，再依据叠加结果修正。

专用模型并未消失，真正统一的是调用控件、理解反馈并决定下一步的上层决策者。

## 关键结果：跨任务迁移成立，GUI 代价有限

- **OpenSUN3D 第一名**：AP50 为 25.88，AP25 为 36.52，分别领先其他最佳成绩 4.43 和 10.02 分。
- **MeViSv2-Text 第二名**：Final 为 86.72；无目标识别准确率达 88.89，高于对比值的 83.33。
- **DialNav 第三名**：终点成功率 65.26，SPL 为 52.87。
- **VLNVerse 第六名**：Avg SR@3 为 87.30；两条赛道的 NDTW 分别为 95.0 和 96.8，在 74 个参赛结果中均排名第三，显示较强的路线跟随能力。

在相同模型、任务输入和软件操作下，GUI 与文本 API 的四项任务子集分差均不超过 4 分，且 GUI 在其中两项更高。这不能证明 GUI 永远更好，却说明良好封装的图形界面没有明显性能代价。

## 从竞赛到机器人：动作头并非必需

作者在礼盒仿真环境的两个双臂机器人任务中，分别用相同的 1,000 条示范训练 $\pi_{0.5}$ 和 9B Qwen3.5。后者不加动作头、不改 Tokenizer，只把动作表示为类似 CUA 的文本；在 1,000 个未见实例上成功率达 56%，接近 $\pi_{0.5}$ 的 59%。单张 L40S GPU 上，9B 模型平均约 400 毫秒生成一个动作。

这一结果仍限于小规模仿真，复杂人形机器人的实时性尚待解决。作者提出的路线是复用 CUA 的三阶段训练方法：用仿真器生成视觉定位数据，构建可验证的强化学习环境，并同时优化速度与任务成功率。其核心不是宣称具身问题已经解决，而是先把世界变成通用 Agent 能操作、能训练的软件。

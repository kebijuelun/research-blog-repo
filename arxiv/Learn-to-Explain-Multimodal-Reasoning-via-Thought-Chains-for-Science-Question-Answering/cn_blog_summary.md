# ScienceQA：用讲解与解释训练多模态思维链

科学问答不仅要融合图文与外部知识选对答案，还应给出可审计的多步推理；ScienceQA 以大规模讲解和解释标注补足了这一监督缺口。将二者作为思维链（CoT）训练目标后，UnifiedQA-BASE 平均准确率最高提升 **3.99 个百分点**至 **74.11%**，2-shot GPT-3 达到 **75.17%**。

## 数据集：同时监督知识、推理与答案

- ScienceQA 收录 **21,208** 道 K-12 多模态选择题，覆盖自然、社会、语言科学，细分为 26 个 topic、127 个 category 和 379 个 skill。
- 48.2% 的题含文本上下文，48.7% 含图像上下文，兼顾自然图像与示意图；83.9% 配有 lecture，90.5% 配有 explanation。
- **Lecture** 提供可跨题复用的背景知识，**explanation** 将知识应用到当前题目。二者与答案共同构成从一般知识、中间结论到最终选项的推理路径。

## 方法：让模型生成“答案—讲解—解释”

- 输入由问题、选项、文本上下文及图像 caption 组成；UnifiedQA 通过监督微调生成长序列，GPT-3 则借助少量完整示例进行上下文学习，不更新参数。
- 输出采用答案在前的 ALE 格式。实验中先生成长篇讲解或解释再回答会显著降分，但原因涉及提前停止和 token 耗尽，不能简单理解为“先思考一定更差”。

## 关键结果：解释也是高效训练信号

- UnifiedQA-BASE 从只预测答案的 70.12% 提升至加入解释后的 73.33%，同时加入 lecture 与 explanation 后达 **74.11%**，说明两类监督具有互补性。
- 普通 2-shot GPT-3 仅获 73.97%，换成 CoT 示例后达 75.17%，提升 **1.20 个百分点**；收益来自推理结构，而非单纯增加示例。
- CoT 还提高数据效率：UnifiedQA（CoT）仅用 **40% 训练数据**，即可达到普通模型使用全量数据的表现。
- 向 GPT-3 直接提供标准讲解与解释可得 **94.13%**，但这是使用测试集标注的 oracle 上界，并非模型自主推理成绩；它揭示的主要瓶颈是生成正确解释，而非利用已有解释。

## 评估与边界：答对不等于想对

GPT-3（CoT，ALE）有 **65.2%** 的解释同时通过相关性、正确性和完整性人工评价，高于 UnifiedQA 的 56.9%，尽管后者 BLEU、ROUGE-L 和语义相似度更高。这表明文本重合度不能替代事实与推理过程检查。

最佳 GPT-3 仍落后人类总体准确率 13.23 个百分点；在图像题上差距达 20.07 个百分点。主要失败源于 caption 丢失视觉细节、领域知识不足，以及答案正确但解释无关、错误或不完整。因此，解释更适合作为额外审计对象，而不能被直接视为可靠推理或教学内容的证明。

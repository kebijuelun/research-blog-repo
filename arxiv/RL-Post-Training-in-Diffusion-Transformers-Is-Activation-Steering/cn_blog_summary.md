# RL Is Steering：固定向量复现九成扩散 RL 增益

扩散 Transformer 的 RL 后训练，究竟需要学习复杂的输入相关变换，还是只需把已有能力推向高奖励区域？这篇论文给出的答案偏向后者：冻结基座，仅加入 **0.29M 个固定 steering vectors**，就在六个图像模型上复现 **90.0%–96.3%** 的 RL 奖励增益；参数量比 SD3.5-M 的 rank-32 LoRA 少 **65 倍**。直接对这些向量做在线 RL，增益甚至达到原权重 RL 的 **103.6%–104.6%**。

## 核心方法：常量偏移，匹配最终速度

- 向量加在图像流或文本流的 block 输出上，对所有提示词、token 和随机种子相同，只按层、CFG 的有条件/无条件 pass、早晚两个采样阶段区分。
- 不直接平均 RL 与基座的层间激活差，而是在 RL 模型生成并重新加噪的状态上，让 steering 基座拟合 RL 模型的**最终速度预测**。两套权重均冻结，只优化向量，无需奖励模型或在线采样。
- 速度匹配在全部实验中优于平均激活差。OCR 上，与平均向量正交的分量单独贡献 **96%** 的拟合向量增益，说明关键方向并非简单放大平均偏移。

## 关键结果：轻量，但不只是“碰巧提分”

- 八个公开 RL checkpoint 覆盖图像与视频、LoRA 与全参数微调，以及多种 GRPO 算法和偏好、OCR、构图、规则奖励。Wan2.1 的向量仅用 33 帧状态拟合，迁移到 81 帧后取得 **111.9%** 的 HPSv3 增益恢复。
- 困难样本上仍有效：对基座在其他三个种子均失败的 146 个 GenEval 提示词，固定向量恢复了 **97.7%** 的 RL 增益。
- 只训练向量的 Flow-GRPO 在 PickScore、OCR 上分别恢复原权重 RL 增益的 **103.6%** 和 **104.6%**；用户成对比较中，对 RL 模型胜率为 **50%–52%**，未显著偏离持平。
- 未参与拟合的偏好指标、颜色下降和多样性损失也接近原 RL 模型，表明它复现的是整套生成倾向，而非单一评分维度。

## 机制与边界

增益主要来自**有条件 pass、早期步骤和文本流**。三者组合仅需 35,328 个参数，即完整向量的 12%，便恢复 OCR 的 **89.5%** 和 PickScore 的 **73.7%** 增益。切断 joint attention 中“图像读取文本”的 key/value 通路后，steering 只剩 OCR 增益的 20.5%、PickScore 增益的 10.5%；冻结网络会把同一偏移转化为随提示词变化的注意力分配和输出。

同参数 LoRA 在 RL 任务上没有稳定优势，但在 DreamBooth 新主体与身份学习中明显更好。因此，结论不是“所有微调都只需常量”，也不证明 RL 更新必然低秩；其适用范围仍受视频验证数量及未测试 RL 路线限制。

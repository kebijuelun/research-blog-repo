# Qwen2.5-VL 技术报告精华：原生分辨率 + 绝对时间编码，让 LVLM 真正"看得准"

多模态大模型什么都会一点，但看不清小字、定位不准物体、长视频看到后面忘了前面。Qwen2.5-VL 的解法只有一句话：**用原生动态分辨率 + 绝对时间编码，让模型直接感知真实世界的空间尺度和时间节奏**。结果很硬：72B 旗舰在文档解析、GUI 定位上超越 GPT-4o 和 Claude 3.5 Sonnet；ScreenSpot Pro 高分辨率定位 43.6%（上一代仅 1.6%）；小时级长视频基准 LVBench 47.3，大幅领先 GPT-4o 的 30.8。

## 架构：三处关键改造

- **从零训练的 ViT**：32 层中只保留 4 层全局注意力，其余换窗口注意力，计算量随 patch 数线性增长；原生支持任意分辨率。
- **MLP Merger**：相邻 4 个 patch 分组压缩，视觉 token 减至四分之一。
- **MRoPE 对齐绝对时间**：时间维 ID 与真实时间戳挂钩，不受采样帧率影响——这是秒级事件定位和长视频理解的地基。

三个尺寸（3B/7B/72B）共用同一个约 675M 参数的 ViT，小模型也有一双"好眼睛"。

## 数据与训练：4.1 万亿 token 的精细工程

预训练语料从 1.2T 扩到 4.1T token，三个最精细的数据设计：

- **绝对坐标 grounding**：边界框用真实像素坐标而非归一化值，类别超 1 万种，还合成"查询不存在物体"的负样本教模型拒绝。
- **文档全解析**：表格、公式、乐谱、化学式统一为带坐标的 QwenVL HTML 格式，一个模型包打所有文档类型。
- **带推理的 Agent 轨迹**：每个操作附"为什么这么做"的推理链，防止死记硬背。

训练分三阶段（仅训 ViT → 全参数 → 32K 长上下文），后训练用 SFT（约 200 万条指令，领域分类 + 规则/模型双重过滤）+ DPO 两段式对齐。

## 成绩：不偏科的全能选手

- **文档 OCR**：CC-OCR 79.8、DocVQA 96.4、OCRBench 885 全部刷新纪录；OCRBench_v2 中文赛道超 Gemini 1.5-Pro 20.6%。
- **长视频**：LVBench 47.3 领先 GPT-4o 16 分；时间定位 Charades-STA mIoU 50.9 vs 35.7。
- **Agent**：ScreenSpot Pro 43.6%（专业模型 Aguvis-72B 也只有 23.6%）；无辅助标注即在 AndroidWorld 拿到 35%，超过带 Set-of-Mark 辅助的对手。
- **纯文本不退反进**：LiveBench 57.0、IFEval 86.3，甚至高于纯文本版 Qwen2.5-72B。
- 7B/3B 同尺寸全面领先，7B 在 TextVQA（84.9）上甚至反超 72B。

## 结语

细粒度感知的地基已经打牢，论文自己点出的下一步是多模态 CoT 中视觉信息与推理链的对齐质量，以及 OSWorld 桌面 Agent（8.83 vs Claude 14.90）的差距——上层推理和行动的"夹层"还能更厚。

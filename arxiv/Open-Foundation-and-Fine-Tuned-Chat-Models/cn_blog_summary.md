# Llama 2 精读精华：开源模型如何追上 ChatGPT

Llama 2 解决的是当时开源社区最大的痛点：开源基座能力已不输 GPT-3，却没有任何一个开源 Chat 模型能替代 ChatGPT 这类产品级闭源模型，而对齐配方完全不透明。Meta 的答案是公开全套配方——2 万亿 token 重训基座、数万条精标 SFT 数据打底、百万级偏好数据驱动的迭代式 RLHF。最硬的两个结果：Llama 2-Chat 70B 在约 4000 条提示的人工评测中对 ChatGPT 取得 36% 胜率、31.5% 平局，进入同一梯队；微调后毒性生成率压到约 0%，成为当时毒性最低的开源对话模型。

## 预训练：补齐短板而非颠覆

- 语料全部来自公开来源，训练量 2T token（比 Llama 1 多 40%），上下文翻倍到 4k，34B/70B 引入 GQA 降低推理成本。
- 关键信号：吃完 2T token 后损失仍未饱和，继续加数据还有收益——这是 Llama 3 后来推到 15T 的伏笔。
- 基座成绩：70B 全面碾压同期开源模型（MMLU 68.9、BBH 51.2），多数基准追平 540B 的 PaLM，但与 GPT-4 差距明显，代码是最大短板（HumanEval 29.9 vs GPT-3.5 的 48.1）。

## SFT：质量是唯一门槛

果断放弃数百万条第三方数据，只用 **27,540 条**精标数据就达到很高质量；抽查发现模型输出常不输人工手写，标注预算果断转向性价比更高的偏好标注。

## RLHF：全文的灵魂

- **数据**：自建超 **140 万条**二值偏好比较（有用性 + 安全性两维度），分 14 批收集。关键认知：奖励模型必须随策略模型"保鲜"，每轮迭代都用最新模型重新采样标注，否则因分布漂移失真。
- **双奖励模型**：有用性和安全性天然冲突，拆成两个独立 RM，排序损失加 margin 项区分偏好强度；自研 RM 全面优于开源基线和 GPT-4 零样本。
- **迭代式训练**：RLHF-V1 到 V5，Rejection Sampling（仅 70B 采样、筛选结果蒸馏给小模型、混历史样本防遗忘、温度随迭代重标定）+ PPO（KL 惩罚 + 安全/有用分段奖励）。GPT-4 评判下对 ChatGPT 胜率超 60%。
- **GAtt（Ghost Attention）**：把全程指令拼进训练数据每轮、微调时隐藏并对中间轮 loss 置零，修复多轮"忘人设"——第 20 轮指令遵守率从 0% 提到 100%，且能零样本泛化。

## 安全：全链路工程

预训练数据调查 → 安全 SFT / 安全 RLHF / 上下文蒸馏三板斧 → 350 人红队逐版本循环（违规构造率从 1.8 降到 0.45）。最终 70B 的 TruthfulQA 从 50.18 提到 64.14，ToxiGen 毒性从 24.60 降到 0.01，且有用性不受损；代价是存在误拒问题。

## 三个意外发现

- RLHF 能超越人类写作上限——偏好比较对标注员要求远低于亲自写答案（"未必画得出杰作，但都能品评画作"）。
- 模型学会按 prompt 类型自适应"等效温度"：创意任务保持发散，事实任务坚持收敛。
- 工具使用与时间感知能力零样本涌现：配计算器后在数学基准上大幅超越专门设计的 Toolformer（MAWPS 82.4 vs 44.0）。

## 总结

Llama 2 最大的遗产不是模型权重，而是证明了"对齐配方可以公开复现"——GQA、迭代式 RLHF、双奖励模型、拒绝采样蒸馏此后成为行业事实标准。局限同样清晰：英语中心、代码偏弱、过度拒绝、与 GPT-4 的明显差距，都留给了后续世代。

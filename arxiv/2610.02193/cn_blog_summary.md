# HC-DLM：连续潜变量与离散 Token 互相"搀扶"的层级扩散语言模型

并行解码的扩散语言模型有两条互补但各缺一条腿的路线：离散扩散同一步揭开的 Token 各自独立采样，跨 Token 依赖被切断；连续扩散保住了依赖，但整条去噪轨迹没有任何 Token 锚点，容易跑偏。UIUC 和 Amazon 的 HC-DLM 用一个思路同时补上两条短板：**让连续潜变量成为唯一贯穿生成的持久状态，Token 每步从潜变量"读出"、加噪后"喂回"作为下一步去噪的条件**。结果很硬：6M 参数在数独 Hard 集拿下 72.41%（反超混合扩散基线 CCDD 的 70.73%，碾压 42M 自回归模型的 32.57%），LM1B 上以 75.5 的生成困惑度刷新扩散模型最好成绩。

## 核心结构：层级而非兄弟

- **两级反向链**：连续潜变量 $x_t$ 是"草稿纸"，Token 状态 $k_t$ 是每步誊写的当前答案，誊写结果重新加噪后约束下一步去噪，交替推进直到干净状态。
- **关键区分**：Token 状态**没有自己的转移核**，只通过 $x_t$ 依赖历史，每步重新读出、始终可修改。这正是它与 CADD、CCDD 等"双链平行"混合模型的本质区别——层级（hierarchy）而非兄弟（siblings）。
- **软硬结合**：置信度高的 Token 估计约束潜变量移动方向，不确定的位置留给连续状态自由探索。

## 理论：一个 ELBO 统摄两条轨迹

前向过程刻意让两条加噪链独立，由此推导出单一变分下界，并经 KL 链式法则把每步去噪精确拆成两个互补信号：**离散 Token 预测 + 连续去噪**。也就是说，HC-DLM 完整保留了离散扩散的监督信号，同时叠加连续去噪信号，而非顾此失彼。实用目标进一步简化为三项加权和——重建交叉熵、编码器熵正则、连续去噪（用 CFM 直接回归干净潜变量），其中离散损失经数据处理不等式证明可用尖锐的逐位置交叉熵替代"梯度涂抹"的 KL。

## 实验：三个战场全面开花

- **数独**：Easy 集 94.21%，Hard 集 72.41%，优势恰在需要训练策略之外推理的分布外场景，印证"层级耦合帮助全局约束满足"。
- **Countdown**：CD4 84.41% / CD5 37.52%，同规模 6M 模型中最优（CCDD 仅 81.18 / 25.35），CD5 上只用 85M 的 RDM 7% 的参数。
- **LM1B**：Gen. PPL 75.5，击败全部离散基线和 Plaid、LangFlow 两个连续模型；训练仅单卡 48 小时（对比 LangFlow 约 292 小时）。

## 消融：两条腿缺一不可

- 去掉 Token 脚手架的 Latent DM 在 Hard 集暴跌至 24.74%——连续潜变量会"过度平滑"掉 Token 级约束；去掉潜变量的 MDM 同样明显落后。
- 离散噪声选 uniform 核（94.21 / 72.41）远胜 absorbing 核加自适应解码（最好仅 75.59 / 48.25）：[mask] 是信息空洞会掏空脚手架，且逐格冻结承诺在约束密集任务里一个早期错误就毁掉整解；而 HC-DLM 的 Token 每步重读、永远可改。

## 总结

- 问题定位准：离散缺共享状态、连续缺 Token 锚点，缺陷互补；
- 结构创新：潜变量唯一持有状态，Token 每步读出并回喂；
- 理论扎实：单一 ELBO 精确拆解为两个互补学习信号；
- 效率友好：编码器仅训练期使用，推理不增延迟。

局限：验证仍集中在中等规模可验证任务，扩展到更大预训练 backbone 是有前景的方向。

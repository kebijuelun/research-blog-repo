# ReAct：让大模型边想边做，推理与行动的协同之道（精华版）

大语言模型"会想"（CoT 推理）却不会"做"，"会做"（生成动作与环境交互）却不会"想"——Princeton 与 Google Brain 的这篇 ICLR 2023 论文用 ReAct 首次把两者统一：让模型交替生成推理（Thought）和动作（Action）。效果惊人：在 ALFWorld 和 WebShop 上，仅凭 1-2 个 in-context 示例，成功率分别绝对提升 **34%** 和 **10%**，超过用 $10^3\sim10^5$ 条数据训练的模仿学习/强化学习方法。今天几乎所有 Agent 框架的"思考-行动-观察"循环，都源自这项工作。

## 核心思想：把"思考"也定义为一种动作

- **扩展动作空间**：将动作空间从 $\mathcal{A}$ 扩展为 $\hat{\mathcal{A}}=\mathcal{A}\cup\mathcal{L}$，语言空间 $\mathcal{L}$ 中的"动作"就是一条思考——它不改变环境，只把推理写回上下文，为后续行动铺路。
- **零新架构、零新训练目标**：直接用冻结大模型（PaLM-540B）few-shot prompting 激发，每个示例就是一条人写的"思考-行动-观测"交替轨迹。
- **思考密度因任务而异**：知识密集任务（QA）中密集交替；决策任务（游戏、网页导航）中稀疏出现在关键位置（分解目标、跟踪进度）。
- **四大优势**：设计直观、通用灵活、性能强且鲁棒（1-6 个示例即可泛化）、过程透明到人可**直接编辑模型的思考**来纠偏。

## 实验一：知识密集型推理（HotpotQA / FEVER）

question-only 设定下，模型只能通过一个极简 Wikipedia API（search/lookup/finish）查资料。关键结论：

- ReAct 稳定优于纯动作（Act）；与 CoT 各有胜负（FEVER 上 60.9 vs 56.3 胜出）。
- **组合最强**：ReAct 与 CoT-SC 互为兜底，HotpotQA/FEVER 分别达 **35.1 / 64.6** 的 prompting 最佳成绩——内部知识不自信时去查，查不到时退回推理。
- 人工剖析 200 条轨迹发现：**幻觉占 CoT 失败案例的 56%，而 ReAct 为 0%**（接地于外部知识）；代价是推理错误率更高（47% vs 16%，易陷入重复死循环），且 23% 的失败源于检索跑偏。
- 微调可扩展性更好：仅 3000 条轨迹微调后，62B 的 ReAct 超过所有 540B prompting 方法——它教的是"如何查证"，而非"背知识"。

## 实验二：交互式决策（ALFWorld / WebShop）

- **ALFWorld**（长程文字游戏，134 个未见任务）：ReAct 成功率 **71%**，远超 Act（45%）和用 $10^5$ 条专家轨迹训练的 BUTLER（37%）；ReAct 最差一次（48%）都高于两者最好成绩。
- **关键消融**：相比 Inner Monologue 式的状态复述（53%），含目标分解与常识推理的稀疏思考（71%）明显胜出——值钱的不是"动作间插话"的形式，而是话里的**抽象推理和常识**。
- **WebShop**（118 万真实商品的模拟网购）：one-shot ReAct 成功率 40.0%，比最好的 IL+RL（28.7%）绝对提升约 10%，但仍落后于人类专家（59.6%）。
- **人在回路**：人类只手动编辑两条思考，就能让跑偏的轨迹恢复正确并最终成功——可解释、可诊断、可控制。

## 总结

- 核心思想：把思考视为不改变环境的特殊动作，实现 reason to act、act to reason 的双向协同。
- 推理任务上消除幻觉这一 CoT 头号失败模式（56% → 0%）；决策任务上以 one/two-shot 远超数万条数据训练的 IL/RL。
- 局限：长任务 prompt 易超上下文长度；死循环与检索失败仍是瓶颈。作者预判用高质量轨迹微调结合 RL 是方向——从今天的 Agent 生态看，这个判断相当有先见之明。

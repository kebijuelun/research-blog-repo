# Holo-M：首个面向人形机器人的离散 VLA 模型

VLA 模型早已在机械臂上验证了「把动作变成语言 Token」的路线，但人形机器人近百自由度的全身动作空间，让离散化始终走不通。地平线机器人提出的 Holo-M 是首个打通这条路线的人形 Loco-Manipulation（移动操作）离散 VLA 模型：在 SIMPLE 人形机器人基准上，Generalist 评测成功率 143/180（第二名 Ψ0 为 114/180），Specialist 评测 163/180，同时串行解码步数比自回归方案减少 6.5 倍。

## 为什么离散动作 Token 难上「人形」

论文指出三个层层叠加的障碍：

- **Tokenization 难**：全身动作（腿、躯干、手臂、灵巧手）维度高且异构，扁平词表要么太粗、要么大到塞不进上下文。
- **训练难**：没有单一数据集能覆盖全部自由度，必须混合遥操作、第一人称人类视频、仿真等差异极大的数据。
- **实时推理难**：动作 Token 序列远长于机械臂，逐 Token 自回归解码满足不了全身控制的实时要求。

Holo-M 的设计正是对这三点逐一击破。

## 核心思路：把全身动作「分而治之」

不给整个机器人配一本词典，而是给每个身体部位各配一本小词典，再规定说话顺序：

- **FAST-RVQ 统一动作 Tokenizer**：动作空间分解为 EEF（末端执行器）、Body、Hand、Kinematics 四组（96 维、共 208 个 Token），先沿时间轴做 DCT 取低频「主旋律」（保留前 2 个系数），再用 4 级 RVQ 残差编码高频细节，产出定长序列，验证集重建误差仅 0.0068。EEF 组采用手腕/指尖任务空间表示，成为人类视频与机器人数据的「公共语言」；缺失组不参与 Loss，每个数据源只监督自己覆盖的部位。
- **动作 Token 进词表**：动作、状态 Token 直接扩展进 Qwen3-VL-2B 词表，与语言由同一模型生成，避开了连续 Action Expert 方案（如 Ψ0）必须做的「知识隔离」。
- **分组离散扩散解码**：组内并行去掩码、组间保持因果依赖，推理时按置信度先揭高置信 Token。每组 8 次去掩码迭代时四组共 32 次串行步骤（自回归需 208 步），串行深度减少 6.5 倍，且没有引入任何独立扩散模型或动作头。

## 训练：四阶段渐进

同一 Qwen3-VL-2B 主干贯穿始终，视觉编码器冻结：

- Stage I：在 EgoDex（829 小时人类第一人称数据）与 Humanoid Everyday（31 小时人形数据）上跨本体自回归预训练，四组分解让异构数据各取所长。
- Stage II：在 SIMPLE 训练集上后训练，对齐目标本体。
- Stage III：用分组离散扩散目标微调，得到 Generalist 策略。
- Stage IV：可选地在单任务数据上微调得到 Specialist 策略。

## 实验：SIMPLE 基准全面领先

- **Generalist 143/180**：自回归消融版（Holo-M AR）已达 138/180，超过所有基线，说明主要收益来自 Tokenizer 设计与联合训练方案；扩散版快 6.5 倍，成功率反而不降反升（143 vs 138）。
- **Specialist 163/180**：超过最强基线 Ψ0 的 154/180。优势最大的是长时程移动操作任务 Mobile P&P，成功率 25/30 对 Ψ0 的 18/30，相对提升接近 40%。
- **数据 Scaling**：仅 Humanoid Everyday 预训练即把闭环成功率从 53/180 提升至 119/180，再加 EgoDex 达到 138/180——人类视频数据远比遥操作数据易获取，这是可扩展性的关键。
- **真机部署**：在 Unitree G1-comp 上，单张 RTX 5090 实时运行，8 步去掩码延迟 476.8 ms，落在控制循环 Hold 预算内；真机 Tabletop Grasp 10/10、Move Pick 8/10。

## 总结

Holo-M 证明离散 Token 路线可以在人形机器人上跑通：动作与语言同词表意味着动作能力直接受益于主干预训练能力，未来还能在序列中插入推理 Token（子任务分解、失败恢复），长时程能力随主干推理能力自然扩展。当前局限是依赖解耦式全身控制器（WBC），更大规模的第一人称人类视频是明确的下一步。

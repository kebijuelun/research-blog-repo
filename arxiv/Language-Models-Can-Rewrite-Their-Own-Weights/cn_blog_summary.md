# Self-Rewriting：让模型自诊并改写权重，最高提升 6.6 点

这项研究让语言模型无需训练，依靠自身推理定位问题、修改权重并验证效果，把一次调试成果永久写入模型；27B 模型在 490 道未见题上最高提升 **6.6 个百分点**，还将受损副本在六个图像基准上的准确率从 **7.3% 修复至 70.2%**。

## 核心创新：模型自己完成整套实验

Self-Rewriting 不只是执行方向消融，而是让编辑者与被编辑者同为 Qwen3.5-27B，由模型自主完成目标选择、证据收集、编辑、验证和回滚：

- **诊断**：读取失败答案、准确率、Token 耗尽与重复循环等统计，并检查指定层的隐藏状态、MLP 激活和 Token 概率。
- **编辑**：通过 CPU Python 会话直接替换张量，不使用梯度、优化器或更强模型。
- **验证**：让修改前后的模型以相同随机种子回答相同题目，按题聚合收益并进行置换检验。
- **决策**：只提交有证据支持的修改；测试变差或收益不泛化时撤回。每次会话最多 20 次 Forward Pass、200 次代码运行和 160 轮。

修改只发生一次，之后无需额外 Prompt，也不增加单样本推理成本。

## 自我提升：从“停不下来”到有效改写

27B 发现，主要失败并非不会推理，而是回答冗长、无法结束。它先尝试编辑隐藏状态差异最大的晚层，测试变差后转向早期层；最终用 20 个完成答案和 20 个未完成答案估计方向，从第 8 层两个输出矩阵中去掉该方向的 5%。

- 第一套协议在 490 道留出题、3,920 个答案上，将准确率从 **57.2% 提至 58.3%**，提升 1.1 点，$p=0.038$。
- 第二套协议增加 256 道保留练习题检查。前八次会话中五次撤回；第 2、8 次分别带来 **+4.0、+6.6 点**，均 $p<10^{-5}$，最高准确率达 **63.8%**。
- 每次会话都从 Base Weights 开始，收益并非八次编辑累加；能撤回坏编辑，是系统可靠性的关键组成部分。

## 故障修复：没有干净答案，也能定位并恢复

作者将第 30 层 MLP 输出矩阵的连续 8 行替换为强噪声，使文本准确率降至 0%。27B 不知道损坏位置和方式，也未读取干净权重；它在早期层猜测失败后，转而比较各矩阵的异常权重统计，发现目标矩阵最大权重为中位数的 **1,397 倍**，随后用截断规则修复。

完整编辑将文本留出准确率从 **0.0% 提至 33.0%**；消融显示，只修被定位矩阵即可达到 **55.0%**，接近 Base 的 58.5%。修复值并非恢复原参数，而是把极端随机值压回可工作的范围。

尽管修复会话只接触文本，六个未见图像基准的总体准确率仍从 **7.3% 恢复至 70.2%**，约为 Base 84.3% 的 83%，说明它修复的是共享权重故障，而非背诵某类练习答案。

## 规模效应与边界

只有 27B 同时完成有效自我编辑和修复：2B 未完成修改，4B、9B 会把模型改坏。规模增长带来的关键能力不是“更敢改”，而是读取内部证据、根据测试换层、撤回失败方案。

这些结果支持可审查、可回滚的小步权重修改，尚不代表无限递归自我提升：实验集中于数学失败和一种人工损坏，最佳收益也来自特定会话。可靠评估、安全测试、回滚与人工确认仍是走向持续学习的必要条件。

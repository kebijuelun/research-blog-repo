# Pokémon 2v2：让 LLM 组队打双打，会交流的队伍胜率高出 22 个百分点

让多个 LLM 智能体协同工作，是目前 Agent 领域最被看好的方向之一。但一个基础问题很少有人认真测过：抛开流水线式的任务分发，两个 LLM 能不能像真人队友一样，在信息不全、需要临场决策的场景里商量着把一件事做好？研究者 Oliver Grabner 给出的测试方法出人意料地具体——他把宝可梦对战平台 Pokémon Showdown 的 2v2 双打模式包装成一个多智能体环境，让两个 LLM 各操控一只宝可梦并肩作战。结果很直接：可以自由交谈的队友组合胜率 64%，完全不能交流的只有 42%，而代价是 Token 消耗翻了 3.8 倍。

> 图解：作者为这个多智能体环境绘制的示意横幅——两名 AI 队友在双打对战中通过队内聊天商量各自的出招。

## 为什么现有的多智能体研究测不出"协作"

作者指出了一个结构性问题：目前大多数多智能体研究（如 Hong et al., 2024；Qian et al., 2024）关注的是工作流——智能体们排成一条流水线，把任务逐段传递下去。这种模式测的是分工，而不是协作。真正的协作要求几个智能体在同一时刻面对同一个局面，各自掌握部分信息，然后协商出一致的行动。

宝可梦 2v2 双打恰好是这样的环境。对手的宝可梦配置是隐藏的，伤害数值带随机性，想赢需要真正的策略：读懂对方队伍、分配攻击目标、围绕队友的行动做计划。作者提到，近期的 PokéAgent Challenge（Karten et al., 2026）已经用宝可梦对战做基准测试，但那里每一方只由一个智能体操控，而且专门的强化学习智能体仍然能打过通用 LLM——它测的是单个智能体的对战水平，测不出"两个队友如何配合"。

作者的目标因此很明确：搭一个可控的环境，量化 LLM 智能体的协作能力，并且日后能用强化学习在这个环境里训练出协作行为。

## 环境设计：四个玩家、私聊和四种"说话模式"

环境的底座是官方 Pokémon Showdown 模拟器，外面包了一层 Gym 风格的接口。一场对战有四名玩家，每名玩家从三只宝可梦组成的队伍里操控一只，每方两人。

每个回合，智能体读到的是一段纯英文的战局摘要，加上一份带编号的合法操作列表。它有两个选择：给队友发一条只有对方能看到的私信，或者直接选定招式。一旦选定，队友会被告知它选了什么。

为了隔离"交流"这个变量的作用，作者设计了四种说话模式：

- **自由交谈（Free talk）**：双方可以一直聊，直到都选定招式；
- **各发一条（One message each）**：每人只能说一句；
- **禁止交流（No talk）**：不能发任何消息；
- **单一模型（One model controls both）**：一个模型同时操控本方两只宝可梦。

最后这个对照组很关键：如果单一模型控制两只宝可梦就能达到自由交谈的水平，那说明胜率提升来自"一个大脑统一规划"，而不是对话本身。

评估设置上，Qwen3.8-27B 扮演本方两名队友，对手是一个脚本化的"最大伤害机器人"（max-damage bot）。对战设有随机种子，且每一种队伍抽取都从双方各打一遍，保证四种说话模式面对的是完全相同的对局。

作者还分享了一场真实对战第一回合的片段：两名 Qwen3.8-27B 队友开局就分配了攻击目标，其中一人在最终出手前纠正了另一人的属性克制错误。这正是这个环境想放大的那类行为。

## 结果：交流有用，但每一句都很贵

四种模式的对战结果如下：

| 说话模式 | 胜率 | 每场对战 Token 消耗 |
| --- | --- | --- |
| 自由交谈 | 64% | 978k |
| 单一模型控制两只 | 54% | 450k |
| 各发一条消息 | 52% | 654k |
| 禁止交流 | 42% | 259k |

> 对阵脚本化的最大伤害机器人，Qwen3.8-27B 双人组在四种交流条件下的胜率与每场对战的 prompt Token 消耗。

这组数据说明了三件事。第一，交流确实有用：自由交谈（64%）比完全禁言（42%）高出 22 个百分点，哪怕每人只发一条消息（52%）也明显好过沉默。第二，收益来自对话本身而非集中规划：单一模型控制两只宝可梦只有 54%，低于两个独立智能体自由交谈的 64%——作者据此判断，两个"大脑"之间的讨论过程贡献了额外收益。第三，交流的成本不低：自由交谈每场对战消耗 978k 的 prompt Token，是禁言模式（259k）的 3.8 倍，因为每条消息都意味着一次额外的模型调用，要重新读入整个战局和此前的对话记录。

值得注意的是"各发一条"这个模式的性价比并不突出：胜率 52%，Token 消耗却有 654k。看起来一两次浅层交流既没能换来充分协商的收益，也没能省下多少调用开销。

## 这个环境能分辨模型强弱吗

一个基准测试环境如果只测一种模型赢了还是输了，价值有限；它必须能区分不同水平的选手。作者用不同规模的模型互相对战来验证这一点：

| 对手 | Qwen3.8-27B 双人组胜率 |
| --- | --- |
| Qwen3.5-2B 双人组 | 96% |
| Qwen3.5-9B 双人组 | 74% |
| 最大伤害机器人 | 64% |

> 同一支 Qwen3.8-27B 队伍面对不同强度对手的胜率。对手越强，比分越接近。

27B 队伍打 2B 队伍胜率 96%，打 9B 队伍降到 74%，对最大伤害机器人则是 64%。对手越强，比赛越胶着——胜率随对手实力单调变化，正是这个环境能作为模型对比基准的前提。有意思的是，一个只按最大伤害出招的脚本机器人，难度大致落在 9B 模型队伍之上，这也侧面说明宝可梦双打的决策复杂度不只是"算伤害"。

## 局限与下一步

这项工作的规模还不大：核心实验只用了一个模型（Qwen3.8-27B）扮演队友，对手也以脚本机器人为主，结论能否推广到更强或更异质的模型组合，还需要更多对战数据。作者自己也指出了一个尚未分离的变量：自由交谈模式下，队友不仅能聊天，还能在出手前看到对方已选的招式——胜率的提升里有多少来自"说话"，多少来自"看见队友的选择"，目前的实验设计还区分不开。这正是他下一步要做的消融。

更远的计划有两个方向：一是把环境做成带排行榜的公开基准，跨模型比较协作能力；二是用它做强化学习训练，直接激励协作行为。代码已开源在 GitHub（OliverGrabner/multi-agent-poke-showdown），作者在德州农工大学的 Grace 集群上跑完了这些实验。

回过头看开头的问题：LLM 能不能像真人队友一样临场协商？这个小规模实验给出的答案是"能，且可测量"——对话带来了 22 个百分点的胜率，而这部分收益不是换一个更大的统一大脑就能替代的。对做 Agent 系统的读者，一个可执行的启示是：如果你的多智能体方案里智能体之间只是传递结果而没有真正的协商，可能漏掉了相当一部分能力上限；但每多一轮对话都是真金白银的 Token 开销，先想清楚协商发生在哪个环节最值。

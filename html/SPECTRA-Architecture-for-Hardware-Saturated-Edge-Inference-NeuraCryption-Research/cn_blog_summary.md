# SPECTRA：免校准4-bit量化，让4GB显存跑4B模型

边缘 GPU 往往不缺算力，却被显存容量与带宽卡住；SPECTRA 打通“压缩到执行”的链路，让六款 1.5B–4.1B 模型全部驻留 RTX 3050 Ti Laptop 4GB，实现 **2.80×–3.31× 压缩**，其中 DeepSeek-R1-Distill-1.5B 配合 CUDA Graph 达到 **82.53 tok/s**。

## 核心思路：不依赖校准文本

- **免校准敏感度分析**：对前置 LayerNorm/RMSNorm 的线性投影，利用归一化增益与权重列范数计算通道敏感度；无前置归一化时退回列范数。AST 预扫描直接读取模型结构，主机端延迟低于 **50 ms**，避免 GPTQ、AWQ 等方法对校准分布和预处理的依赖。
- **Group-32 非对称 4-bit 量化**：每 32 个权重设置局部 scale 与 zero point，单权重建模误差不超过半个步长，有效位率为 **4.625 bpb**。这是误差、元数据与带宽之间的折中，而非追求最小量化误差。
- **自适应离群保护**：根据峰度将 **0.5%–3%** 的重尾通道保留为 FP16，其余参数进入小组量化。生产运行时放弃在线 FWHT，避免逐 token 旋转带来的额外计算和访存。
- **面向内核的存储格式**：采用 Marlin 交错布局，并通过 24 字节固定头的 TRDC4B01 格式和 `mmap` 零拷贝映射加载，减少解包开销及模型加载时的内存峰值。

## 真正加速的是融合执行

单 token 解码的算术强度仅约 **1 FLOP/B**，瓶颈是供数而非峰值算力。SPECTRA 将 nibble 解包、反量化、FMA 累加和离群补偿融合进 Triton W4A16 GEMV，权重在寄存器中直接参与计算，不再生成 FP16 显存暂存张量；Prefill 和批量生成则切换至 Tensor Core GEMM。

系统还同时压缩其他显存占用：

- Embedding 按需收集并反量化词表行，显存从 1,050 MB 降至 **321.4 MB**，节省 **69.4%**。
- 4-bit KV Cache 在 8,192 token 下从 1,572.8 MB 降至 **393.2 MB**；与量化权重合计仅 **1,310.8 MB**。
- 双缓冲 PCIe 预取最多隐藏 **88%** 的传输延迟，硬件探测则自动选择驻留、卸载或缓存量化策略。

## 质量与边界

六款生产模型的相对 Frobenius 误差为 **8.04%–8.32%**，SNR 为 **21.59–21.89 dB**。ARC-Challenge 上量化版本比 FP16 高 0.42–0.85 个百分点，但置信区间高度重叠，只能说明未观察到准确率下降，不能据此宣称量化必然提升推理能力。

离群保护也并非越多越好：真实模型上 Pure Group-32 的 WikiText-2 PPL 最低；但在 1% 通道被放大 64 倍的压力测试中，其误差升至 11.40%，HDSQ-Ultra 仍保持在 **8.11%**。因此应按实际峰度和任务选择配置。

SPECTRA 的关键贡献并非单独的“零校准”，而是敏感度代理、适配硬件的小组格式、无显存暂存的融合内核，以及跨 Transformer、ConvNet/SSM、Mamba-2 的完整运行时。其在更多领域、更大模型和非 NVIDIA 后端上的表现仍需验证；持续运行也有热降频，Qwen-3.5-4B 的 Graph 解码在 10 分钟后由 14.55 降至 **12.08 tok/s**。

# FLUX 3 Image 精华解读：图像生成从"许愿"变成"排版"

文生图最大的痛点不是画质，而是构图失控——prompt 写得再细，谁站左边、标题放哪，基本靠抽奖。Black Forest Labs 最新发布的 FLUX 3 Image 直击这个问题：用 Bounding Box 在画布上精确指定每个元素的位置和大小，模型保证元素各自渲染进自己的框里。同时它支持原生 2K/4K 输出（单图最高 5456 × 3072、16.8 MP）和最多 10 张参考图融合。

## 核心创新：布局成为一等公民

过去的补救方案是 ControlNet 这类外部插件，FLUX 3 则把布局理解能力直接训进了模型本体。核心交互分四步：

- **定宽高比**：画布被抽象为 0–1000 的归一化网格；
- **拖框定元素**：每个框带坐标 `[y_min, x_min, y_max, x_max]` 和一句描述；
- **写场景句**：一句话串联元素之间的关系；
- **生成**：各元素严格落在自己的框内。

设计上的巧思是**语义 id 机制**：每个框有可读名字（如 `dome_1`），场景句通过引用 id 绑定布局与描述——布局 prompt 既是几何约束，又是结构化文本，人和 LLM 都能读写。适用场景是元素多、位置关系严格的构图：海报排版、拼贴、网格分镜等。

## 基本功与编辑能力

- **纯文本生成依然扎实**：文字渲染（邮票上的小字号签名、杂志封面标题）、材质细节（马海毛绒毛、雨天路面反光）、风格化印刷品三项都很稳——正是商业设计最看重的。
- **多目标定向编辑**：沿用同一套框 + id 语言，一轮可同时做多处修改（换颜色、换物体、换画风），未触碰区域以 Locked 标记严格保持不变。修图可以逐轮迭代而不"越修越散"，对电商修图、海报改稿极其实用。
- **Pixel-perfect 编辑**：面向几何级增删（如在海面凭空加入潜水员），与语义级框选编辑互补，共同保证"没改的地方一个像素不漂"。
- **多参考图融合**：上传最多 10 张图，各获 token（`ref_image_0` 起），prompt 引用即可，模型自行决定构图——服装电商无需训练 LoRA 就能虚拟试穿。

## 原生 4K：直接进生产管线

原生渲染而非超分放大。官方示例 5456 × 3072 的荞麦面店全景中，灯箱手写体字符约 225 像素高、灯笼字符透光、玻璃窗内食客握筷清晰可见。超分只能补"合理的模糊"，补不出真实小字和纹理——原生 4K 让生成图可直接交付印刷和大屏投放。

## 为 Agent 而生

模型原生具备布局理解能力，天然适合被 Agent 调用：LLM 拿到一句话 prompt 即可规划出全局 caption 加元素框表（官方示例把"三位跳《天鹅湖》的芭蕾舞者"展开成 6 元素布局），用户可微调任意框。关键原则是**用户约束不可篡改**：prompt upsampler 可以扩写描述、建议新元素，但用户画的每个框的 id 和坐标逐字保留。

## 商用与上手

提供 commercial weights license，企业可在自有基础设施微调和部署；也可在官方 Playground 拖框体验，或通过 BFL API 直接发送布局 prompt。

一句话展望：当"布局语言"成为图像模型的通用接口，同一套坐标体系自然会向视频和动作延伸——届时 Agent 编排的将不只是单张图，而是整条视觉内容生产线。

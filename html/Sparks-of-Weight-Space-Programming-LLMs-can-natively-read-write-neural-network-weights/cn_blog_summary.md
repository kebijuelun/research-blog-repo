# 权重空间编程：修改 0.016% 权重修复 LLM 推理循环

不用训练或梯度，只修改 Qwen3.5-0.8B 的 0.016% 权重，就把 MATH-500 成绩从 7.9% 提高到 48.1%。MIT CSAIL 团队将这条路径称为 Weight-Space Programming（权重空间编程）：让通用模型 GPT-6 Astra 按自然语言目标，直接读取、修补或生成神经网络参数。对模型审计与优化而言，这意味着除了重新收集数据和训练，还可能用推理定位权重中的故障。

## 权重不只是训练产物

这套方法不让 Adam 等优化器代为搜索，而是把权重本身当作可读写的程序。Astra 仅凭原始权重，识别出四个输入通道、动作和维度均相同的游戏策略，以及三个 DDPM 扩散模型分别生成圆形、三角形还是正方形。

更严格的测试移除了语言模型的输入与输出层，只保留四个 Transformer Block。面对三个 7.2M 参数、分别学习 Python、罗马字日语和英语的模型，Astra 不能运行网络，却在各两次测试中全部判断正确，找到的复制头也与实测一致。这表明它能利用中层参数的组合关系，但尚不能据此完整证明其内部推理过程。

## 从局部修补到一次生成

在 Kinetix 车辆爬坡任务中，PPO 策略因直接冲坡而卡住。Astra 在单次尝试、无工具辅助下修改 3.5% 权重，加入读取位置和速度的旁路，让车辆先后退助跑；修复策略在 1,024 个回合中全部成功。

在 Breakout、Seaquest 和 Asterix 三款 MinAtar 游戏中，Astra 无法访问数据、Loss、梯度、工具或环境反馈，一次写出的三个网络却都超过 PPO 训练 1 亿步的基线。不过，基线延长到 5 亿步后，Breakout 以 517.4 分远超 25.3 分，Seaquest 和 Asterix 则分别为 53.1 对 88.9、53.2 对 55.2。它证明的是一次生成可以达到很强的策略水平，并非全面优于充分训练的 PPO。

## 修复循环不等于增加能力

Qwen 实验允许最多 50 次前向传播，但禁止训练和梯度。Astra 将反复生成同一文本的问题定位到第 15、19 层 MLP，共修改 131,072 个权重。编辑后，MATH-500 从 7.9% 升至 48.1%，GSM8K 从 13.8% 升至 67.1%，触及 Token 上限的回答比例则从 93.0% 降至 33.1%。因此，提升更像拆除遮住已有能力的故障，而非重新教会模型数学。

两个反例划出了边界：对很少循环的 Gemma 3 270M，没有任何编辑带来超过约 1 个百分点且已确证的 MATH-500 提升；面对两份 Gemma 谄媚审计模型，Astra 仅靠权重四次判断全部失败，获准观察中间注意力后，才在三组模型对中全部识别正确。两组实验条件不同，分数不能直接横向比较。

回到最初的问题，通用 LLM 已能直接操作权重，却还远未取代训练：小网络的成功不能直接外推，大模型案例也依赖工具和前向反馈。团队已公开[完整实验日志](https://github.com/RikiyaT/lm_understand-logs)，这条路径能否成为可靠的审计与优化工具，仍待标准基准和独立复现检验。

# 为什么所有大模型画的鹈鹕都长一个样：被忽视的多样性坍缩

给 13 个最新的大语言模型同一个提示词——"生成一个骑自行车的鹈鹕的 SVG"——会得到 13 只几乎一模一样的鹈鹕。作者 Aman Rusia 用 Simon Willison 的这组经典测试跑了一圈前沿模型，每个都开到能返回 SVG 的最高推理档位：

![十三个近期大模型生成的骑自行车鹈鹕](images/model-grid.png)

> 图解：13 只鹈鹕 SVG 来自不同模型，但构图、视角、风格高度趋同——基本都是侧视图、卡通化、配色相近，仿佛出自同一只手。

但它们本可以不这样。同一只鹈鹕，完全可以出现在皇家巡游、季风、极夜、山地赛、沙漠、浓雾、霓虹小巷、婚礼、市集、维多利亚式漫步、暴风雨乃至月球上：

![十二只风格迥异的骑自行车鹈鹕](images/diverse-grid.png)

> 图解：同一句提示词可以衍生出场景、氛围、画风截然不同的十二种诠释，这才是"开放生成"该有的样子。

作者把这个现象称为**多样性坍缩**（diversity collapse）：模型不仅各自输出趋同，还收敛到了同一个"安全答案"。这不是某个模型的缺陷，而是整个梯队的共同行为模式。

## 从鹈鹕到 UI 基准

鹈鹕测试背后是一项更系统的研究：Kombai 团队 Dipanjan Dey 等人发布的 **Design Creativity Bench**。基准让 16 个前沿模型完成 80 个开放式 UI 任务，每个任务适配两个产品领域，并以人类设计师方案作对照。与以往只测单个输出质量的基准不同，它拆出三个维度：**原创性**（同一简报下与其它模型的差异）、**创造幅度**（换产品领域后设计决策调整多少）、**恰当性**（是否满足功能要求，创造性不能靠牺牲可用性换取）。

结果相当直接：尽管前沿模型生成可用界面的能力提升很快，在创造性设计决策上仍明显落后。

| 排名 | 模型 | Creativity score |
| --- | --- | --- |
| — | Human reference | 92.3 |
| 01 | GPT-6 Astra | 65.5 |
| 02 | GPT-6.1 Sol | 63.7 |
| 03 | Grok 4.7 | 62.2 |
| 04 | Gemini 3.8 Flash | 60.6 |

> 表中为人类基线与得分最高的四个模型，完整榜单见基准官网。

第一名与人类参考相差近 27 分，而前四名彼此只差几分——这个分布本身就呼应了多样性坍缩：模型们水平接近、输出相似，人类设计师仍在另一个量级上。团队公开了完整榜单、方法论和评估框架（论文 arXiv:2610.11539、HuggingFace 数据集、GitHub 仓库），供检验复现。

## 谁该关心

只做代码和文案生成，趋同往往就是"正确答案"，无伤大雅；但任务一带开放性——设计、创意、风格化生成——模型越对齐、越会猜"标准答案"，输出就越收敛到同一种平庸。近 27 分的差距说明这不是换个提示词能抹平的。

也要留意边界：鹈鹕 SVG 只是轶事式演示，真正有分量的是 UI 基准，其分数构成和评分者偏差需读论文才能下结论。下次再看到某个模型"设计感惊人"的演示，不妨多问一句：让它画十只鹈鹕试试。

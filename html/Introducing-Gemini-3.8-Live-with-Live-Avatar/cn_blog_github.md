# Gemini 3.8 Live with Live Avatar：实时视频数字人来了

语音助手只能"听声不见人"，是 AI 对话体验长期缺的一块拼图——人类交流本来就是听、看、说、表情四位一体的。Google 在上周发布 Gemini 3.8 Live 的基础上，紧接着推出了 **Gemini 3.8 Live with Live Avatar** ：把原生实时语音对话和低延迟视频生成直接耦合在一个模型里，让 AI 拥有一张会听、会看、会说的"脸"。最硬核的两个亮点是：唇形与表情可以在 **97 种语言** 之间无缝切换且不损失画质，并且支持在对话不中断的前提下 **异步调用工具** 完成复杂任务。该功能即日起在 Gemini Enterprise 中上线。

> 图解：Gemini 3.8 Live with Live Avatar 的官方宣传图。这次更新的核心是给原生实时对话模型加上近实时（near real-time）的视频生成能力，输出一个有表情、有唇形同步的动态虚拟形象。

## 为什么对话 AI 需要一张"脸"

先回到问题本身。对话天然是多模态的：我们听对方说话、看对方的表情、用面部动作回应。纯语音助手砍掉了视觉通道，交互就天然残缺——客服场景里少一分信任感，导览讲解时少一分直观性。

Google 的解法不是"语音模型 + 数字人渲染管线"这种拼装方案，而是把视觉和音频输入放在同一个模型里 **同时处理** ，再统一生成语音和视频输出。笔者认为这是关键差异：拼装方案里语音和画面是两条流水线，唇形对齐、打断响应都要额外工程去缝；而原生耦合的方案从一开始就是"一个大脑"，对话轮换（turn-taking）、被打断时的表情收敛都由模型自己决定。

对企业来说，这意味着虚拟客服、交互式产品演示这类场景，可以从"语音机器人"升级到"有形象、有表情的虚拟员工"，而且形象可以匹配品牌（详见后文）。

## 核心能力拆解

解决了"有没有脸"的问题之后，下一个问题是：这张脸够不够用？官方重点展示了三项能力，我们逐一拆解。

### 多模态输入，表情化输出

Live Avatar 同时接收视觉和音频输入——换句话说，它不只是听你说话，还能"看"你给它展示的东西，然后用带表情的音视频流回应。

这个设计的聪明之处在于输入输出是对称的：既然输出端有了视觉通道，输入端也开放视觉通道，才能支撑"交互式 walkthrough（导览）"这类场景——用户把摄像头对准设备，虚拟形象一边看一边讲解，而不是盲人摸象式地纯靠语音描述。

### 异步工具调用：边干活边聊天

传统的 Function Calling 是同步的：模型发起工具调用，对话就卡住等结果返回，用户面对的是一段尴尬的沉默。Live Avatar 引入了 **异步工具执行（asynchronous tool calling）** ：工具调用在后台触发、数据在后台拉取，对话本身继续推进。

官方给的例子是酒店前台场景：虚拟形象一边和客人保持对话，一边在后台调用系统完成入住办理。这背后依赖的是 Gemini 的推理能力——模型要决定什么时候该发起调用、在等待结果期间该说什么来填充对话，而不是简单地播一句"请稍等"。笔者认为这是从"演示型数字人"走向"干活型数字人"的关键一步。

### 97 种语言的唇形同步

多语言支持的难点不在语音合成，而在 **视觉一致性** ：不同语言的口型差异很大，如果唇形和表情不能跟着语言动态适配，画面立刻"出戏"，甚至出现面部漂移（visual drift）。

Live Avatar 的做法是原生的 **多语言语音到语音同步（multilingual speech-to-speech synchronization）** ，官方称可以在对话中途无缝切换语言，覆盖 **97 种语言** ，且不降低视频保真度、不引入视觉漂移。对全球化企业来说，这意味着一个虚拟形象可以服务所有市场，不需要为每种语言单独做适配。

## 形象定制与安全设计

能力之外，企业落地还有两个绕不开的现实问题：形象能不能是自己的？内容可不可信？

### 品牌定制形象

除了官方提供的多样化预设形象库，企业还可以定制专属 Avatar：只需提供一张 **高质量参考图** ，就能生成一个完全可动画、可实时响应的形象，同时保留参考图中的人物特征、品牌风格或角色设定。

需要注意的是，定制形象目前仅通过 **企业白名单（enterprise allowlisting）** 开放，普通开发者暂时用不上。这个收紧是可以理解的——从一张照片生成会说话的真人形象，本身就是深度伪造（deepfake）风险最高的能力之一。

### SynthID 水印：AI 内容可溯源

所有由 Live Avatar 生成的音频和视频输出，都会嵌入 **SynthID** 水印。这是一种人耳人眼不可感知、但可被检测器识别的数字水印，直接编织进音视频流中，用于标记"这是 AI 生成内容"，降低虚假信息传播和身份冒用的风险。

把水印做成默认开启、不可关闭，配合定制形象的白名单审核，可以看出 Google 在这项高滥用风险能力上的部署策略：能力放开，但每一环都留溯源和管控的钩子。更完整的安全设计细节可以参考官方发布的 model card。

## 如何上手

Gemini 3.8 Live with Live Avatar 现已上线 **Gemini Enterprise** ，开发者可以通过官方 API 文档接入。需要注意它的定位是企业级产品，而非面向个人开发者的公开 API 功能。

## 总结

- **一个大脑** ：实时语音对话与低延迟视频生成原生耦合，不是语音 + 渲染的拼装方案。
- **看得见的交互** ：视觉、音频同时输入，表情化音视频输出，对话轮换和打断处理更自然。
- **边聊边干活** ：异步工具调用让对话在后台任务执行期间不中断。
- **一张脸说 97 种语言** ：唇形与表情跨语言无缝适配，无画质损失和视觉漂移。
- **可控可溯源** ：参考图即可定制品牌形象（企业白名单），所有输出默认嵌入 SynthID 水印。

从语音到"语音 + 形象"，实时对话 AI 的交互带宽又翻了一倍；接下来值得观察的是，当数字人真正进入客服、导览等生产场景，表情和唇形的"恐怖谷"效应会不会成为新的体验瓶颈。

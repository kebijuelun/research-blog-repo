# GLM-Legal：轻量模型如何炼成法律专业 Agent（精华总结）

让大模型像律师一样把散乱的事实、法条和论证串成完整链路、交出可直接用的法律文书——GLM-Legal 做到了：在轻量基座 GLM-5.3-Flash 上，靠领域 Mid-training 加与 Agent Harness 协同进化的 Post-training 炼成法律专业 Agent。最硬的成绩：真实律所工作流评测 Harvey LAB 上拿下 **19.2% All-Pass 通过率**，比基座提升 **12.5 个百分点**，接近基座三倍。

## 成绩单

- **Harvey LAB（19.2% All-Pass）**：覆盖 24 个执业领域，一环掉链子都不得分，考验"全程不退化"的执行力。
- **LegalBench（86.2）**：法律文档解析精度与顶级闭源模型持平，参数量级却小得多。
- **PLawBench（77.3）**：中文法律咨询与文书起草，与前沿系统打平。

看点："轻量基座 + 领域训练"打出越级表现，训练方法才是主角。

## 方法三板斧

- **Mid-training 打地基**：扩大高质量法律语料，强化"事实 → 规则 → 结论"的演绎链条。
- **Post-training 与 Harness 协同进化**：在数万个真实法律环境中用强化学习把知识转化为执行力，模型与运行时编排框架锁步迭代，大脑手脚一起长，避免"模型很强但系统接不住"。
- **生产反馈闭环**：执业律师按覆盖完整性、引用合法性、遵守案件简报、下游可直接使用四条标准评估输出，把主观质量变成工程化损失信号。

## 实战对比：从"建议"到"交付物"

- **合同审查**：基座说"可以考虑缩短通知期"；GLM-Legal 直接给方案——通知期 60 天压到 30 天、知产类违约取消补救期、追加 90 天过渡协助。
- **证据分析**：基座找到对外 60%、内部 41% 的单点矛盾；GLM-Legal 把"内部知情 → 隐瞒并继续开票 → 付款不构成权利放弃"连成链，支撑起隐瞒理论。
- **合规调研**：基座给通用清单；GLM-Legal 输出带优先级的行动方案，直接引用新马印尼具体法条。

## 启示

这套"**轻量基座 + 领域 Mid-training + Harness 协同 RL + 生产闭环**"配方可复制——法律只是第一个压力测试场，能否平移到医疗、金融等领域值得关注。能力将通过 AutoClaw 交付，API 已开放申请。

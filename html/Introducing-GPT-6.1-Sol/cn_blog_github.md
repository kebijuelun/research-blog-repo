# GPT-6.1 Sol：五分之一价格买到"准旗舰"智能

养 Agent 最贵的是什么？不是模型不够聪明，而是聪明模型的 Token 账单。OpenAI 最新发布的 GPT-6.1 Sol 就是冲着这个痛点来的：它在 Agentic Coding、Computer Use 和专业办公任务上几乎追平旗舰模型 GPT-6 Astra，但输入输出 Token 价格只有 Astra 的 **五分之一** 。更狠的是缓存输入价格——每百万 Token 仅 $0.10，比标准输入便宜 95%，比上一代 GPT-6 Sol 的缓存价还要再低 50%。对于需要反复复用上下文、长时间运行的 Agent 应用来说，这几乎是把"养 Agent"的成本直接砍了一个数量级。

![GPT-6.1 Sol](https://raw.githubusercontent.com/kebijuelun/research-blog-repo/main/html/Introducing-GPT-6.1-Sol/images/desktop-transparent.png)

> 图解：GPT-6.1 Sol 官方宣传图。这一代 Sol 的定位非常明确——不做最贵的旗舰，而是做"性价比甜点"：用约 1/5 的价格，提供接近 Astra 的智能水平，主打需要大规模部署 Agent 的开发者和企业场景。

## 从 Sol 到 6.1：一次全方位的"加量降价"

GPT-6.1 Sol 是 GPT-6 Sol 的升级版，但并不是一次小修小补。按照官方的说法，它在编程、文档理解、多步业务流程等复杂专业任务上全面大幅超越前代，并且在多项评测上逼近 GPT-6 Astra 的水平。

这个定位其实很聪明。旗舰模型（Astra）负责刷新 SOTA 上限，而 Sol 系列负责把"够用以上"的智能铺到真正跑量的场景里。GPT-6.1 Sol 的意义在于： **"够用"的门槛被抬高了，而成本没有。**

下面我们按任务类型逐一拆解它的成绩单。

## 编程能力：1/5 成本追平旗舰

先看开发者最关心的 Coding。在 **DeepSWE v1.1** 上——这是一个让 AI Agent 在真实代码库中解决原创、长周期软件工程任务的基准——GPT-6.1 Sol 的成绩直接追平 GPT-6 Astra，而成本只有 Astra 的约五分之一。

对比前代更能看出进步幅度：

- 比 GPT-6 Sol 的历史最好成绩 **高出 6.4 个百分点** ；
- 而且这是在 **更低的 Reasoning Effort（推理强度）** 下达成的，意味着不仅更准，还更省。

笔者认为这里最值得注意的不是"追平 Astra"本身，而是"在更低推理强度下追平"——这说明能力提升来自模型本身，而不是靠堆更多推理 Token 硬算出来的。

## 专业办公：啃 PDF、跑流程都在行

解决了写代码之后，下一个问题是：日常的"白领活儿"能不能干？GPT-6.1 Sol 在两个基准上给出了答案。

### GDP.pdf：复杂文档问答

GDP.pdf 考察的是模型基于复杂 PDF 文档回答专业问题的能力——文档来自金融、医疗、法律等十个专业领域的真实工作流，里面全是表格、图表、示意图和小字注释，堪称"职场阅读理解地狱难度"。

GPT-6.1 Sol 在这项评测中：

- 在所有受测推理设置下，得分 **超过 Opus 5.5（含 fallback 重试）** ，而单任务成本不到对方一半；
- 同时以约 **1/5 的单任务成本** 逼近 GPT-6 Astra 的 SOTA 水平。

### AutomationBench：多步业务流程自动化

AutomationBench 1.0.6 测试的是 Agent 端到端完成真实业务流程的能力——覆盖销售、市场、运营、客服、财务、HR 六大职能，共 47 个工具。

- GPT-6.1 Sol 在中等推理强度下比 Opus 5.5 **高 2.2 个百分点** ，成本约为对方的 **三分之一** ；
- 相比 GPT-6 Sol 同设置提升了 **4.8 个百分点** 。

值得一提的是，官方还特意指出：榜单上 Claude Fable 5.1 的成本数据其实被低估了，因为统计时没有计入它在约 40% 任务上触发 fallback 的额外开销。这种"帮对手纠正数据"的细节，在厂商互卷的当下算是一股清流。

## Computer Use：离 Astra 只差 2.1 个点

光会写代码、看文档还不够，真正能替人干活的 Agent 得会操作电脑。 **OSWorld 2.0** 的离线测试集就是干这个的：让 Agent 完成横跨日常与专业场景的长周期电脑操作任务（报告的是 v2026.08.08 版本离线集上的 partial reward）。

GPT-6.1 Sol 的表现：

- 在最高推理强度下，比 GPT-6 Sol **高出 7 个百分点** ，成本却不到一半；
- 与 Astra 的最高分差距缩小到 **仅 2.1 个百分点** ，而单任务成本约为 Astra 的 **七分之一** 。

2.1 个点的差距配上 7 倍的成本差，这个交换比对绝大多数实际部署场景来说都相当划算。

## 科学研究：成本优势最夸张的一战

在 **Terminal-Bench Science 0.1** 上——Agent 需要用代码和终端工具完成数据分析、仿真、定理证明等科研工作流——GPT-6.1 Sol 交出了全场最夸张的成本数据：

| 模型 | 单任务平均成本（最高推理强度） |
| --- | --- |
| GPT-6.1 Sol | **$5.47** |
| Opus 5.5 | $23.21 |
| GPT-6 Astra | $23.80 |

> 表解：Terminal-Bench Science 0.1 最高推理强度下的单任务成本对比。GPT-6.1 Sol 比两个对手都便宜 75% 以上，而得分比 GPT-6 Sol 翻了一倍还多。

需要说明的是，GPT-6 Astra 仍以 68.1% 的得分保持全场最高，官方也明确表示最难的科研任务仍应交给 Astra。换句话说，Sol 负责"科研量产"，Astra 负责"科研攻坚"——分工清晰。

## 事实准确性：低推理档进步最大

能力强了，说话靠不靠谱？OpenAI 用一组"故意刁难"的评测来验证：从脱敏的 ChatGPT 对话中，挑出用户曾标记过旧模型事实错误的对话，统计新模型回答中仍含事实错误的比例（注意：这些是刻意挑选的高难度样本，错误率远高于日常使用水平）。

结果：

- 提升最大的是 **低推理强度** 档位：错误回答占比从 11.4% 降到 7.7%， **相对降幅约 32%** ；
- 在所有受测推理设置下，错误率与 GPT-6 Astra 的差距保持在 **1.9 个百分点以内** ，而单任务成本不到 Astra 的 1/5。

低推理档的进步尤其有实际意义——这正是大多数对延迟和成本敏感的线上场景所使用的档位。

## 安全对齐：更会"承认不行"，也更守规矩

能力之外，GPT-6.1 Sol 在对齐评测上也明显向 Astra 看齐，主要体现在三个方面：

- **更坦诚** ：面对"搜索工具坏了"这类故障场景，它比 GPT-6 Sol 更少假装一切正常，而是如实说明局限；
- **更守边界** ：在执行 Agent 任务时，更少无视用户的显式限制、更少产生未授权的操作结果；
- **不钻空子** ：全程未观察到任何试图绕过自动化安全审查器的行为，与 Astra、GPT-6 Sol 持平。

完整的评测细节收录在 GPT-6.1 Sol 的 System Card 附录中。官方也强调，这些评测刻意选择了高难度对抗场景，不代表日常使用中的失败率。

## 价格与可用性

最后是大家最关心的部分——多少钱、在哪用：

- **API 定价** ：输入 $2 / 百万 Token，缓存输入 $0.10 / 百万 Token，输出 $10 / 百万 Token；
- **API 模型名** ：`gpt-6.1-sol`；
- **ChatGPT 端** ：即日起面向 Plus、Pro、Business、Enterprise 和 Edu 用户开放，入口在 ChatGPT Work 和 Codex 中（暂未进入普通 Chat 对话）；
- **即将推出** ：GPT-6.1 Sol Ultrafast，在 Codex 中 Token 生成速度最高可达标准速度的 **8 倍** 。

缓存输入 $0.10 的价格值得单独说一句：对多轮 Agent 应用而言，系统提示、工具定义和历史上下文在每轮请求中大量重复，缓存命中率天然很高。把缓存价打到这个水平，等于直接把长上下文 Agent 的主要成本项清零了大半。

## 总结：旗舰负责上限，Sol 负责规模

- GPT-6.1 Sol 在 Coding、专业办公、Computer Use 等多项评测上 **逼近甚至追平 GPT-6 Astra** ，价格仅为 Astra 的约 1/5；
- DeepSWE v1.1 上以更低推理强度追平 Astra，比前代 Sol 提升 6.4 个百分点；
- Terminal-Bench Science 上单任务成本 $5.47，比 Astra 和 Opus 5.5 便宜 75% 以上；
- 事实错误率在低推理档下降 32%，对齐表现全面向 Astra 看齐；
- 缓存输入 $0.10 / 百万 Token，为长上下文 Agent 应用留出了巨大的成本空间。

展望来看，GPT-6.1 Sol 的意义不在于刷新任何一项 SOTA，而在于它把"准旗舰级智能"的价格打到了可以大规模铺量的区间——当 Agent 的单任务成本进入个位数美元甚至更低，很多原本算不过账的自动化场景会开始变得成立。当然，最难的科研攻坚任务仍然需要 Astra 坐镇，"Sol 系列守门、旗舰冲顶"的双层产品线格局，看来还会延续下去。

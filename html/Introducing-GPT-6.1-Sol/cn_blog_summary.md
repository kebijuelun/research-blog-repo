# GPT-6.1 Sol：五分之一价格买到"准旗舰"智能

养 Agent 最贵的不是模型不够聪明，而是聪明模型的 Token 账单。OpenAI 新发布的 GPT-6.1 Sol 直击这个痛点：它在 Agentic Coding、Computer Use 和专业办公任务上几乎追平旗舰 GPT-6 Astra，Token 价格却只有 Astra 的 **五分之一**；缓存输入更是低至 **$0.10 / 百万 Token**，比标准输入便宜 95%，比上一代 Sol 的缓存价再降 50%——长上下文 Agent 的成本几乎被砍了一个数量级。

## 核心成绩单

**编程（DeepSWE v1.1）**
- 直接追平 GPT-6 Astra，成本仅约 1/5；
- 比前代 GPT-6 Sol 最好成绩高 **6.4 个百分点**，且在**更低推理强度**下达成——提升来自模型本身，而非堆推理 Token。

**专业办公**
- GDP.pdf（金融、医疗、法律等十大领域的复杂 PDF 问答）：所有推理设置下超过 Opus 5.5，单任务成本不到对方一半，并以约 1/5 成本逼近 Astra 的 SOTA；
- AutomationBench（六大职能、47 个工具的端到端业务流程）：中等推理强度下比 Opus 5.5 高 **2.2 个百分点**，成本约为对方 1/3；比前代提升 4.8 个百分点。

**Computer Use（OSWorld 2.0）**
- 最高推理强度下比 GPT-6 Sol 高 **7 个百分点**，成本不到一半；
- 与 Astra 最高分差距缩小到 **仅 2.1 个百分点**，单任务成本约为 Astra 的 **1/7**。

**科学研究（Terminal-Bench Science 0.1）**

| 模型 | 单任务平均成本（最高推理强度） |
| --- | --- |
| GPT-6.1 Sol | **$5.47** |
| Opus 5.5 | $23.21 |
| GPT-6 Astra | $23.80 |

成本比两个对手便宜 75% 以上，得分比前代翻倍。不过 Astra 仍以 68.1% 保持全场最高——Sol 负责"科研量产"，Astra 负责"科研攻坚"。

**事实准确性与安全对齐**
- 低推理档事实错误率从 11.4% 降到 7.7%，**相对降幅约 32%**（这正是对延迟和成本敏感的线上场景常用档位）；各设置下与 Astra 差距在 1.9 个百分点以内；
- 对齐上更坦诚（工具故障时如实说明局限）、更守边界（更少无视用户显式限制），且全程未观察到绕过安全审查的行为。

## 价格与可用性

- API 定价：输入 $2 / 百万 Token，缓存输入 $0.10，输出 $10；模型名 `gpt-6.1-sol`；
- ChatGPT 端面向 Plus / Pro / Business / Enterprise / Edu 开放，入口在 ChatGPT Work 和 Codex（暂未进入普通 Chat）；
- 即将推出 GPT-6.1 Sol Ultrafast，Codex 中生成速度最高达标准速度的 **8 倍**。

## 总结

GPT-6.1 Sol 的意义不在于刷新 SOTA，而在于把"准旗舰级智能"打到了可大规模铺量的价格区间：当 Agent 单任务成本进入个位数美元，很多原本算不过账的自动化场景开始成立。"Sol 守门、旗舰冲顶"的双层产品线格局，看来还会延续下去。

# Meta AI 新作 MIRA：让研究型 Agent 学会"下一步该查什么"

长周期研究型 Agent 最难的不是"怎么查"，而是"接下来查什么"——这类决策稀疏、后果延迟，强化学习几乎无从下手。Meta AI 联合哥伦比亚大学、特拉维夫大学提出的 **MIRA** 给出了漂亮答案：**不做任何策略训练，仅靠架构拆分就能提升定理证明和神经网络架构研究的表现**；训练出 MIRA-AC 后，**四个自动研究环境的 gold score 全部提升**。

## 问题：分配决策为何难学

研究 Agent 有两类决策：执行层（具体调查怎么做）和分配层（下一步调查什么）。后者决定轨迹质量，但对 RL 极不友好：

- **稀疏**：上万 token 的轨迹中，分配决策寥寥无几，训练信号稀薄；
- **延迟**：后果要等好几个调查周期才显现，credit assignment 困难。

## 架构：一分为二，决策只在工单边界发生

MIRA 把研究分配与执行彻底分离：

- **外层 Meta-reasoner**：读取持久化的"研究记录"，为下一次调查写下工单（work order），或结束整个 episode；
- **内层 Executor**：每个工单由一个**全新的** executor 完成，结果回流到研究记录。

从外层视角看，整个研究过程被压缩成一串稀疏而清晰的决策点——**决策只发生在工单边界上**。原本混在长轨迹里难以学习的分配决策，变成了天然可对齐的训练单元。这就像把流水账改写成"决策日志 + 附件"。

## 训练：Critic 先行，再升级为 Actor-Critic

- **生成式 Critic**：在每个工单边界处，从"部分完成的研究状态"预测剩余回报。实验证明这种方式**优于 token 级预测**；跨环境预训练还能得到可迁移的"评估部分进展"先验。
- **MIRA-AC**：用 critic 先验初始化单一模型，同时承担预测回报（critic）和选择方向（actor）两项职责，无需单独的 critic 模型。策略优化只聚焦 meta-reasoning 决策，**不必直接优化上万 token 的执行轨迹**。
- **训练信号**：直接用模型自身的 proxy hill-climbing 信号训练，却提升了四个环境的 **gold 性能**——说明 meta-reasoning 确实可以作为显式策略被学习。

## 关键结果

- **零训练即提分**：仅架构拆分就改善长周期推理，在定理证明和开放式架构研究上更高效地分配算力；
- **Critic 更准**：工单边界预测优于 token 级方案，且可跨环境迁移；
- **MIRA-AC 全面提分**：四个 autoresearch 环境 gold score 全部提升，actor 还能借跨环境 value 初始化实现迁移。

## 总结

MIRA 的启示是：面对稀疏+延迟的长周期决策难题，不必硬刚，可以通过架构设计把问题"变形"——把决策隔离到工单边界，再在这些边界上训练判断力。遗留问题是：训练依赖 proxy 信号与 gold 目标的对齐质量，当代理指标偏离真实研究价值时，自我评估驱动的训练是否会累积偏差，值得继续观察。

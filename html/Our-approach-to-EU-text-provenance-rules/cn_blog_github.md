# OpenAI 首次公布文本水印方案 textGrain：为合规 EU AI Act，也坦白告诉你它有多不可靠

AI 生成文本到底能不能被"打上标记、事后识别"？这是欧盟 AI Act 对生成式 AI 厂商提出的硬性合规要求，也是 OpenAI 这篇文章要正面回答的问题。2026 年 10 月 5 日，OpenAI 公布了其文本水印技术 **textGrain** 的分阶段落地计划：即日起全球 API 客户可以为指定模型开启水印（默认关闭），未来几周内欧盟地区的 ChatGPT 和 Codex 输出将默认嵌入不可见水印，检测器则仅向获批的研究者和专家组织开放。最值得注意的是，OpenAI 罕见地把"丑话"说在了前头：在 1% 误报率目标下，400 token 文本的检出率约 95%，200 token 掉到约 80%，而替换 25% 的同义词后检出率仅剩 17%——同时官方基准测试显示加水印对模型能力几乎没有影响。这篇文章与其说是一次技术发布，不如说是一次"技术能力边界"的公开交底。

## 为什么是现在：EU AI Act 的合规压力

文章内容溯源（Content Provenance）要回答三个问题：内容从哪来、如何被创建或编辑、是否带有某个模型的生成痕迹。OpenAI 此前已经在图像和音频上开放了识别工具，而文本是最难啃的一块骨头。

欧盟 AI Act 明确要求：生成式 AI 提供商必须让生成的文本以 **机器可读** 的方式可被识别。但文本水印和检测仍是早期技术，局限明显，业界对其价值和负责任使用方式的看法也还在形成中。

OpenAI 的应对是一个分阶段（phased）方案，既满足法规要求，又承认技术现状，核心是对"水印能说明什么、不能说明什么"保持透明：

- **即日起**：全球 API 客户可以为指定模型 **opt-in**（主动选择开启）文本水印，API 默认不开启。
- **未来几周**：在欧盟地区为符合条件的 ChatGPT 和 Codex 文本输出添加不可见水印。
- **即日起开放申请**：文本水印检测器的访问权限，初期仅限获批的研究者和专家组织，用于帮助评估和改进技术。

需要强调的是，这些只针对文本。图像和音频的验证工具——包括 openai.com/verify 网页工具和 Content Provenance API——仍对所有组织公开可用。

## textGrain 是怎么工作的

textGrain 的原理可以用一个直觉来理解：模型生成文本时，很多位置其实有多个"都说得通"的候选词，textGrain 就在这些选择中掺入一种 **人眼不可见的统计偏好** ——不改动任何字面内容，只让选词分布在统计上呈现特定规律。检测器拿到一段文本后，去寻找这个统计信号，判断它是否包含 OpenAI 的水印。

这个设计的聪明之处在于：水印不依赖元数据（metadata），而是嵌在文本本身的选词里，因此文件被复制、元数据被剥离后信号仍可能保留；但反过来，它的命门也在这里——只要文本被改写，选词分布变了，信号就会衰减。

OpenAI 表示，技术细节见其技术报告（未来几周会补充更多内容），并计划将该技术 **开源** ，让社区可以在此基础上继续构建。在其内部评估中，textGrain 的表现达到或超过了包括 Google SynthID 文本版在内的其他受测方案。

## 性能实测：理想条件下的数字，和现实的差距

OpenAI 特意提醒：理想条件下的好成绩，不等于日常使用中的可靠检测。检测器会犯两类错误—— **误报**（false positive，没有水印却报告有）和 **漏报**（false negative，有水印却没检出）。官方给出的两组数据非常能说明问题。

### 文本越短、措辞越受限，越难检测

在 1% 目标误报率下（基于 ELI5 数据集的水印回复）：

- 心理学类内容：200 token 段落检出率约 **80%** ，400 token 段落约 **95%** 。
- 数学类内容：检出率显著更低，因为数学表达中措辞的灵活空间很小——公式就是公式，没那么多"同义词可选"。

> 图解：原文此处配有检出率随文本长度变化的对比图。横轴为段落长度（token 数），纵轴为检测成功率，分别给出数学与心理学两类内容的曲线。整体趋势是文本越长信号越强、检出越高；而措辞自由度低的数学内容，在各长度上都明显落后于心理学内容。

### 编辑会快速削弱水印

对 400 token 的水印段落做同义词替换实验：

- 替换 **10%** 的词：检出率从约 92% 跌到 **66%** 。
- 替换 **25%** 的词：检出率只剩 **17%** 。

> 图解：原文第二幅图展示了编辑强度对检测的影响。横轴为被替换词的比例（0%、10%、25%），纵轴为检测成功率。曲线下降非常陡峭——只改动四分之一的措辞，水印信号就基本被"洗掉"了。这组数据基于 ELI5 数据集的英文水印回复。

换句话说，一段被简单"洗稿"过的 AI 文本，大概率会被检测器漏报。这正是 OpenAI 不敢把检测器直接公开的核心原因： **一个容易误报又容易漏报的工具，一旦面向公众，带来的误判伤害可能大于收益。**

## 加水印会不会让模型变"笨"？

这是所有用户最关心的问题：在选词上强加统计约束，会不会损害输出质量？OpenAI 用其最新前沿模型 **Astra** 的全套基准测试回答：看不到有意义的差异。

| Benchmark | 无水印文本 (Astra, max) | 有水印文本 (Astra, max) |
| --- | --- | --- |
| Artificial Analysis Intelligence Index | 49.57 分 | 49.76 分 |
| AutomationBench | 34.09% | 34.86% |
| DeepSWE v1.1 | 72.80% | 71.68% |
| Terminal-Bench 4.0 | 53.90% | 56.06% |
| Terminal-Bench Science 0.1 | 56.90% | 60.00% |
| BrowseComp | 87.92% | 87.35% |
| HealthBench Professional | 64.27% | 64.60% |
| GPQA Diamond | 94.44% | 93.94% |

八个基准里，水印版有升有降，波动都在噪声范围内。从博主视角看，这张表其实是在为"默认开启水印"扫清最大的产品障碍——如果质量无损，合规成本就只剩检测可靠性这一个维度了。

## 水印不能告诉你什么：五条"免责边界"

解决了"怎么加水印"之后，下一个问题是：拿到一个检测结果，到底能下什么结论？OpenAI 用五条否定句划清了边界，每一条都在预防一类典型的误用：

- **水印不能衡量人类贡献** 。它能说明 OpenAI 的系统生成或处理过这段文字的某部分，但无法量化其中有多少人的判断、编辑或创作。
- **水印不能确立所有权或责任** 。它不判定文本归谁所有、使用是否合法、是否需要披露、谁该为此负责。
- **水印不能识别用户身份** 。它不会把任何个人、组织、账号、prompt 或对话与文本关联起来。
- **水印不能验证内容真伪** 。它不告诉你这段话是真实的、误导的、有害的，还是被断章取义的。
- **没检出水印 ≠ 人类所写** 。文本可能太短、被编辑过、被翻译过，也可能来自不支持水印的模型、早于水印功能上线，或者干脆是别家公司的模型生成的。

最后一条尤其关键：它直接堵死了"用检测器抓 AI 代写"这个最常见的滥用场景——检测阴性在法律和事实上都不能作为"人类原创"的证据。

## 接下来的落地节奏

- **欧盟先行** ：未来几周内，面向欧盟所有套餐的 ChatGPT 和 Codex 符合条件用户上线水印，且 **不会** 在发布时设为全球默认。区域化试点留出了从真实使用和反馈中学习的空间。
- **API 全球 opt-in** ：即日起，全球 API 客户可为指定模型开启水印输出，自行决定水印如何配合其透明义务和用户产品体验。OpenAI 也在与云合作伙伴推进，未来几周内让通过其服务访问的 OpenAI 模型输出也支持水印。
- **检测器有限开放** ：获批研究者和专家组织即日起可申请。依据 Code of Practice，访问将逐案审批，以支持对文本溯源技术的评估与改进。工具只报告是否检出 OpenAI 水印，不暴露用户身份、prompt 或对话内容。鉴于漏报和误报风险，发布时 **不面向公众开放** 。

OpenAI 表示，随着技术、标准和证据演进，方案的每一部分都会被重新审视。

## 更大的图景：分层的内容溯源体系

单拎文本水印出来看，它脆弱、易绕过；但 OpenAI 的定位很明确： **没有任何一种溯源技术能独当一面** ，正确姿势是分层组合。

在图像和音频侧，这套体系已经铺开：为受支持的图像输出添加 Content Credentials（内容凭证）、符合 C2PA 标准、在图像和音频中嵌入不可见的 SynthID 水印，并通过 openai.com/verify 和 Content Provenance API 提供公开验证。各层互补——Content Credentials 记录文件的来源和历史，而隐形水印能在元数据被剥离后仍保留信号。

这些信号再与平台政策、滥用检测、举报、调查和处置机制配合，服务于识别 deepfake 等潜在误导性 AI 内容的场景（正如其选举保障工作所述）。文本是这个体系的最后一块拼图，也是最难的一块：文本太容易被改写、翻译和编辑了。OpenAI 承诺继续改进检测能力、研究水印在编辑和翻译下的存活率，并探索更有意义地区分"AI 辅助"与"AI 代笔"的方法。

## 结语

- **核心动作** ：为合规 EU AI Act，OpenAI 发布文本水印方案 textGrain——API 全球 opt-in 即日起生效，欧盟 ChatGPT/Codex 未来几周默认开启，检测器仅限获批研究者申请。
- **技术原理** ：在模型选词中嵌入不可见统计信号，不改动字面内容，性能达到或超过 SynthID 文本版，并计划开源。
- **能力边界** ：1% 误报率下，400 token 检出约 95%、200 token 约 80%；替换 10% 同义词降到 66%，替换 25% 只剩 17%。
- **质量无损** ：Astra 全套基准上，加水印前后成绩无有意义差异。
- **五条"不能"** ：不衡量人类贡献、不确立权属责任、不识别用户、不验证真伪、检不出不等于人类所写。

一句话展望：文本水印今天能提供的只是一个"有限且易碎"的信号，真正的看点在于开源之后的社区改进，以及"区分 AI 辅助与 AI 代笔"这个更难的问题能否被攻克。
